Implemented facts

页面内容来自现有工具代码

flycheck 当前是基于 Python、pandas 与 Tkinter 的 macOS 桌面工具。用户选择两份 Excel 文件、数据类型和检查方式后运行比对，结果在界面中区分“正确”与“差异”，并可保存为 Excel 日志。

官网只说明已实现的处理流程，不上传源代码、原始表格、真实单位名称、人员姓名、证照号或训练记录。

Verification workflow

实际核验流程

以下步骤对应当前代码的处理顺序。

  1. 01
    载入两类数据读取训管数据和云执照数据 Excel 文件，并检查空行和列数范围。
  2. 02
    选择核验场景选择机上训练或 FTD/FFS，以及学员检查或教员检查。
  3. 03
    标准化字段组合日期与时间、统计昼夜着陆次数，并统一模拟机编号和机型等格式。
  4. 04
    逐条比对根据明确映射核验时间、航空器或模拟机、起降与训练分类字段。
  5. 05
    输出与留痕汇总录入错误、未录入和重复录入，并保存包含时间范围和结论的 Excel 日志。

Current checks

代码中已经实现的检查

不同场景使用不同列映射，以下为当前版本覆盖的主要字段。

  • 机上训练登记号、航空器型号、出发站、到达站、滑出/滑入时间等。
  • FTD/FFS模拟机编号、机型、模拟机等级、开始/结束时间等。
  • 时间与次数训练时间、机长/转场/带飞/仪表/单飞时间及昼夜着陆次数。
  • 学员检查逐行比对字段值，并汇总录入错误数量。
  • 教员检查按开始时间识别未录入、单次录入或重复录入。
  • 异常提示识别空行、无效时间格式、数据列不符及两侧行数不一致。
