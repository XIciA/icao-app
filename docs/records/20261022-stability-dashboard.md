# 后台稳定性仪表盘

用户确认以用户体验、资源与容量、费用与到期、事件与恢复四类组织；去掉待办建议面板，
以折线、柱状、占用条和备份采样格展示客观数据。苹果与安卓包不变；告警只保留服务器记录。

## 实现与数据边界

- 现有 Ops 后台新增管理员专用看板；复用原会话、角色和审计。
- AI 已结束调用成功率、小时 P95 与费用来源为 `ai_usage_logs`，每日有点击账户来源为
  `product_click_events`。按上海自然日区分，不称完整日活、在线人数或用户任务成功率。
- 复用五分钟监控历史；新增真实 CPU 使用率和内存占用采样，旧记录保留未知。
- 服务器只导出白名单聚合子目录并只读挂载到 Ops，不挂载 Docker socket、环境文件或原始日志。
- DeepSeek 余额由现有普通 API 容器使用内部密钥读取；余额与费用估算分开显示各自时间及口径。
- 官网维护链接已提供；真实并发、手机完整体验、套餐余量、到期日、异地副本、恢复验证、版本
  时间线与压测上限尚未接入时显示缺口，不以示例值、文件存在或空采样冒充已验证状态。

## 验证与交付状态

本地真实数据库与服务器历史预览可用；四类、总览和时间范围切换，以及 1280/768/390/320px
布局完成浏览器验证。其余静态、鉴权和聚合检查以本任务最终执行结果为准。

上线需使用合入主干的干净源码执行正式 Ops 发布脚本，并将两份监控 Python 文件安装到同一个
不可变 release 目录。上线后验证只读挂载、五分钟自动采集、角色隔离、真实余额和回滚产物。
当前记录不宣称生产部署或用户验收已经完成；部署后补充精确提交、标签与证据。
