# 历史档案

这里保存被替代但仍有追溯价值的战略、设计基线、流程、阶段记录和需求快照。

- 档案内容反映其形成时的上下文，不代表当前产品状态或工程要求。
- Codex 默认不读取本目录。只有排查历史原因、迁移遗漏或用户明确要求时才检索。
- 归档文件应尽量保持原文；当前事实写入 `docs/resources/`，长期规则由用户明确写入
  `docs/rules/`。
- 档案内相对链接和本机路径可能保留原目录形成时的样子；使用时结合迁移表与 Git 历史定位。
- 删除档案前必须确认没有独有信息、没有有效引用，并且 Git 历史可恢复。
