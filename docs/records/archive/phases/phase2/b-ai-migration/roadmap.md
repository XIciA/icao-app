## 3. B0：基线与真实模型预检

### 主要工作

- 为 `docs/resources/ai/` 与仍在运行时使用的基础资产生成文件清单、checksum 和引用报告，冻结迁移基线。
- 从已授权的 `feizhuicu/.env.local` 读取必要模型配置，安全写入本地/ECS 私密环境；不打印或写入 Git。
- 在 ECS 执行一次最小文本 JSON mode 和一次短 WAV ASR 真实调用，锁定 provider 地域、模型快照、超时和价格版本。
- 记录密钥来源已验证、模型 ID 与冒烟结论，不记录密钥值。

### 允许/禁止范围

- 允许：文档、资产校验脚本、私密环境配置、最小真实调用。
- 禁止：不改 RN 页面，不建数据表，不公网开放，不输出密钥。

### 验收

- 真实文本与 ASR 请求均成功，快照/地域/成本可用，资产快照无结构错误。
- 如密钥失效、账号未开通、模型不可用或数据地域不符合已定边界，形成 P0 并回到大流程。

## 4. B1：共享 contract 与 AI 后端核心

### 主要工作

- 建立五能力请求/结果/错误 contract、Prompt/hints 版本和禁止字段。
- 建立资产编译/选择层、NestJS AI module、TextProvider/AsrProvider、百炼适配器与统一错误映射。
- 使用 JSON mode + Zod/字段白名单阻断越界输出；保留 `rawTranscript` 和 `hintsVersion`。

### 允许/禁止范围

- 允许：`packages/contracts`、`services/api/src/ai`、资产生成/校验脚本、API 测试。
- 禁止：不接页面，不迁移 Web 评测/模型选择，不保存用户内容。

### 验收

- 假 provider 测试通过；真实文本/ASR 短请求符合合约，越界字段被拒绝，民航资产稳定 ID 与含义未改变。

## 5. B2：同意、流水、额度与录音门禁

### 主要工作

- 新增 Migration：AI 使用流水、同意版本和必要的额度/并发状态；完成 RLS/服务端权限和索引。
- 实现同意/撤回、北京日额度、每分钟频率、单用户语音任务锁、成本预警/熔断与最小化流水。
- 实现 ASR 专用 multipart、文件校验、取消、`finally` 删除和超时清理。

### 禁止范围

- 不保存原始音频、完整 Prompt、完整输入/输出、IP 或设备指纹；不上传 Storage；不先接学习页。

### 验收

- 未同意、超额、超频、并发和成本熔断不能绕过；失败/取消不扣功能额度；成功/失败/超时/取消/限制都有流水。
- 临时目录在成功、失败、取消和超时清理后无残留；Migration 可从空库应用并重复验证。

## 6. B3：真实 AI 查词

### 主要工作

- 接通五套题库 `InteractiveStudyText -> AI 查词 Sheet -> API`，展示释义和本句理解。
- 实现应用会话缓存，键包含模块/句子/词/短语/Prompt/模型版本；完整覆盖加载、超时、失败、限制和重试。

### 验收

- 五套题库真实调用成功；短语不硬拆；同键复用不发外部请求、不增加成功额度；无模型密钥进入 bundle。

## 7. B4：真实语音转写

### 主要工作

- 在现有录音上增加主动提交、上传进度/取消、转写、失败与重试。
- 保留只读 `rawTranscript`、`hintsVersion` 和可编辑规范化文本；后续能力只使用用户当前确认文本。
- 实现民航缩写/数字的白名单规范化，保留语法错误与未完整表达。

### 验收

- 900 句、陆空通话、OPI、故事复诵均在真实 ASR 下可用；编辑不改 `rawTranscript`；超大/无效音频被拒绝；服务端无临时音频残留。

## 8. B5：900 句原文比对

### 主要工作

- 迁移确定性 token/diff 规则，输出完全一致或 missing/extra/replacement/order。
- 将用户确认文本与当前稳定原文比较，在“我的回答”中展示差异。

### 验收

- 四类差异与完全一致测试通过；操作不调外部模型、不扣 AI 额度、不产生分数/等级。

## 9. B6：语法检查与 OPI 表达润色

### 主要工作

- 陆空通话/故事复诵接入 grammar-only，展示中文反馈、issues 和 correctedText。
- OPI “分析表达”按 grammar -> polish 组合，分层展示原转写、用户编辑文本、纠错与润色。
- 保留独立 polish 服务能力，不开发独立学习入口；不实现 `rewrite-answer`。

### 验收

- 三模块真实模型调用成功；无语法问题时 issues 为空；润色保留原意与近似长度；无评分、等级、标准答案或新信息补全。

## 10. B7：主动保存与恢复

### 主要工作

- 扩展 `LearningRecord` 为会话报告/AI 保存结果的向后兼容联合类型。
- 只在用户点击“保存”后写入本地 store 和同步 outbox；记录可包含 `rawTranscript`/用户确认文本/纠错/润色，不包含音频。
- 在现有学习记录页显示 AI 结果类型，不建立 AI 历史页；使用流水始终不对用户显示为内容。

### 验收

- 未保存结果在退出后不进入学习记录；已保存结果可在退出重登、第二受控 iOS 会话恢复；重复保存不重复数据。

## 11. B8：iOS 完整验收与收口

### 必须验证

- `pnpm check`、`pnpm doctor`、Migration 空库/重复应用、iOS Development Build。
- iOS 模拟器 + 物理 iPhone：五库查词、900 句“录音 -> 转写 -> 对比”、ATC/story“录音 -> 转写 -> 语法”、OPI“录音 -> 转写 -> 语法 -> 润色”。
- 同意/撤回、错误密钥隔离、额度、频率、并发、成本熔断、超时、取消、上游失败、无效返回和重试。
- 临时音频无服务端/Storage 残留；使用流水无用户全文/音频；主动保存结果可跨会话恢复。
- 民航资产的文件、稳定 ID、含义和 `hint-only` 边界保持。

### 收口标准

- 不存在“AI 功能待接入”、Mock 成功结果、缺密钥降级或只有假 provider 通过的能力。
- 所有需求验收项有真实调用与 iOS 证据，无密钥泄漏、静默误扣额度、音频残留或静默保存 AI 内容。
- 更新 `phase-log.md`，生成 `closeout.md`；明确 Android、公网运营、支付、评分与评测工具仍未开放。

## 12. 小流程启动条件

- 用户确认 `technical-plan.md` 和本 `roadmap.md`。
- 当前工作区的文档改动归属清楚，不存在与 AI 写入范围冲突的未提交改动。
- 确认后从 B0 自动执行；除密钥失效/账号未开通、成本或数据风险扩大、需要改变已确认需求外，不重复请求人工确认。
