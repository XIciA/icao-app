# 历史归档：第二阶段 A 需求——题库云端接入与数据同步

状态：已验收

更新时间：2026-07-12

## 1. 定位与目标

第二阶段 A 是完整第二阶段的受控子阶段，只利用当前已具备的 ECS 完成真实云端数据基础，核心交付是题库/资源接入和学习数据同步。

邮箱密码账号只用于给同步数据建立最小用户归属，不扩展为完整账号阶段。

本子阶段不替代完整第二阶段。匿名游客、手机号、微信、AI、权益和商业化仍按原第二阶段继续保留。

## 2. 云端基础

- 使用已购买的阿里云中国内地 ECS 部署真实开发/内测服务。
- 建立 TypeScript 业务后端、自托管 Supabase Auth/PostgreSQL/Storage、Migration、配置门禁和备份恢复能力。
- 密钥只保存在服务端，客户端不得持有数据库、Storage 管理或服务端密钥。

## 3. 真实题库与资源

- 五套题库、4947 张卡片进入云端权威数据源，保持现有字段、稳定 ID、内容和模块关系。
- 3894 个规范音频文件及首版图片进入对象存储，服务端保存资源元数据和稳定 object key。
- App 通过远程 repository 和资源 adapter 使用云端数据，同时保留当前内嵌题库作为受控回退。
- 资源缺失、网络失败、超时和缓存失效必须有明确提示与重试，不提供完整离线下载。

题库采用统一内容工程，不建设五套独立代码：

- 维护层：按题库、话题拆分源文件，统一 schema、稳定 ID 和资源命名，便于编辑、审查和追踪变更。
- 发布层：由脚本统一校验并生成带版本、checksum、manifest 和变更报告的发布产物；生成文件不得手工维护。
- 运行层：继续使用统一 `QuestionBankRepository`、业务 API、学习页面和资源 adapter，不让页面感知维护目录。
- 新增或更新题库必须经过 ID 唯一性、数量、字段、资源引用、checksum 和兼容性检查；已有稳定 ID 不得重编号、复用或随目录移动改变。

## 4. 邮箱密码账号

- 第二阶段 A 只实现邮箱和密码的最小注册、登录、会话恢复和退出，用于验证账号归属和数据同步。
- 未登录时保留现有本地学习能力；云同步仅对已登录邮箱账号启用。
- 手机号、微信、Apple 和真实云端匿名游客不在本子阶段实现；相关 adapter 和后续接入边界必须保留。
- 本子阶段不要求验证邮件、找回密码、换绑邮箱、全部设备退出或账号注销；这些能力不得反向阻塞题库和同步主线。
- 页面不得把尚未实现的登录方式显示为可真实使用。

## 5. 学习数据同步

- 同步学习进度、作答、标注、高亮、笔记、学习记录和报告。
- 首次登录时，设备现有本地数据必须可安全归入当前账号，不得清空、重复或静默覆盖。
- 上传、拉取和重试必须幂等；旧版本不得覆盖新版本，失败时继续保留本地数据。
- 同账号重新登录或第二个受控 iOS 会话后，可以恢复核心学习数据。
- 本地存储继续承担退出保护和失败恢复，不建设完整离线学习或复杂双向冲突编辑器。

## 6. 环境与验收边界

- 第二阶段 A 仍只验收 iOS，不执行 Android 构建、模拟器或真机测试。
- 当前 ECS 在正式域名和受信任 HTTPS 就绪前，只允许通过本机或 SSH 隧道进行开发验证，不向公众开放账号注册。
- iOS 模拟器可在安全隧道内验证；物理 iPhone 的公网完整链路必须等待受信任 HTTPS。
- 当前环境只用于内部开发测试，不代表已满足备案、公开运营或正式上架条件。

## 7. 后续接口预留

- 认证层必须允许后续增加匿名游客、手机号、微信和 Apple，不让学习数据绑定具体登录方式。
- 资源层必须允许后续从自托管 Storage 迁移到 OSS/CDN，业务数据只保存稳定 object key。
- 同步层必须通过业务 API 和版本化 contract 工作，不让页面直接依赖数据库或 Supabase 表结构。
- 后端必须保留 AI、权益和商业化模块边界，但本子阶段不创建其真实业务。

## 8. 明确不做

- 不解决原第二阶段的微信 Auth 可行性门禁，也不为微信建立平行账号系统。
- 不接手机号、Apple 登录、短信、邮件发送服务、AI、支付、会员或权益。
- 不改变题库内容、稳定 ID、现有 UI 视觉、导航和学习流程。
- 不删除内嵌题库、现有 SQLite 学习数据或当前回退能力。
- 不公开运营，不上传未经确认的真实用户数据。
- 不为完成第二阶段 A 购买或开通新的域名、备案、SMTP、短信、微信、AI 或商店服务。

## 9. 验收效果

- ECS 上可从空环境重复建立后端、Auth、数据库和 Storage，配置缺失时安全失败。
- 五套题库和规范资源可重复导入、校验和读取，数量与引用可对账。
- 维护源、发布产物和运行接口边界清楚；单库更新无需复制页面、Repository 或后端模块。
- 受控测试用户可通过邮箱和密码建立最小账号，完成登录、会话恢复和退出。
- 登录账号可同步并恢复核心学习数据，弱网、重复提交和冲突不会造成静默丢失。
- 当前内嵌数据与本地记录在迁移期间仍可回退，完整第二阶段的延期能力保持清楚。
