# 1.3.14 随身听目录与原生词频角标修复

## 范围与根因

- 随身听原先只补全当前题库，切换会取消旧轮并用目录元数据替换其他题库已补全内容；列表却以暂存 tracks.length 显示总数。Web 还订阅每次权益刷新版本，权限未变化的心跳也会重启加载。
- 现改为会话内一次有界并发加载所有授权目录，当前题库优先，逐话题发布不可变快照；切换不重启，权限变化仍清空并重载，失败保留已经返回的快照并提供重试。完整性由授权话题的实际卡片数判断，未完整时不声称暂存题数是总数。音频文件仍按播放需求加载。
- 词频角标旧 left:100% 依赖 CSS 式收缩定位。使用仓库 React Native 自带 Yoga、YGErrataAll 复现：390 点屏宽、80 点短词时，旧角标局部左坐标361、右边421，超出350点内容区；新布局为219–279，单词中心仍在175。等宽左右76点插槽与可收缩词文本替代绝对百分比定位。
- 高频词书介绍补充：单词右上角标注其在题库原文中的出现次数。
- 不包含讨论中的分组目录改版，无后端部署、数据库迁移、会员授权修改或正式商店发布。
