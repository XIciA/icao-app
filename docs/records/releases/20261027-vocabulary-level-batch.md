# 2026-10-27 后台批量调整等级与词库历史

用户在本聊天确认方案后要求执行。范围为现有运营后台、本地后台桥接与管理 API；App 客户端、在线词库协议、安装包版本、正式词库内容及用户学习数据不作修改。

## 实现

- 词库管理增加批量调整模式与操作历史；沿用三本词书、释义和现有词频。支持搜索、四种排序、复选、多选移动、筛选结果全选、跨分类累计、批次撤销及净变化预览。
- 草稿按管理员隔离保存在当前浏览器；刷新恢复。发布前展示原分类、目标分类、各书前后数量，可填写备注。线上版本变化时保留草稿，核对冲突后再合入。
- 专用管理接口仅接受词条 ID 和目标词书，最多 5000 项；从服务端当前词条构造修改，保留原 ID、正文、例句、录音和频次。继续使用既有发布规划、完整校验、发布锁、资源就绪检查和版本快照。
- 一个批次在一个事务中切换词库版本并写审计；批次编号与内容指纹支持并发/超时重试幂等。浏览器先保存待提交内容，结果不明时锁定原批次，重试不会换批次编号。
- 历史复用 vocabulary_releases 和 ops_audit_events，无新增表/迁移。按快照对比还原旧记录，展示时间（北京时间）、操作人、类型、备注及逐词变化；支持单词/账号/类型/日期筛选、分页和版本详情。最早快照没有前版时明确说明，不伪造历史。
- 本地后台既有 URL 白名单补充 levels/preview、levels/publish 和 history，只允许相应管理路径；沿用原管理员权限。

## 验证与交付边界

- 聚焦自动化覆盖原有编辑、合并、拆分与排序，以及跨分类累计、120 词选择、草稿恢复、净零移动、未知结果原批次重试、冲突处理、历史筛选/详情。
- 真实隔离 PostgreSQL 覆盖 110 个词一次发布、并发重复批次只生成一版、版本栅栏、审计失败整体回滚、历史查询和移动后保留学习/收藏状态。
- HTTP 控制器覆盖管理员/客服/未登录权限、大批次输入、非法目标、条数上限和历史参数；本地白名单新路径及越界拒绝。
- 运营前端/API 类型检查及构建、受影响 API lint、合同运行时检查与聚焦测试通过；GitHub CI 与最终本地安装证据以 PR 和本机交付清单为准。浏览器已进行只读预览，未向正式库提交测试移动。
- 截图功能对应线上新版运营后台代码；本机同时运行的旧版后台尚无词库入口，不能将该旧进程视为截图入口。本轮先更新本地后台供直接验收；线上独立运营后台生产部署需另核对明确授权，ECS App API 不需部署，不作数据库迁移或正式词库发布。

代码检查通过不等于用户验收。本轮不重新构建 App、不修改 App 更新提示或现有词库版本。
