# 离线音频、下载恢复与学习界面统一交付

用户授权修复下载／离线播放回归、保护学习保存与同步，并将两个并行界面任务一起交付；明确授权必要 API 部署和新 TestFlight。统一 PR [#330](https://github.com/XIciA/icao-app/pull/330) 已合入 main，精确源码 `c841dbaebfd02784db679d50ed289903417b597d`。原 PR #329 的完整改动及后续四入口增量已包含，原 PR 已关闭，三个实现任务的临时分支与工作树已清理。

## 根因与修复

- 3596169 增加高频原子保存后，Expo SQLite 的独立事务连接会与离线索引读取、下载状态读写争用，产生 `SQLITE_BUSY`。共享存储入口现在协调完整写操作与读取，保留原子性、数据格式和账号隔离；没有更换播放器、清除下载或丢弃保存失败。
- 随身听目录逐题签发凭据，与下载共享账号配额，容易触发 429。学习、随身听与下载改用同一签发入口，批量、去重、复用有效凭据并隔离旧账号任务，保留权限、签名、版本和有效期校验。
- 限流原先被归为不可恢复的“待验证”。API 返回兼容旧端的可选冷却秒数，App 级调度到期恢复，旧遗留任务重新评估一次；用户手动暂停、删除和切账号不能被自动恢复覆盖。
- 检查结果明确区分已下载部分和未完成任务。整合下载状态颜色、首页共用图标与单行更新时间；四个标注／查词入口共用列表条目，保留筛选、高亮定位、收藏撤销；会员六项权益只调整 App/Web 展示。
