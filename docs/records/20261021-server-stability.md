## 同步

- 初次调查最近 24 小时 `/v1/sync/push` 出现 720 次 413。未把请求次数当作受影响人数。
- 线上 API 原 bodyLimit 16 MiB；只读统计发现单条 session 学习记录最大 13,968,574 字节，其中 studyReview 占 13,968,019 字节，items 占 13,930,232 字节。大头为学习回顾题目快照。
- 新策略只对同步 POST 设置 64 MiB 上限；4 MiB 以上或未知大小上传最多同时两条，其他接口保持 16 MiB。缺少 Bearer 的大请求在读正文前拒绝，身份验证仍由原 guard 完整执行。
- 繁忙返回 503 与 Retry-After，413/完成请求仅记录字节数与状态，便于核对实际包大小。无用户正文写入新日志。
- 保留客户端提交的完整学习内容，不清空云端记录或客户端队列。此兼容修复不等于客户端快照体积已经优化；大记录仍会影响带宽、同步耗时与后续存储增长。
