# 2026-10-21 服务器空间、同步与基础监控

本记录是本次任务证据，不新增长期规则。用户授权处理磁盘空间、同步失败和基础监控；iOS/Android 安装包不变。告警仅保留在服务器。

## 磁盘

- 初始系统盘约 59 GiB，使用率 97%，可用 2,045,825,024 字节。
- Docker 镜像账面 37.86 GB，包含多次 API 和 Ops 候选/回滚版本；账面大小存在共享层，不能直接加总作为可回收空间。
- `/opt/icao/runtime` 约 6.0 GiB（其中 Supabase 4.9 GiB），备份约 3.2 GiB，日志约 0.28 GiB。
- 清理只移除 14 个更早发布镜像，保留所有容器引用、API 与两种 Ops 镜像各最近两代旧版本。未删除备份、数据库、Storage 或用户数据。
- 获取全局发布、API 发布与 Ops 发布锁后，再次核对标签与 image ID，以非 force 的 `docker image rm` 删除明确标签。
- 第一轮清理后可用 8,174,993,408 字节，实际回收 6,129,168,384 字节（约 5.71 GiB），使用率 87%。保留镜像均重新验证存在。
- 继续核对到无标签、无容器引用且超过一天的历史构建中间镜像，分批以非 force 删除，并在每批之后验证全部有标签镜像仍存在。第二阶段及后续中间层清理分别回收 3,638,673,408 与 11,957,714,944 字节。
- 清理结束可用 23,769,231,360 字节（约 22.14 GiB），使用率 61%；相比初始可用空间净增加约 20.23 GiB。Docker 镜像账面从 37.86 GB 降至 16.14 GB。
- 生产原始清单和结果：`/opt/icao/backups/storage-cleanup-20261021/{inventory,result}.json`，root-only。
- 未通过删除必要回滚或备份来降低占用；后续增长由基础监控继续记录。本轮不扩盘或购买资源。

## 同步

- 初次调查最近 24 小时 `/v1/sync/push` 出现 720 次 413。未把请求次数当作受影响人数。
- 线上 API 原 bodyLimit 16 MiB；只读统计发现单条 session 学习记录最大 13,968,574 字节，其中 studyReview 占 13,968,019 字节，items 占 13,930,232 字节。大头为学习回顾题目快照。
- 新策略只对同步 POST 设置 64 MiB 上限；4 MiB 以上或未知大小上传最多同时两条，其他接口保持 16 MiB。缺少 Bearer 的大请求在读正文前拒绝，身份验证仍由原 guard 完整执行。
- 繁忙返回 503 与 Retry-After，413/完成请求仅记录字节数与状态，便于核对实际包大小。无用户正文写入新日志。
- 保留客户端提交的完整学习内容，不清空云端记录或客户端队列。此兼容修复不等于客户端快照体积已经优化；大记录仍会影响带宽、同步耗时与后续存储增长。
