# 网站 OPI 音频修复

## 用户确认的范围

仅修复 readyoufife.com。用户选择完整修复：复用已发布的 1,067 道题音频，
补齐新增 1,167 道题，网站全部使用真实音频文件。保留 App 当前播放方式；不修改冻结 Vercel。

## 已确认的原因与实现

- 当前线上 OPI v17 有 2,234 道带 audioText 的题，均与仓库源文本一致。
- 其中 1,067 道与 v13 音频文本完全一致；数据库 ready 记录和私有 storage 对象均仍存在。
- 当前题目没有 audio 字段，网站进入系统朗读分支。内置浏览器可能不支持朗读，
  自动播放限制和浏览器朗读回调也可能造成错误或无声状态。
- 网站用题目 ID 与完整文本 SHA-256 匹配音频，通过已有 useQuestionBankAsset 获取授权地址，
  继续使用 study 播放会话；不增加播放器、公共音频桶或平行缓存。
- 网站 OPI 提供手动播放入口，等播放器状态确认后显示播放中；不再回退系统朗读。
- Native 使用空录音映射适配器，仍走原来的 expo-speech。
- 新增音频均不属于免费话题，可通过已有资源权限逻辑授权；无需 API 部署或数据库迁移。

## 生成与发布

用户于 2026-10-11 明确要求使用 Mac 本地朗读，不使用腾讯云，并要求继续完成网站修复。
`tools/generate-opi-recordings.mjs` 使用已安装的 Samantha 英语音色（165 词/分钟），
转成单声道 24 kHz、64 kbps MP3；按文本和合成参数保存可续跑缓存。
每个文件完成解码、时长和非静音检查后才进入清单；MP3 源文件和哈希清单一并纳入 Git。
旧音频只引用既有发布对象，不重新生成。

发布先通过 PR 合入 origin/main；从干净 main 使用现有内容导入脚本导入仅资源发布包
（banks 为空，不修改题库版本），再部署 readyoufife.com 的 EdgeOne 网页。
不部署 Native、Vercel 或 API，不执行数据库迁移。

最终验收：全部 2,234 个 ID/文本/音频对应关系、线上旧题和新增题可播放，暂停/继续/重播正常。
手机实机效果需用户在自己的浏览器确认。
