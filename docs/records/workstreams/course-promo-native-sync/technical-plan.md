# 体系课程宣传内容原生同步技术方案

状态：已确认并执行

更新时间：2026-07-23

## 方案

- 建立 `CoursePromoCatalog` 强类型快照，集中保存来源元数据、Hero、指标、优势、课程分类、课程详情、权益与联系方式。
- 将课程页从综合内容组件拆为独立 `CourseCatalogScreen`，原路由只切换组件，不改变公共导航接口。
- 页面使用一个原生纵向 ScrollView；Hero 按钮通过记录区块位置滚动到优势或培训模式。
- 分类使用横向可访问 Tab；默认暑期小班，只渲染当前分类课程卡。
- 课程详情使用现有 Bottom Sheet，固定底部咨询按钮，内容区展示标准说明、分组课纲和可选权益。
- 咨询按钮关闭详情并滚动到页尾；微信号使用 `Text selectable`，不新增原生依赖。

## 视觉

- 使用暖白、墨蓝、钴蓝语义令牌和现有 serif/sans/mono 字体角色。
- 复用现有大圆角轻边框卡片、原生顶部栏、按钮、标签和 Bottom Sheet。
- 信息层级来自宣传页，但布局保持移动学习 App 的紧凑原生形态，不复刻桌面营销站。

## 不采用

- 不使用 WebView 或 iframe。
- 不直接解析线上 HTML/chunk 作为运行时数据。
- 不新增远程课程 API、缓存、失败重试或支付链路。
- 不引入 Clipboard 或其他原生依赖。
