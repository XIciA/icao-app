# 笔记输入与标签编辑入口修复

日期：2026-10-05

本记录用于后续发版交接，不是长期规则。原先“仅网站修复、以后提醒 APP 同步”的要求已被三端同步修复替代。

## 原因与修复

- 正式 EdgeOne 网站通过既有模块映射复用 Native 学习页面。笔记 TextInput 的受控 value 原来直接取异步持久化结果，输入期间的旧回传可能恢复旧文字、干扰中文输入及连续编辑。
- 在同一工作台增加按会话、题库和题目隔离的短期输入草稿。每次输入立即显示，同时继续调用原来的保存接口；离开输入框后，只有最后一次保存已经结束、没有保存错误且存储内容一致，才释放草稿。切题不会带入上一题草稿，保存失败保留原重试入口。不新增存储、队列或云同步所有者。
- 标签/高亮列表中的管理笔原来位于横向 ScrollView 尾部，名称较长时滚出可视区。管理笔移到滚动区域外并禁止收缩，只有标签列表滚动。
- 不改回答、AI、音频、账户、数据库或旧 Vercel 实现。

## 验证

- 聚焦测试覆盖中文输入的连续文本更新、旧保存回传、删除、失焦、相同文字的不同保存请求、保存失败与重试、切题/新会话、原有标签管理和学习退出保存。
- 真实 Chrome 中以 390px/1280px 视口渲染实际标签组件和笔记草稿 hook + React Native Web TextInput；验证固定编辑笔可见且可点击、标签选择、快速键入、composition 事件、换行、删除及延迟保存。系统输入法真实候选窗未由自动化操作，仍需用户设备体验验收。
- 原工作目录的无关修改保留；修复在独立 worktree 完成。
