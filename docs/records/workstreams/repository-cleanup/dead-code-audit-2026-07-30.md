## 判定标准

只有同时满足以下条件的内容才进入本次删除：

1. 不在 Expo Router、Metro Web/Native、Vercel 路由、Nest 模块、测试或脚本入口链中。
2. 全仓无有效引用，或已有明确的新实现接管。
3. 删除不改变当前 iOS、Android、Web、API、题库和本地数据兼容行为。
4. 历史证据保留在 workstream 或 Git 历史中。
