# 听力题库去重需求
状态：已由用户明确开始执行；2026-10-14。

## 已确认决策
- 按英文原文（包含问题）相似度严格 >92% 判重，不附加选项、问题或正确答案一致条件。结合最新1612题及截图指定题，删除110题，保留1502题。
- 删除被删题的用户笔记、标注、高亮、标签关联、作答和学习状态，以及实际存在的收藏/错题关联；不把这些记录转移到保留题。
- 普通混合练习历史只清理被删题部分，保留有效部分；没有有效题目则删除该历史。
- 包含被删听力题的整场模拟考试历史及其关联记录删除；其他考试保留。
- 用户明确开始执行后，授权必要的生产数据清理和正式API/题库发布。
- 不更新App：复用现有同步协议。允许本机保留无笔记、无答案、无学习进度的空状态条目；清理在账号联网同步后完成。未登录、一直离线或尚未刷新内容的设备暂保留旧副本，用户已接受此范围。

## 边界
只处理明确删除清单中的听力题及直接关联记录；不清空用户全部学习数据，不改变其他题库、账号、会员、订单、点数、独立单词记录及全局标签定义。
不上传TestFlight、不构建或发布iOS/Android安装包、不提交商店审核。Vercel继续冻结，不改动其旧快照。当前方案不要求部署新的EdgeOne前端代码。
受影响的本地录音不属于云端同步，现有App无法保证远程物理删除；不将此项列为无需更新App方案的完成标准。

## 验收
上线新题库不存在已冻结删除ID；账号同步后被删题不出现在有效学习状态、标注列表或历史回顾；重放离线写入不得恢复这些内容；保留题记录及其他模块保持完整。数量、目录、免费访问范围和模拟考试出题引用一致。
