# 03｜模拟考试

2026-09-10增补：本轮用户实测后的最新修正及验证边界见[十二项反馈修复](../testflight-feedback-fixes.md)，相应旧描述以该增补为准。学习记录已改为普通可编辑题包，实际再练另存新记录；Logo内页必须显示圆角，准备学习空间不显示Logo。

## 用户体验与已确认行为

题目来自同一题库，复用学习页面，以考试模式限制操作：显示必要题目与作答能力，不展开参考答案和辅助学习工具。学习资料共用、分次作答与历史只读边界见 [学习记录](03-practice-and-history.md)。

听力按顺序进行，不允许回到上一题修改答案。允许当前题不作答直接进入下一题；依次经过20题并提交后立即进入听力成绩页面，展示分数与等级，不等待整场考试结束，也不要求20题全部有答案。未答题不得分，实际作答数量如实显示。有后续模块时成绩页允许继续或结束；只选听力时成绩页就是本次结束状态。不得通过题目目录、滑动或返回操作绕过前题锁定。成绩揭晓不重置或修改原作答。

```text
听力依次经过20题（允许未答）→ 提交听力 → 听力成绩页（分数、等级）
                              ├→ 有后续模块：继续，或结束并保存
                              └→ 仅选听力：本次结束并保存记录
```

本轮功能决策已收口，尚未实施。成绩页结束时保存同一场考试记录，继续时不生成另一场考试；必要页面按已确认内容和现有App组件适配，不再继续逐张选稿。

## 已确认的入口与考试操作

- 入口默认读取个人资料中的备考目标，允许临时切换本次考试类型，不自动修改个人资料。
- 当前考试类型对应的板块默认全部勾选，用户可以取消勾选，自选参与的板块。自选板块仍按已确认顺序及各模块规则组卷。
- 进入新题后，题目音频自动开始播放。所有模块均不允许用户主动重播、暂停、拖动进度或调整倍速。录音重录不代表可以重新播放题目音频。
- 来电中断当前题目音频后，允许该题重新播放一次，作为中断恢复例外；不提供普通重播能力，也不扩大为任意退出再进入即可重播。
- 所有模块顺序进行，不能返回上一题或通过目录任意跳题；允许当前题未作答直接进入下一题，并保留未作答状态。不提供上一题与目录跳转入口，滑动等操作也不能绕过。
- 当前题允许重新录音，但不允许回听当前录音。进入下一题后不能返回重录。
- 未经过完整听力流程即提前结束，仅显示“未完成”和实际作答数量，不给出完整分数或等级。依次经过20题并提交但存在未答题，不属于该提前结束情形；其余记录仍按已确认的保存规则处理。
- 听力成绩页仅展示分数、等级及作答概况，提供继续考试或结束考试的路径；逐题答案统一到只读历史查看，不在成绩页插入逐题解析。
- 听力完成后再结束整场，保留已获得的完整听力成绩，整场其余模块如实标记未完成，不能将听力成绩冒充整场成绩。

## 已确认的抽题与计分规则

以下抽题来源、数量、顺序、计分与等级换算为已确认的产品目标，不等于官方考试标准或当前Native已实现。

| 模块 | 已确认规则 |
| --- | --- |
| 听力 | 10秒航空英语、10秒陆空通话、20秒航空英语、20秒陆空通话，各抽5题，共20题；每类从其首个题组抽取 |
| 900句：4初考 | 3级抽8句、4级抽4句，共12句，每4句一组 |
| 900句：5初考 | 在上述基础上加5级8句，共20句，每4句一组 |
| 陆空通话 | 从包含15—20题的场景中随机选一个，保留整场景及原题顺序 |
| OPI | 从至少有5题的话题中随机选一个，再从该话题抽5题 |
| 故事复诵 | 从“飞行ICAO → 必做题库”抽1题 |

单次抽样无放回；不同场考试可以再次抽到同题。

| 类型 | 已确认模块执行顺序 |
| --- | --- |
| ICAO 4 初考 | 听力20 → 900句12 → 陆空通话15—20 → OPI5 |
| ICAO 4 复考 | 陆空通话15—20 → OPI5 |
| ICAO 5 初考 | 听力20 → 900句20 → 陆空通话15—20 → 故事复诵1 → OPI5 |
| ICAO 5 复考 | 陆空通话15—20 → 故事复诵1 → OPI5；沿用上述各模块抽题规则，Native 需补齐该类型 |

听力计分：前10题每题2分，后10题每题3分，满分50分。等级换算：0—20分为2级、21—24分为3级、25—40分为4级、41—45分为5级、46—50分为6级。页面明确为听力模拟成绩与等级，不表述为官方认证或整场考试等级。

选择选项后点击“下一题”锁定本题；当前题提交前允许更正误触，进入下一题后不能返回修改。第20题使用“提交听力”，提交后直接进入成绩页，不增加全卷检查改答步骤。

## 补充确认与简化边界

900句逐句播放、逐句录音，每4句仅为组卷分组。正式进入考试并提交，即使全部未答也保存记录；听力走完20题并提交按既定规则计分，未答为0分。尚未进入有效题目即退出、加载失败不生成空记录。

来电后由用户准备好再明确启动该题允许的一次重播。未实际播放成功的加载失败允许重试；其他中断尽可能恢复原进度，不自动从头重播。无法恢复或再次中断时，可按未答继续或结束，保留已可靠保存内容；不为少见情况建立复杂恢复体系，不把未保存录音承诺为可恢复。后台切换和恢复不构成另一次考试，不重新抽题。

## 已确认的页面收尾规则

- 全部板块取消勾选时禁用开始并简短提示至少选择一个，不擅自重新勾选。
- 只选听力时，成绩页直接作为本次结束页，不显示“继续考试”；未选听力时不显示听力成绩或“听力未完成”。题量和流程状态只按所选板块计算。
- 已走完流程但含未答题可显示已结束/已提交，同时显示真实已答数量，不将流程结束等同全部作答或全部答对。
- 结束反馈仅展示来源、状态、实际作答数量、用时和已有听力成绩，提供查看本次记录及返回入口，不增加复杂总评。只选听力时复用成绩页承载，不再多一层结束页。
- 从结束状态进入本次只读历史，返回原结束状态，不回到已结束的作答现场、不重复保存；从历史列表进入则返回列表原位置。

当前无待确认的功能逻辑项；沿用现有视觉规范，实施验收另行推进。

本文件只规定考试差异，普通题库和热点不套用上述限制。整套关系与视觉范围见 [最终方案总览](../learning-flow-final-plan.md)。

## 后续验收重点

听力第20题提交后才显示成绩与等级，前题锁定不可绕过；继续考试保留听力结果，结束保存同一场记录；后续回看不改变本次作答或成绩。计分与题目顺序必须与最终确认规则一致。

默认全选且可自选，试卷只包含选中的板块。新题音频自动播放，所有模块不能主动重播、暂停、拖动、倍速或回前题、任意跳题；允许未答进入下一题，未答状态和数量准确。当前题可重录但不可回听，重录不会重播题目；来电中断允许当前题音频重播一次。听力未走完流程即结束仅显示未完成与作答数量；走完20题提交后按既定规则计分，未答不得分；已完成听力不因整场提前结束而丢失成绩。
