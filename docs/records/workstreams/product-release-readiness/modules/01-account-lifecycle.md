## 1. 范围与证据状态

本模块合并原先的首次进入/登录和个人资料/设置讨论：必要启动加载、验证码/密码/Apple/微信登录、资料修改、备考目标联动、账号安全、隐私与数据、帮助、退出和注销。意见反馈在此确定我的中的固定入口，内部流程以已确认的 [08 意见反馈与题目纠错](08-feedback.md) 为准；题目纠错复用同一表单并携带题目上下文，不另建反馈系统。

不在本模块决定会员购买方案、微信支付方案、题库练习细节、收藏标注学习记录升级或 AI 模拟考试重写；它们仅承接统一账号和相应数据边界。

跨模块更新：AI 展示与权益规则以 [02 会员与购买](02-membership-ai-and-purchase.md) 最新确认内容为准。“我的”个人资料卡下、功能列表上增加唯一不可点击的 AI 额度卡，不增加设置或隐私中的额度入口。本文旧称“剩余AI点数”在新方案中对应服务端剩余AI额度；清空学习数据不重置或返还额度，不因此继续采用旧长期累计点数模型。微信绑定冲突以 [04 微信接入](04-wechat-integration.md) 已确认的不自动合并、不覆盖、不切换账号原则为准。

用户截图和实测报告：Apple 登录后可进入 App；单设备退出可用，全部设备退出失败；未同意条款出现红字，勾选后截图中仍有红字；个人资料与编辑字段不对应；头像编辑角标有裁切；设置含多处重复入口及技术说明。这些是现象，不是服务端根因结论。

截图显示旧版资料含 ICAO 4/5/6 级、性别、地区、签名；这些不作为目标方案。截图显示导出等按钮，不代表完整功能已验证。本文所有未来要求均须在执行前结合实际代码核验，不能引用旧 Agent 报告作为验收通过。

## 已确认的核心视觉方向

用户明确选择 **A 的登录＋B 的个人资料和设置**。具体参照与生成偏差见 [核心页面视觉记录](../assets/01-account-lifecycle/README.md)。登录采用 A 左侧图；资料和设置采用 B 中间、右侧图。保持同一品牌、字体与组件尺度，功能仍依本文要求；不是照搬生成图中的额外文字、区号下拉箭头或失真的品牌细部。当前仍为决策阶段，未实施。

```text

└─ 未登录 → 登录/注册
   ├─ 手机验证码（默认）
   ├─ 手机号＋密码 → 忘记密码
   ├─ Apple / 微信（按平台与实际可用能力）
   └─ 条款确认、用户协议、隐私政策

App
├─ 题库：首页左上角仅显示头像，不可点击
│  └─ 按备考目标展示相应题库
└─ 我的
   ├─ 顶部头像/昵称 → 个人资料（唯一入口；展示编辑合并）
   │  ├─ 头像
   │  ├─ 昵称
   │  ├─ 备考目标
   │  └─ 账号 ID（只读，可复制）
   ├─ AI 额度卡（个人资料卡下、功能列表上；唯一展示，不可点击）
   ├─ 会员与购买 / 学习记录 / 我的标注 / 单词收藏（其他议题）
   ├─ 设置
   │  ├─ 账号安全（唯一管理入口）
   │  │  ├─ 手机号：绑定 / 更换
   │  │  ├─ 登录密码：设置 / 修改 / 找回
   │  │  ├─ Apple / 微信绑定管理
   │  │  └─ 注销账号（底部入口）
   │  ├─ 隐私与数据
   │  │  ├─ AI 数据处理授权
   │  │  ├─ 删除全部 AI 结果
   │  │  ├─ 清空学习数据
   │  │  └─ 用户协议 / 隐私政策 / 第三方服务清单 / 隐私权利联系
   │  ├─ ASR 模型设置（现有编号与调试说明暂时不动）
   │  ├─ 其他
   │  │  ├─ 帮助中心（Q&A）
   │  │  └─ 关于听你五个（唯一入口；图标、名称、版本、公司主体、App备案查询）
```

层级表达入口归属，不规定最终像素布局。静态信息不画成可点击按钮；不额外给设置添加无必要的头像区。协议阅读使用统一内容来源。

## 3. 使用流程图

```text
启动 → 必要加载 → 联网确认登录与账号状态
                    ├─ 有效 → 题库首页
                    ├─ 网络不可用 → 保留登录，提示连接网络，恢复后自动重试
                    └─ 无有效登录 → 登录页
登录页 → 选择登录方式 → 必要条款确认 → 发起验证
                                      ├─ 取消/失败 → 原登录页，保留适当输入，可更正/重试
                                      └─ 成功 → 进入同一业务账号 → 题库首页
密码登录 → 忘记密码 → 验证已有手机号 → 重设密码 → 进入已验证账号
协议阅读 → 返回 → 原登录页，保留模式与输入，不自动同意

我的 → 个人资料 → 编辑字段 → 保存 → 返回资料，更新关联展示
                            └─ 取消/失败 → 不误报已保存，允许返回/更正
             └─ 修改备考目标 → 保存 → 首页题库按目标更新

我的 → 设置 → 账号安全 → 绑定/更换/密码操作 → 必要身份验证
                                             ├─ 成功 → 原账号安全页更新状态
                                             └─ 取消/失败/身份占用 → 保持原账号与绑定
             ├─ 隐私与数据 → 授权管理/明确范围的数据操作 → 真实结果
             ├─ 帮助中心 → 展开 Q&A → 返回
             └─ 退出登录 → 确认 → 当前设备退出 → 登录页
                           └─ 取消 → 设置

账号安全 → 注销账号 → 简短后果说明 → 验证已有身份 → 明确确认注销
                       └─ 取消/验证失败 → 不删除账号，返回
完成提交 → 处理结果
           ├─ 已完成 → 清除当前账号会话与对应本机数据 → 登录页
           └─ 失败/结果不确定 → 如实提示，允许安全查询/处理，不冒充已完成
```

本图中的细分反馈采用第 11 节建议边界，不表示所有提示文案、对话框顺序已完成视觉确认。

## 4. 启动与登录要求

| 编号 | 已确认行为 |
| --- | --- |
| ACC-L01 | 未登录不允许浏览 App；无游客模式。只保留必要启动加载，不增加需要点击“开始使用”的欢迎页 |
| ACC-L02 | 已有有效登录经启动联网确认后直接进入 App；正常登录成功进入题库，不强制补资料或选择备考目标 |
| ACC-L03 | 默认手机号验证码登录：手机号框、验证码框，验证码框右侧获取验证码，统一登录按钮及条款区域；可切换手机号＋密码 |
| ACC-L04 | 下方圆形第三方快捷登录包含实际可用的 Apple、微信；不能只显示按钮而没有完整登录能力；实际平台可用性与品牌展示约束需核验 |
| ACC-L05 | 验证码验证后的新手机号可创建账号；密码登录与找回密码不能将未知手机号静默注册 |
| ACC-L06 | 第三方登录不强制绑定手机号；可在账号安全添加其他方式。不同登录方式必须围绕同一业务账号协同 |
| ACC-L07 | 保留满 16 周岁及协议的明确确认，不预勾选。未同意时尝试受此约束的操作，使用简短明确确认而非插入常驻红字；同意后继续原动作，取消留在原页；已同意不重复确认 |
| ACC-L08 | 删除“继续你的 ICAO 备考进度”、独立自动注册解释段、第三方无需绑手机长解释；通过登录/注册等必要文案表达功能，不损失必要告知 |
| ACC-L09 | 用户协议和隐私政策阅读方式暂时保留，后续再讨论；打开/返回保持登录上下文，阅读不等于同意 |
| ACC-L10 | 验证码、密码、第三方取消/失败/超时、重复点击、冷启动回调等纳入同一闭环检查，不新增无限制验证码白名单 |
| ACC-L11 | 密码找回承接已有手机号身份；登录前完成重设后进入已验证账号，账号安全内发起则回到安全管理上下文，不要求先退出再找回 |

手机号在模式切换时保留；不适用的敏感输入应适当清理。第三方账号与手机号属于不同现有账号时不得自动合并；提供不丢失现有权益与数据的处理路径，具体冲突文案后续确认。

## 5. 个人资料与备考目标

- ACC-P01：我的顶部是唯一资料管理入口；首页左上角保留头像但取消点击，不提供箭头、编辑角标或按压反馈。
- ACC-P02：独立展示页与编辑页合并。采用一个资料管理页，字段编辑后保存返回并更新显示，不重复增加整页保存或“我知道了”。具体字段编辑容器复用现有组件，由实施时按简洁及导航原则选择，不再另设界面稿确认门槛。
- ACC-P03：保留头像、可修改昵称、备考目标和只读账号 ID；删除性别、地区、个性签名；手机号不在个人资料展示或管理。
- ACC-P04：头像可设置；我的、资料、题库首页等现有头像展示处使用同一资料。保存失败不能显示成功；图片加载失败应有正常占位，不能出现裁切残缺的编辑图标。
- ACC-P05：资料随账号保持，重新进入、重启、跨设备和切换账号应正确；不得依赖与账号无关的全局资料导致串号。
- ACC-P06：首次默认 ICAO 4 初考，不弹出强制选择；用户以后可自行更改，后续登录不覆盖其选择。

### 唯一备考目标与题库映射

| 备考目标 | 首页展示题库，按以下顺序 |
| --- | --- |
| ICAO 4 初考 | 听力、900 句、陆空通话、OPI |
| ICAO 4 复考 | 陆空通话、OPI |
| ICAO 5 初考 | 听力、900 句、陆空通话、OPI、故事复诵 |
| ICAO 5 复考 | 陆空通话、OPI、故事复诵 |

这四个选项替代旧 ICAO 4/5/6 级；名称采用 ICAO，不沿用口述中的 Echo。切换只改变首页展示，不取消合法会员限制，不删除历史学习数据。题库内部呈现另议。

## 6. 账号安全

- ACC-S01：唯一固定入口为“我的 → 设置 → 账号安全”；隐私页不再复制此入口。
- ACC-S02：手机号一行按状态显示绑定或更换，已绑定号码脱敏；密码一行按状态进入设置、修改或找回，避免把全部操作同时平铺。
- ACC-S03：手机号密码依赖已验证手机号；仅第三方登录用户不因普通使用而被迫绑手机。设置密码所需条件在用户操作时解释。
- ACC-S04：Apple、微信可用方式的绑定/解绑与登录协同；至少保留一种可用登录方式。验证用户已持有的身份，不让未绑定方式成为随意替代验证手段。
- ACC-S05：换绑先完成必要验证再变更；取消、失败、号码或第三方身份占用时保留原账号、原绑定、会员和学习数据，不自动切换或合并账号。
- ACC-S06：删除会话存储“本机加密”等用户无需操作的展示项，保留底层安全。普通退出不再有退出全部设备；密码安全与注销所需的会话失效能力不能因此误删。
- ACC-S07：注销统一放此页底部，入口低频但易找到，不散落到隐私页或隐藏在长协议中。

敏感验证应共享交互与业务能力，但绑定、找回、退出与注销的验证目的不能混用。取消验证不得撤销 Apple/微信绑定或注销账号。全部设备退出失败和截图中的 Apple 撤销通知不能仅凭时间相邻认定根因；后续需核验相关验证调用，不能仅删除按钮就宣称安全问题已修复。

## 7. 设置、隐私、帮助与反馈

### 设置精简

ACC-T01：按第 2 节结构保留账号安全、隐私与数据、ASR、帮助中心、关于听你五个及退出登录。设置原“帮助”分组改为“其他”，包含帮助中心和关于听你五个。更新、评分、分享功能仍删除，不换位置保留。

### 产品身份信息集中展示（2026-09-10 用户已确认，代码已实施、待真机验收）

- 唯一入口为“我的 → 设置 → 关于听你五个”；我的不新增直接入口。删除我的、设置底部散落的产品名称、版本号、版权小字和备案信息。
- 关于页按顺序展示：统一来源的 App 图标、听你五个、Read You 5、当前安装版本、开发及运营主体、App 备案号。
- 开发及运营主体显示全称“云启航科（成都）科技有限公司”；执行时核对真实主体，不将简称代替公司全称。
- 版本读取当前安装版本，不写死 1.0.0。App 备案号为“蜀ICP备2026045996号-1A”，不得使用网站备案号 -2。
- 备案号以正常可读字号直接展示，不折叠；点击进入 https://beian.miit.gov.cn 查询。其他身份信息静态展示，不增加箭头或独立详情页。
- 不增加检查更新、评分、分享、二维码或“我知道了”按钮。用户协议、隐私政策等入口继续归隐私与数据，关于页不重复；协议正文的主体披露保留。
- 该页可用于展示真实 App 与公司主体关系，但不承诺微信支付审核通过，也不替代独立的应用市场上架证明。
- 本决定替代此前“删除整个关于页、版本备案保留设置底部”的方案；只恢复有明确身份信息用途的关于页，不恢复原宣传及推广功能。用户随后授权实施，关于页面、单一设置入口及旧页脚清理已完成代码修改；不代表已发布或真机验收。

ACC-T02：帮助中心保留现有 Q&A 方向，问题可展开查看；答案须符合实际能力。独立意见反馈继续位于“我的”中设置项下方，不与帮助中心合并，不在帮助内复制反馈入口。不新增聊天客服或消息中心。

ACC-T03：ASR 模型选项、编号和调试说明本轮明确暂不改动。技术编号不是普遍保留原则，此处是用户明确例外。

### 隐私与数据

| 编号 | 功能 | 效果边界 |
| --- | --- | --- |
| ACC-D01 | AI 数据处理授权 | 可撤回及以后重新明确同意；撤回停止后续相关上传/处理，不自动删除已有结果，不影响无需 AI 的功能 |
| ACC-D02 | 删除全部 AI 结果 | 明确删除对象，保留其他学习数据；与单条结果删除的后续学习记录流程保持一致 |
| ACC-D03 | 清空学习数据 | 清除学习进度、作答、记录、收藏、标注、笔记、AI 结果、本机练习录音和播放进度；保留范围见下文；不增加多选清理面板，不写成“清缓存” |
| ACC-D04 | 用户协议、隐私政策、第三方清单、隐私权利联系 | 内容与实际功能一致，共享阅读内容；隐私权利联系用于对应权利请求，不另造普通反馈系统 |
| ACC-D05 | 删除数据导出 | 完全删除用户导出入口及专用功能代码、对应专用接口/测试/说明；仅在核验专用归属后删除，不误删共享读取、同步、备份能力 |

用户在只读盘点后已明确同意完整清空范围，尤其收藏、笔记、录音一并删除。同步学习文档中承载的上述数据同属清空范围，不扩大至无关业务数据。

- ACC-D06：保留账号、登录方式、头像昵称、备考目标、会员、剩余 AI 点数、订单及设置；清空学习不返还已消耗点数。这不是注销账号，不改变注销的后果约定。
- ACC-D07：清空必须联网完成；服务端未确认时不只清本机并报成功。云端完成但本机清理失败时，如实说明仍有清理待完成，恢复后继续；结果未知时安全确认原请求结果，不能盲目重复删除。
- ACC-D08：其他设备下次联网同步时完成对应学习数据、录音与播放状态清理；离线设备无法立即收到结果，不承诺即时远程擦除。旧离线数据不得重新恢复已清空内容。

确认文案须明确包括录音，不能只列统计、收藏而漏掉实际删除对象。注销与数据删除的必要信息不可因简洁原则省略。

## 8. 自动同步与退出

- ACC-Y01：删除手动同步按钮及面向用户的同步设置/详情入口，直接自动同步。登录、本机修改、网络恢复等场景自动推进，不要求用户理解同步机制。
- ACC-Y02：正常使用无同步弹窗；本机可靠保存与云端已同步不是同一结果，不假报成功。真正需要用户处理时才提示必要动作。
- ACC-Y03：原账号未同步内容不得上传到另一账号。切换、清空和注销不能造成数据串用或被自动同步重新恢复。
- ACC-O01：设置仅显示“退出登录”，作用于当前设备；取消返回设置，完成后进入登录页，返回不能绕过登录限制。
- ACC-O02：普通退出不需要 Apple/微信二次授权。存在未同步内容时先做有上限的自动同步；仍有残留则提供取消或继续退出的简短提示，不增加“手动同步后退出”按钮，不无限等待。
- ACC-O03：继续退出时保护原账号隔离的本机待同步数据；重新登录相同账号后才能按其身份处理，不使用下一账号上传。退出不等于注销，不删除云端学习与权益。

### 已确认：断网与登录过期

- ACC-N01：本轮启动需要联网确认业务账号。断网重开 App 时提示连接网络，保留原登录状态，网络恢复自动重试；网络故障与本机安全存储异常分别提示，不把两者统称账号失效。暂不新增完整离线启动能力。
- ACC-N02：已进入 App 后短暂断网，已加载且可本机完成的内容继续使用、可靠保存；需要网络的功能在相关位置提示，网络恢复自动同步。普通断网不把用户踢回登录页，不承诺所有题库和音频均可离线使用，也不绕过会员权限。
- ACC-N03：凭证到期优先自动续期；只有明确确认登录失效才要求重新登录。续期时网络失败不等于账号失效，不因此清除已保存内容。
- ACC-N04：重新登录后返回原来安全且仍有效的页面；不能恢复则回题库首页。保留可靠保存的学习内容，不承诺未保存的录音/答案现场完整恢复，不自动重复提交、购买或删除。
