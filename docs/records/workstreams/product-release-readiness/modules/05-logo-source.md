## 已确认方案

- 主图为完整不透明正方形，蓝色背景铺满四边及四角，不含外围白边、预制圆角外框、外部投影；主体内部立体明暗可保留。
- 保留已确认源稿的品牌主体、两道波纹及图像内容。此前“清理波纹尖端杂影”属于源稿确认前的制图要求，现仅作历史记录，不是后续继续修图的任务；正式资源只从已确认源稿引用或按平台要求派生，不自行修图或重绘。
- 原有带白边版本不删除，定位为备份或视觉参考；后续统一执行时从正式来源退役并明确命名，不能继续与新稿竞争成为正式来源。
- 唯一来源指一个权威品牌图稿；允许由它产生平台需要的尺寸及适配资源，不独立重绘另一套 Logo。平台派生资源不是第二个设计来源。
- iOS 由系统处理桌面外轮廓；Android 需正确处理自适应裁切和主体安全区域，不能假定单张 PNG 就已经完成所有平台适配。
- App 内 Logo、启动图标、桌面图标等正式品牌引用在后续实施时一起核查；不能为了内部展示重新把白边写回桌面主图。
- 全项目统一是目标，不解除冻结网页的边界：Vercel、宣传网站等现有独立资源先列入引用清单，未经相应修改授权不直接更改或部署。
