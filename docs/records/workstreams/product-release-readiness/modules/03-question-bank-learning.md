# 03｜普通题库学习

状态：2026-09-09，本轮功能决策已确认；以保留现有完整刷题体验并接入统一记录为目标，尚未实施或验收。

## 用户体验与操作流程

用户登录进入 App 后，在题库首页选择适合备考目标的模块和题组，按现有方式学习。可以查看答案、使用该题型已有的播放、录音、AI、查词、笔记、标签和标注能力。完成或手动结束后自动保存这次学习，以后在“我的 → 学习记录”回看。

```text
题库首页 → 选择模块及题组 → 完整学习页
                              ├→ 题目播放／作答／查看答案
                              ├→ 使用现有学习工具
                              ├→ 上下题／既有目录
                              └→ 完成／结束／主动离开
                                            ↓
                                  保存本次记录与实际结果反馈
                                            ↓
                                  我的 → 学习记录 → 只读回看
```

## 首页与备考目标

新账号默认 ICAO 4 初考，不强制选择；之后在个人资料更改。四种目标展示范围与顺序的唯一详细定义见 [账户使用全流程第5节](01-account-lifecycle.md)：4初考显示听力、900句、陆空通话、OPI；4复考显示陆空通话、OPI；5初考在4初考基础上增加故事复诵；5复考显示陆空通话、OPI、故事复诵。

普通首页展示顺序与模拟考试执行顺序分别遵循对应模块，不能将模考“故事复诵在OPI之前”的规则反过来改变首页顺序。资料目标变化不删除历史或绕过会员权限；模考临时选择也不反改个人资料。

## 本轮保留和改动边界

| 编号 | 最终行为 |
| --- | --- |
| BANK-01 | 普通题库保留完整学习模式，按现有题型提供功能，不套用模拟考试的禁止重播、禁止回前题等限制 |
| BANK-02 | 不重新设计普通学习页，不新增题型、独立题库或学习辅助功能；复用现有布局，完成必要的状态与数据衔接 |
| BANK-03 | 同一道题跨普通题库、热点和模考仍保持唯一身份；期次和试卷组织不切断笔记、标签、标注的关联 |
| BANK-04 | 本次回答与既有学习进度区分，不将之前的作答或AI结果冒充本次记录；保存和AI归属按学习记录HIS-13—15 |
| BANK-05 | 完成、结束或主动离开后保存同一次记录；仅切后台或打开辅助页面不结束。实际学习、空记录和恢复规则按HIS-09—10 |
| BANK-06 | 沿用普通模式现有答案反馈方式，不将模考听力20题统一公布成绩的限制扩展到普通学习 |
| BANK-07 | 会员权限与AI额度沿用同一账户能力，不因为从题包进入就绕过限制或另算一套额度 |

本轮普通学习保存实际学过的题；用户只阅读、播放也可以形成学习记录，不强制有文字回答。具体保存内容、历史不存录音、删除及自动同步以 [学习记录](03-practice-and-history.md) 为准，不在本模块另设规则。

## 验收要求

- 四个备考目标的首页模块及顺序与账户方案一致，切换不会丢失历史。
- 普通学习的既有答案、播放、录音及辅助工具正常，模考限制没有误应用。
- 同题在普通题库与热点中的共享资料一致；修改资料后历史只读入口正确反映当前状态。
- 结束保存的是本次实际学习及独立回答，不夹带此前回答，不保存周围整本题库。
- 反复点击结束或返回不会生成重复记录；保存失败有真实反馈和可靠内容保留路径。
- 历史回看不能编辑或再次调用AI，不因回看增加学习次数。

跨模块关系和最终验收场景见 [最终方案总览](../learning-flow-final-plan.md)。现有收藏、标注等功能若另有专项升级，另行讨论；本轮不借“完整学习模式”擅自增加功能。
