# 03｜OPI 热点

## 用户的核心体验

用户选择某一天的考试资讯，进入由相关话题和题目组成的 OPI 题包，使用与普通 OPI 题库完全一致的页面与刷题能力。完成或主动结束后，在统一学习记录中找到这次热点学习并只读回看，能够识别来源期次。

状态：上述产品方向已确认，当前不可用问题待定位，尚未实施或验收。首先保证真实内容可进入、可学习，再完成统一记录闭环。

本模块是 [最终方案](../learning-flow-final-plan.md) 的组成部分；功能决策已完成，故障诊断不属于新的人工产品选择。

```text
OPI 热点列表 → 某日考试资讯及题包 → 普通 OPI 刷题体验
                                      ↓
                              完成／主动结束
                                      ↓
                         统一学习记录 → 只读回看
```

## 已确认的范围与边界

- HOT-01：热点按考试资讯组织相关话题和题目，题目仍来自原 OPI 题库，不复制为另一个独立题库。
- HOT-02：热点题包使用完整普通学习模式，可以展开答案、播放、录音、使用 AI、笔记、标签与标注；能力与普通题库一致，不沿用模拟考试的播放、导航或辅助工具限制，也不绕过现有账号权益。
- HOT-03：同题资料共用当前状态，每次回答与对应 AI 反馈独立；准确语义只在 [学习记录方案](03-practice-and-history.md) 维护，不另建热点数据或历史系统。
- HOT-04：结束后接入统一学习记录，标识来自哪一期 OPI 热点；保存、删除、账号隔离、自动同步、用户录音不进入历史等规则沿用学习记录方案。
- HOT-05：复用普通题库刷题界面，不为热点重新设计一套学习页。列表及期次说明只承担内容组织和进入学习的职责。
- HOT-06：每期采用固定选题与顺序，不因再次进入重新随机抽题。期次详情简短展示话题与题量，统一通过“开始本期学习”进入整包；学习中沿用既有题目目录，不新增每话题独立历史体系。

## 已知问题及待核对

用户截图显示某期详情出现“热点内容暂不可用”，尚不能据此确定根因。后续只读排查期次索引、题目关联、远程内容加载、会员鉴权与错误分类；不能用删除合法权限限制来修复。异常需有准确提示、合理重试和返回路径。

## 验收效果

- 有访问权限的用户可进入有效期次，题包实际题目与期次内容一致；失效关联或加载错误不得伪装为正常内容。
- 同题在普通题库和热点中的展示、学习操作一致，共享笔记、标签、标注，不串账号；模考限制不误用于热点。
- 一次热点学习形成一条来源明确的记录，按普通学习规则保存本次实际学过的题；能回看本次回答与正确归属的 AI 反馈，不被下一次练习覆盖。
- 学习记录仍只读；不增加热点专用历史入口、同步按钮或另一套 AI 历史。

- 2026-09-10：转写与分析直接操作共用普通题库工作台，行为以[普通题库学习方案](03-question-bank-learning.md)“转写与分析直接操作”为准。
