## 联合复核结论

三项方向没有必然冲突，但现有方案需要落实以下边界：

- 微信 SDK 历史说明不等于当前应用免安装授权已成功；先验证官方入口，不仿造页面或私有接口。SDK WKWebView 与苹果建议的 Safari 容器不同，必须如实说明，必要时根据审核反馈再讨论方案。
- CallKit 删除与随身听共用音频会话，先明确唯一中断责任方；普通学习不因此常驻后台，随身听后台能力不能被一起删掉。
- 预取必须有限且不能阻塞当前操作；有缓存不等于有永久播放权限。缓存不能绕过账号和既定会员/离线权限。
- 不以无限静音、计时器或循环重试保活。播放间隔仅服务用户选择的正常听音节奏；长间隔背景行为在真机验证，不承诺任意时长无声保持运行。
- 三项整合到同一个最终候选后回归，不能把分开测试的三个版本当作同一包已通过。正式制品仅来自 origin/main；具体提交/生产操作遵循后续授权。
