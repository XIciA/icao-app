# 统一管理后台：反馈查看与 AI 额度调整

更新日期：2026-09-09。用户已确认业务范围，并采纳本文与02中后台操作细节建议；当前只记录决策，尚未实现或部署。

## 使用效果与结构

管理者使用一个固定后台地址和一套登录，进入后可方便切换两个业务功能：

```text
管理后台（同一登录）
├─ 用户反馈 → 列表 → 全文、图片、联系方式及题目关联
└─ AI 额度调整 → 当前规则 → 修改 → 核对影响 → 保存
```

- 整个后台只展示上述两个业务入口。登录、退出和访问保护属于必要能力，不额外设为业务模块。
- 优先在既有运营后台基础上收简和补齐，不建立第二套管理应用、管理员身份或 AI 配置来源。虽然用户把本轮称作首次搭建，代码已有运营后台基础，事实与交付目标分别记录。
- 已确认采用简洁的顶部双入口切换，不额外增加仪表盘、统计首页、多级侧栏。额度修改预览、生效提示、保存失败保留输入、未保存离开保护和轻量历史恢复按02执行；页面稿只参考布局内容，样式遵循现有组件及视觉规范，不另设选稿前置条件。
- 切换反馈列表与详情只做查看；切换离开有未保存 AI 修改的页面，应提示是否放弃，避免误丢输入。正常切换不重复登录。
- 交付时提供真实可用地址及登录进入方式，不能只提供源码路径或演示稿。

## 两个功能各自边界

| 功能 | 提供 | 不提供 |
| --- | --- | --- |
| 用户反馈 | 清晰查看完整文字、图片、联系方式、题目关联，方便管理者自行外部联系 | 回复发送、状态流转、分派、处理备注、联系记录、结案和统计 |
| AI 额度调整 | 会员周额度、免费体验额度、已有功能消耗规则及已确认的生效、历史恢复能力 | 用户管理、订单管理、会员定价、为各套餐分设不同额度等额外功能 |

详细行为分别以 [08 意见反馈](modules/08-feedback.md) 和 [02 会员与 AI 额度](modules/02-membership-ai-and-purchase.md) 为准。本文件只维护共同后台的入口与范围，不复制一套额度规则。

## 对既有方案的替代关系

- 替代 02 文档此前“仅一个 AI 单功能后台”的业务数量限制：现在为同一后台的两个功能，AI 仍是单一规则编辑页。
- AI 原有视觉稿仅作为表单内容参考；无导航的单功能外壳不能覆盖本轮明确要求的双功能切换。
- 不改变已经确认的 AI 初始额度、消耗、生效时间、历史版本及已有权益保护，不把反馈模块也变成可写工单系统。
- 后台已有其他页面和 API 不代表本轮需要展示；仅收简用户可见业务入口，不因本决策擅自删除安全审计、隐私请求、运维能力或其他底层代码。

验收：同一地址登录后能切换两个功能，反馈可完整查看，AI 能按已确认规则实际保存并生效；离开未保存表单有保护；不存在额外业务入口或自动联系功能。产品决定不等于授权本轮操作生产额度或部署后台。
