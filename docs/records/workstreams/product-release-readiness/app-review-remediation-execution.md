# 2026-09-13 联合整改执行记录

## 范围和授权

用户授权三项主要整改（微信免安装授权、移除 CallKit、随身听后台播放）、两项细节（圆角启动图、重复领取 AI 体验提示）以及并行后台整合。必要 API 迁移和部署、统一 TestFlight 上传在授权内；再次提交 App Store 审核由用户录屏后处理。

## 实现与检查

- 微信：官方 SDK sendAuthReq 的控制器入口，移除未安装时的前置拦截；请求独立管理取消、超时与回调，成功必须匹配 state。原有 Apple 和手机号登录保留。
- CallKit：删除原生导入、框架链接和来电观察，普通中断按统一播放所有权处理；考试被中断可重播，不设置来电重播次数。迟到播放请求只释放自己的租约。
- 随身听：原生队列串行变更，有限后继预取、按请求代次拒绝迟到结果；共享资源缓存短事务提交，下载不阻塞退出或切换；有限重试及明确失败提示。原生准确时长间隔避免后台 JS seek 时序依赖。
- 启动图：只派生启动图透明圆角；不改已确认源图、桌面图标或既有视觉风格。最终生成物与归档仍待核对。
- AI 体验：明确业务原因与网络失败分离，新增 0048 迁移；等待后台 0047 合入后生成连续元数据并部署。

检查：主 App 161 套件、1,067 项测试通过；音频相关 11 套件、105 项联合测试通过；微信/考试与 AI 领取服务有针对性回归。TypeScript、音频架构和 6 项 Web 冻结测试通过。完整 pnpm check 已通过内容、App、合同部分，暂止于尚待 0047 整合的 0048 migration journal；不能记为完整发布检查通过。

独立审查已返修：旧租约释放新请求、间隔改零循环静音、迟到补队列跳错曲、所有权转交漏暂停、自动切歌后下一首索引过期、旧下载挤占新队列缓存。Web 共享输入恢复原样，Native 修复使用既有平台隔离。
