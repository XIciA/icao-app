# 微信免安装授权登录方案

日期：2026-09-13。状态：**方案已确定，尚未实施或真机验收。**

本轮用户仅要求确定方案并写入文档，不授权因此修改业务代码、平台配置、构建、上传或提交审核。后续实施以用户新的执行指令为准。本文件是本次微信免安装登录的集中方案，不是长期规则；覆盖旧讨论中“无微信直接报错”“是否隐藏入口待定”等本场景描述。

## 目标与决策

- iOS/iPadOS 未安装微信时，仍可在 App 内通过微信官方授权机制登录同一个业务账号；不强制安装微信。
- 优先复用已集成的官方 NoPay OpenSDK `sendAuthReq:viewController:delegate:completion:` 入口，验证并接通 SDK 提供的免安装短信授权；已安装微信时保留现有客户端授权。
- 验证手机号、验证码等界面及处理由微信提供；不自制微信登录表单，不截取凭据，不调用未公开接口，不从 SDK 内提取私有网页地址另行拼装。
- 保留 Apple、手机号和密码登录，微信不是唯一入口。沿用现有 App 颜色、字体、组件和账号体系；SDK 内的授权页面由 SDK 管理，不新增应用级 WebView 或第二套登录网站。
- 本决策仅针对 iOS/iPadOS。本轮不改 Android、Expo Web、Vercel 或微信支付。

## 证据与待验证边界

- 本机 SDK README 标为 2.0.7；历史更新记录在 1.5 说明支持未安装微信情况下 Auth，1.8.6.1 说明短信授权切换为 WKWebView，1.8.7 记录 iPadOS 未安装微信授权修复。见[SDK 自带说明](../../../../modules/icao-wechat-auth/ios/Vendor/WechatOpenSDK.xcframework/README.txt)。这些证明 SDK 曾提供该能力，不等于当前配置及线上服务已验收。
- [当前原生模块](../../../../modules/icao-wechat-auth/ios/IcaoWechatAuthModule.swift)在调用授权前要求已安装且支持微信，是已查明的本地拦截；[认证服务](../../../../src/features/auth/auth-service.ts)另有 supported/configured 判断，实施时一并检查适用调用链。
- 用户提供的有道微信手机号弹窗是体验参考，不能据截图认定其具体 SDK 版本、容器或完整登录已经成功。
- [微信移动应用登录指南](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/WeChat_Login/Development_Guide.html)本轮在线读取失败；不把历史 SDK 记录描述成最新平台开放条件。实施前继续核对官方 SDK、实际应用权限和授权结果。
- [苹果 4.2.3(i)](https://developer.apple.com/app-store/review/guidelines/#minimum-functionality)要求 App 无需安装其他 App 即可使用。审核邮件推荐 Safari View Controller；SDK 的 WKWebView 不等于 Safari View Controller，提交材料必须如实描述。使用官方 SDK 不是自动通过审核的保证。

## 实施路线（待执行授权）

1. 核对锁定 SDK、移动应用 AppID、登录权限、Bundle ID、Universal Link/AASA 与服务端一致；复用已有配置，不重新索要或输出已保存的 Secret。
2. 调整原生及界面层安装状态拦截，让未安装场景进入官方 SDK 授权；保留配置错误检查、单次授权锁和现有 challenge/state 校验。
3. 授权成功仍走现有服务端 code 交换、身份映射和会话建立。验证两条路径返回的同一微信身份关联同一账号；不根据昵称或未经验证的手机号自动合并账号。微信验证手机号不自动绑定本 App。
4. 处理短信交互所需等待时间、取消/拒绝、超时、断网、重复点击、迟到回调与冷启动回调；退出后界面可操作、可重试，不让迟到结果切换用户账号。
5. 保留注销后重新注册规则：注销完成可建新账号，注销中不提前重建；不恢复旧数据/权益、不重复发放同一微信的一次性体验额度。绑定冲突不自动合并或覆盖账号。
6. 聚焦测试与代码审查后，按后续授权从已合入 origin/main 的代码构建新 iOS 候选。涉及原生模块，不能仅部署服务端宣称修复旧包。

若官方能力在当前配置下无法完成授权，先在既定接口内诊断配置、生命周期和兼容性问题。若证据表明必须换登录产品、申请新权限或放弃免安装微信登录，记录具体阻塞并重新讨论；不得静默改成隐藏入口、跳安装页、自建微信表单或强制注册另一个账号。本方案确认不等于以上替代方案获准。

## 验收清单

- [ ] 未安装微信的真实 iPhone、iPad：从点击入口到官方验证、返回 App、进入账号全程成功；弹窗出现不算通过。
- [ ] 同一现存微信通过两种路径登录，业务账号、会员与学习数据一致。
- [ ] 新身份首次登录、再次登录、注销后重新注册及绑定冲突符合既定规则。
- [ ] 已安装微信授权无回归；取消、拒绝、超时、断网、重复点击、迟到/冷启动回调不会卡死、重复建号或串号。
- [ ] Apple 登录及手机号/密码入口实际可用；没有强制安装第三方 App 的步骤。
- [ ] SDK 与隐私披露一致，Secret 仅服务端，日志/录屏/文档不暴露验证码、完整授权响应或会话凭据。

## 审核交付

- 为免安装微信真机完整登录录屏，隐去手机号、验证码等敏感信息；记录设备、系统、候选版本、步骤和结果。
- 审核说明如实写“微信官方 SDK 提供的 App 内授权”，按实际容器描述，不冒称 Safari View Controller。提供可用的审核账号及密码登录路径，不要求审核员收取开发者短信；录屏不能替代真实可用的功能。
- 保留同等可用的 Apple 登录，核对[苹果 4.8](https://developer.apple.com/app-store/review/guidelines/#login-services)；审核账号和完整访问说明遵循[审核准备要求](https://developer.apple.com/app-store/review/guidelines/#before-you-submit)。
- 整次重新送审还依赖 CallKit 删除与随身听后台播放验证/录屏。这两个问题单独维护，本轮微信方案落文不代表它们已修复，也不代表已发送审核回复。

## 当前交接

### 2026-09-13 用户体验与审核复核补充

- 先验证免安装授权真正返回有效身份，再开展完整接入；不得仅移除安装 guard 就宣称修复。已安装但版本不支持授权也要有清楚、可退出的处理，不能落入空弹窗。
- SDK 内收短信所需等待与客户端、服务端 challenge 有效期必须匹配；过期可重新发起独立授权，不能复用旧 code/state 或无限延长期限。取消后关闭加载态，迟到回调失效。
- iPad 上验证横竖屏、键盘遮挡、关闭按钮和回到原页；手机号录入及验证过程由官方页面负责。无法完成时明确“微信授权未完成，可重试或选择其他方式”，不误称已登录。
- 其他方式登录不能自动认定是原微信账号。仅已绑定的身份才能进入原账号；新 Apple 身份可能对应新账号，不能为审核自动合并权益。
- 检查实际候选的 Apple 登录、应用内注销、SDK 隐私说明及审核密码账号。审核录屏为辅助证据，不能代替审核员可直接访问的真实功能。
