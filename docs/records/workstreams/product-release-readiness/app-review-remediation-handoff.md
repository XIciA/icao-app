## 苹果要求的随身听录屏

使用手机或 iPad 本体展示：打开 App → 随身听入口 → 开始播放 → 返回系统主屏 → 后台跨越至少两次切歌。建议补锁屏画面，再返回 App 展示正在播放的第三首。录屏必须能听到真实音频；若系统录屏不包含所需声音，可用另一设备外拍屏幕与声音。不要仅录单曲循环。

把视频放入 App Review Information 的 Notes 可访问链接/附件，并写明随身听入口与测试账号权限。审核账号不能要求审核员接收开发者短信。微信免安装窗口可另附一段从未安装微信到授权成功的演示；仅出现窗口不等于成功登录。
