# OPI 参考答案补全与双语正式版需求

状态：已确认

更新时间：2026-07-28

## 1. 目标

在保持 OPI v9 的 1067 道英文问题、中文问题、卡片 ID、话题和顺序不变的前提下：

- 补齐 158 个 `source-insufficient` 和 10 个图片依赖项的英文参考答案。
- 原则冻结现有 899 份 v9 英文答案，仅修复明确的事实、语法或问答匹配硬错误。
- 英文答案全部锁定后，只依据最终英文重新翻译 1067 份中文参考答案。
- 将完整四字段题库提升为唯一正式维护源 OPI v10，并完成生产发布和回滚验证。

最终正式数据保持 8 分类、144 话题、1090 卡，其中 1067 张文本卡全部具有英文和中文参考答案，23 张纯图片卡保持不变。

## 2. 内容边界

- 废弃的 v8 中英文答案不得作为素材或翻译底稿。
- 新英文答案优先参考当前 899 份 v9 英文答案的事实表达、口语风格和术语。
- 当前答案不足时，由 Codex 依据 ICAO、CAAC、FAA、EASA、制造商等官方资料重新编写。
- 公司、机型和个人经历题采用彼此独立的第一人称示范答案，不要求跨卡保持同一人物经历。
- 10 个图片依赖项必须由 Codex 查看对应正式图片后作答，只描述可见内容；无法确认的原因使用保守措辞。
- 中文答案只依据锁定英文答案翻译，不读取旧中文答案。
- 所有生产文本由主 Codex 完成。独立 Codex 只读复核，不直接写入生产文本。
- 禁止 Ollama、Qwen、外部 API 模型和其他本地模型生成、翻译、改写或审核生产文本。

## 3. 英文答案标准

- 每题一份可直接学习和复述的答案。
- 直接回答问题，通常 1–3 句、15–50 词；复杂题最多 4 句、约 66 词。
- 简单题可以更短，不得为满足长度添加空话。
- 不使用编号、项目符号、多版本、教材说明、引用标记或模板免责声明。
- 不在答案中穿插中文。
- 数值、限制、程序、法规和当前运营信息必须有官方依据；存在机型、公司或监管差异时使用准确的适用范围或通用安全表述。
- 图片答案不得把不可见原因、损伤或事件写成确定事实。

## 4. 中文答案标准

- 完整对应英文的观点、范围、人称、条件、顺序、数字和段落。
- 使用自然、简洁、规范的航空中文，不机械直译。
- 不增加解释、不删减观点、不改变确定性程度。
- ATC、SOP、TCAS 等通用缩写可保留；必要时使用自然的中文术语。
- 不在中文字段中写入完整英文句子。

## 5. 锁定与完成标准

- 问题锁、ID、归属、顺序和数量零变化。
- 899 份现有英文答案 hash 原则不变；例外必须有逐卡理由和前后 hash。
- 168 份新英文答案全部完成一次独立 Codex 全量只读复核。
- 中文阶段执行全量生产校对、机器校验、高风险逐项复核和不少于 300 张普通项分层抽检。
- 1067 张文本卡全部具有 `referenceText` 和 `referenceTextZh`。
- 正式维护源、生成 release、App 内嵌题库和线上活动 OPI 均为 v10。
- Android 不在本轮验收范围；按用户 2026-07-28 最新决定，本轮不执行 iOS 模拟器验收，iOS 真机由用户发布后自行验收。
