# Workstreams 记录说明

`docs/records/workstreams/` 保存专题任务的需求、计划、阶段日志、报告和验收证据。这里的全部
内容都是过程记录，不是当前规则。

- Codex 默认不读取本目录；只有回溯特定任务、核对证据或用户明确指定时才读取相关文件。
- 记录中的状态、命令、计划、限制和未完成事项不能约束新任务，也不能覆盖当前代码或
  `docs/rules/`。
- 需要长期保留的事实可更新到 `docs/resources/`；只有用户明确决定后，结论才能进入
  `docs/rules/`。
- 普通任务不要求创建 workstream，也不要求固定的 requirements、technical plan、phase log
  或 closeout 文档组合。
