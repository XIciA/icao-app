# 静态查词替代运行时 AI 查词：需求文档

状态：已确认

## 目标

把学习页的查词改为本地固定词典展示。用户点选当前题库中的英文词后，应立即获得已审核的词条；该过程不调用 AI、业务 API 或外部网络服务。

## 范围

- iOS / Android 保留听力、900句、陆空通话、OPI、故事复诵学习页中的现有长按查词入口和结果弹层位置；Web 在同一学习页工具栏提供显式“查词”开关，开启后改为单击单词查词。
- 为当前发布题库中可点选的英文词准备固定查词内容；题库内容版本变化时，查词内容须同步校验与补齐。
- 查词面板只展示：所点英文单词、一个美式 IPA 音标、“航空释义”和“常用释义”两个固定区块。两个释义均包含词性和中文含义。例如：`descent`、`/dɪˈsent/`、`航空释义：n. 下降`、`常用释义：n. 斜坡；恶化；沦落；血统`。
- 词表由确定性脚本从题库提取、清洗、规范化和去重；按当前已确认范围约 8,800 条词条的美式 IPA、航空释义和常用释义均由当前 Codex 基于该词表直接生成，生成过程不得调用外部 API、本机其他本地模型或第三方词典数据。
- 多义词不按当前题目句子自动选择词义；只在航空释义和常用释义内按词性并列多个固定短义项，由用户结合原句理解。
- 查词可在无网络状态下使用，打开结果不依赖登录、AI 同意或服务端响应。
- 用户界面不再把该能力表述为 AI 生成、联网查询或缓存结果。
- Web 的“查词”开关与高亮模式互斥；未开启时，Web 不以长按作为隐藏查词入口。开启后，可查词在鼠标悬停或键盘聚焦时显示圆角浅蓝背景和指针光标，明确提示单击查词；不使用下划线，以免与高亮标注混淆。

## 模块要求

| 模块 | 要求 |
| --- | --- |
| 题库文本 | 原生 iOS / Android 按单词长按触发；Web 在现有“答案 / 高亮 / 标签”工具栏增加“查词”开关，开启后可查词悬停显示圆角浅蓝背景并由单击触发，关闭后单击不查词。两端都不重做学习页文本、卡片或工具栏布局。 |
| 查词弹层 | 内容区只显示单词、一个音标、航空释义和常用释义；保留组件自身的关闭手势，不保留额外操作按钮。 |
| 静态内容 | 由项目内唯一、可审查的数据源提供，不在题库卡片中复制维护。 |
| 其他 AI 能力 | 转写、语法纠错、表达分析和润色保持原有接口与行为，本任务不改动。 |

## 题库文本覆盖范围

| 题库 | 纳入静态查词的文本 | 不纳入范围 |
| --- | --- | --- |
| 听力 | 音频原文和每题四个选项文本；选项是听力题的答案 | `referenceText` 中的遗留正确答案键、中文翻译；听力页不应展示参考答案区块 |
| 900句 | 音频原文 | 中文翻译和不存在的参考答案区块 |
| 陆空通话 | 音频原文和参考答案 | 中文翻译 |
| OPI | 音频原文和存在的参考答案 | 中文翻译 |
| 故事复诵 | 音频原文 | 中文翻译和不存在的参考答案区块 |

## 明确不做

- 不调用 `/v1/ai/word-lookup`，不以客户端缓存或服务端缓存作为查词结果来源。
- 不新增通用在线词典、第三方 SDK、外部模型、账号权限或生产部署。
- 不调用外部词典、翻译、发音、AI 或模型 API；不调用本机其他本地模型；不导入第三方词典数据作为词条来源。
- 不改变题库内容、学习记录、标注、音频、题目作答或其他 AI 功能。
- 不承诺本轮支持用户框选多词短语；当前原生交互仍以单个点选词为单位。
- 不做句子语境解析、词义自动消歧或本句理解。
- 不展示“AI 查词”、题库/卡片信息、原句、本句理解、释义标题、星级、考试标签、英美双音标、发音按钮、来源、缓存提示、加载态、重试或“返回学习”按钮。

## 验收效果

- 飞行模式下，任意已收录的当前题库英文词可直接打开固定词条，页面不出现加载、AI 同意、网络失败或重试控件。
- 每个词条只显示单词、一个音标、航空释义和常用释义；两个释义都包含词性和中文含义，不出现任何额外信息或操作控件。
- 航空释义和常用释义稳定、可审核，民航术语、缩写和常用词不存在明显误释。
- 自动校验能证明词表提取、词形覆盖、字段结构、音标格式和词性标记有效；它不替代对词义正确性的人工专业判断。
- 词条内容生成记录可证明未使用外部 API、本机其他本地模型或第三方词典数据。
- 自动校验能证明当前题库所有可点选英文词都有静态词条。
- 用户可见文案不再包含“AI 查词”或“AI 生成内容”。
