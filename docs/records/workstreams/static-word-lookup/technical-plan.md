# 静态查词替代运行时 AI 查词：技术方案

状态：已确认

## 推荐方案

建立一个独立、版本化的静态查词内容源，并在构建时校验它对当前题库的覆盖。学习页在本地查找内容后直接填充既有 Bottom Sheet；查词链路不再经过 `features/ai`、认证、同意记录或 API。

内容只采用一层词条结构：以规范化英文词形为键，提供显示单词、一个美式 IPA 音标、航空释义和常用释义。两个释义分别包含词性和中文含义；多义词在所属区块内并列多个短义项。查词不读取当前句子，不做词义自动消歧，也不产生或展示本句理解。

## 数据与模块边界

```text
question-bank.json ──> 词表清洗/覆盖校验脚本 ──> 已锁定词表
                                               │
                                      Codex 生成词条字段
                                               │
                                   static word-lookup dataset
                                               │
InteractiveStudyText ──> 本地 lookup repository ──> QuestionBankStudyScreen Bottom Sheet
```

- 静态查词数据在 `content/word-lookup/` 保持唯一权威来源；应用端只使用由其生成的只读资源。
- 数据条目应保留内容版本、规范化词形、显示单词、一个美式 IPA 音标、航空释义和常用释义；两个释义字段均须包含词性和中文含义，可在同一词性下并列多个短义项。
- 静态词条作为学习页路由加载时的单一只读映射；查询时只做规范化键的本地 `Map` 查找，不复制题库正文或维护第二套卡片数据。若后续实测包体或内存出现问题，再按首字母分片；本阶段不以增加资源加载复杂度换取未验证收益。
- 题库仍是题目正文唯一来源；查词资源不复制题目全文、句子、音频映射或学习状态。
- 使用新的静态词条类型，不复用带有 `sentenceMeaning`、`promptVersion` 或 `cached` 的 AI 结果类型。
- 交互由同一个跨端策略解析：iOS / Android 为 `long-press`；Web 默认禁用查词，只有工具栏“查词”按钮进入激活态后才为 `tap`。Web 查词与高亮复用独立的可按压词语目标，并在悬停或键盘聚焦时显示圆角浅蓝背景和指针光标；两种模式互斥，查词反馈不使用下划线。

## 内容生产与质量控制

- 先由确定性脚本按已确认的题库文本范围提取可点选英文词；听力只提取 `audioText` 和四个 `choices`，明确排除其遗留答案键 `referenceText`；其它题库按需求文档提取原文与允许的参考答案。脚本完成规范化、去重、异常 token 报告和覆盖清单生成；该步骤不由 Codex 逐题手工输入或整理。
- 按当前已确认范围约 8,800 条固定内容由当前 Codex 基于已锁定词表直接分批生成到临时文件，再经自动校验后写入正式数据。生成过程禁止调用外部 API、本机其他本地模型和第三方词典数据；可读取当前项目题库及已纳入仓库的民航内容作为上下文，不得把它们复制为新的词典数据源。
- 每批内容按 200–300 条执行自动结构校验；校验覆盖字段完整性、词性格式、美式 IPA 格式、重复键、词表覆盖和题库内容指纹。自动校验不能证明词义在专业语义上绝对正确，该风险须在收口记录中保留。
- 校验需阻止：缺少音标、缺少航空释义、缺少常用释义、任一释义缺少词性加含义、未覆盖词、重复规范化词形、超长文本和题库版本不一致。

## 不采用的方案

| 方案 | 不采用原因 |
| --- | --- |
| 保留 API，仅增加缓存 | 仍依赖网络、认证、同意与上游模型，不满足需求。 |
| 直接复用现有 838 条单词学习词库 | 覆盖当前题库英文词形不足，且它的例句并非当前题库语境。 |
| 调用外部词典、翻译、发音或模型 API | 违背“由当前 Codex 直接生成、无外部 API”的明确约束。 |
| 调用本机其他本地模型或导入第三方词典数据 | 违背内容生成边界，并会引入来源、授权和质量不可审查的问题。 |

## 关键取舍与风险

- 静态内容换取了确定性和离线可用性，但词典更新需随 App 内容版本发布，不能即时纠正线上结果。
- 本方案有意不提供本句理解；它是静态词条能力的边界，不应由通用词义伪装为句子翻译。
- 自动校验可保证结构和覆盖，但不能证明词义在专业语义上绝对正确；音标、多义词、专有名词和 ICAO 缩写仍是剩余内容风险。发现系统性错误时只重跑受影响批次。
- 听力选项当前由独立的 `ChoiceList` 渲染，静态查词接入时必须在不改变选项短按作答行为的前提下支持：原生长按查词；Web 查词模式激活后单击选项中的词只查词、不作答。
- 听力的 `referenceText` 是遗留答案键，不是产品参考答案；接入时必须停止在听力学习页展示该区块。四个 `choices` 保持唯一答案展示与查词来源，`correctChoiceIndex` 继续承担判题。
- 题库分词规则变化可能改变可点选词集合，因此内容覆盖校验是上线门槛而不是附加测试。
