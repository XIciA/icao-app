## 6. 基础盘点时尚未完成去重的原因

正确 Web 来源与 App 使用不同 ID、不同分类和不同文本表示形式。以下工作随后由路线图阶段 1 执行，不能用数量差或旧题库结论代替：

- 把呼号全称、民航字母词、数字空格、Runway 写法和正文外标签规范成仅用于比较的形式。
- 听力按原文、问题、选项和正确答案整体比较。
- 陆空通话按任务文本、参考回答、呼号、飞行阶段和指令意图整体比较。
- 故事复诵在剥离篇号和词数后，与四个现有子库及其他 Web 候选比较完整故事正文。
- 音频哈希只作为辅助证据；不同录音不能自动认定为新题。
- 相似度结果只用于筛选，边界候选必须人工判断。

因此，本基础盘点没有声明“没有净新增题”，也没有预先推测具体迁移数量。

## 8. 风险与实施约束

- 不能把 740、37、1367、144 与 App 数量直接相减当作新增数。

- 音频存在不等于答案正确；内容疑点只能进入人工复核，不能使用 ASR 猜测。
- 原隔离区可以按单题进入迁移，但必须保留来源分区不完整标记。
- 当前工作区有其他未提交修改，后续必须使用基线摘要和目标文件白名单，避免覆盖用户工作。
- Web 来源在整个迁移流程中保持只读。
