# 2026-10-22 题库文本统一与子库重排

本记录只承接本次用户授权，不增加长期规则。用户已明确要求“修改并上线，完成任务，不需要人工干涉”。

## 范围与实现

- 正式线上五库共 10,900 卡：听力 1,502，900句 900，陆空通话 5,751，OPI 2,365，故事复诵 382。
- 发布前只读对照线上有效版本发现仓库 OPI 少 44 卡、46 份不可变媒体引用。先同步线上有效内容和关联，保留全部 ID、题目归属及既有媒体；没有新增或替换学习内容。
- 清理装饰性整段括号、异常空白，统一标点和选项句末格式。答案回显与原来的正确选项同步使用相同标点。
- 故事复诵中英正文各一段，英文正文下以单独辅助行统一显示重新统计的 `N words`。沿用现有文本合同，现有三端客户端直接显示；不会为了词数重新录音。
- OPI 题干中的明确“全称（缩写）”只保留缩写，答案全称保留。没有括号缩写的全称不自行猜测缩写。保留原音频资源及其展开读法；这是用户指定的显示简化，不是音频与题目错配。
- 子库使用一次性固定排列。听力按各时长子库、故事按四个原子库、900句按原级别重排；陆空按分类内整组场景重排，组内问答顺序不动；OPI 分类内重排话题、独立问答在话题内重排，看图题整组保持篇内顺序。共 181 个有效重排范围，各范围中每个单位均离开旧位置。
- 全文扫描未检出用户举例的独立版权、来源署名等附加行，不凭空删除正文中的机构或专有名词。有实际语义的括号、数字、频率、负号、单位和缩写保留。
- 未改写语法、大小写、事实或答案。保留 27 项原有内容疑点，已在既有审计清单中标记本轮不处理。

## 数据保护

- `identity-proofs.json` 来自发布前线上有效内容，核验全部卡的分类/话题/ID、媒体引用、答案、学习层级及排除明确冗余后的正文字符内容；同时核验陆空通话和看图题的篇内顺序。
- `text-changes.json` 记录每一处修改原文、结果、定位和 SHA-256；`order-changes.json` 保存每个范围的前后 ID 列表。
- 学习状态、收藏、笔记、作答和录音不换键、不清空；仍按稳定题目 ID 加载，继续学习按原卡最近访问记录恢复。
- 文本高亮依赖旧文本指纹与词位置，生成精确旧版本映射。API 兼容已存标注和旧客户端迟到上传；不猜测未知版本、不删除任何高亮、笔记或标签。已删除冗余标签上的高亮保留原文上下文。
- 生产内容导入增加可选基线版本/校验和门禁，防止盘点期间发生的新发布被覆盖；导入继续使用事务、不可变版本和禁止历史重置的现有机制。
- ASR 热词证据、数量与900句训练文本仅随格式重新生成，词条选择和权重不变。
