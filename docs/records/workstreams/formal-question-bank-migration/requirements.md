# 正式题库数据迁移需求

## 核心问题

本项目目前已经把五个题库模块统一到同一套目录页和学习页结构，但题库内容仍是 mock 数据，不能真实反映未来 App 的题库规模、分类层级和学习内容。

上级目录 `feizhuicu` 已有真实题库内容，但它是生产 Web 项目的数据结构，不能完整搬进本项目。本项目需要的是一份服务于当前高保真 UI 的精简题库数据：先定义本项目学习页真正需要的字段，再从 `feizhuicu` 中抽取对应文本填入。

## 目标

把真实题库内容接入本项目，使五个题库模块都能在当前统一 UI 中展示真实内容：

- 听力
- 900句
- 陆空通话
- ICAO OPI
- 故事复诵

## 基本要求

- 不迁移 `feizhuicu` 的完整 JSON，不保留本项目 UI 不使用的字段。
- 迁移后的数据结构必须重新设计，只包含当前目录页和学习页需要展示的数据。
- 听力音频资源需要迁移到本项目，并按音频/任务模块显示名称重新命名，例如 `10s航空英语-1.mp3`。
- 五个题库模块必须继续统一维护，不能变成每个模块一套独立页面代码。
- 不能破坏当前选定的 UI 设计、展示效果、学习页结构和代码逻辑框架。
- 目录页应展示真实分类、真实题量和真实题库层级。
- 学习页统一保持三段结构：音频/任务模块、原文/理解模块、控制台模块。

## 学习页显示规则

- OPI：任务标题如 `气象-雷击-1`；原文模块标题为 `音频原文`；控制台为 `我的回答 / 参考答案 / 笔记`。
- 听力：任务标题如 `10s航空英语-1`；删除额外的 `选择答案` 标题；原文模块标题为 `音频原文`；控制台为 `笔记`。
- 900句：任务标题如 `Sentence1`；原文模块标题为 `音频原文`；控制台为 `我的回答 / 笔记`。
- 陆空通话：任务标题如 `ACA 121-1`；原文模块标题为 `音频原文`；控制台为 `我的回答 / 参考答案 / 笔记`。
- 故事复诵：任务标题如 `飞行ICAO-必做题库-1`；原文模块标题为 `音频原文`；控制台为 `我的回答 / 参考答案 / 笔记`。

## 暂不纳入

- 不迁移登录、进度、标注、错题、AI、后台管理等生产功能。
- 不重做当前 UI 风格和导航结构。
- 不处理题库内容清洗、翻译、润色。
- 不接入 `feizhuicu` 的生产路由、feature 体系或数据加载体系。
- 不迁移除听力以外的完整音频资源；其它模块音频资源是否复制，后续单独确认。

## 验收标准

- 五个题库模块能基于重构后的精简真实数据展示。
- 数据字段只包含当前 UI 使用内容，未携带无关生产字段。
- 听力音频文件已按本项目任务标题命名并可被听力卡片引用。
- 题库数量、分类和文本来源能与 `feizhuicu` 对账。
- 当前统一目录页和学习页结构不被破坏。
- 项目能通过基础类型检查和构建验证。
