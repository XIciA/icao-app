# 最小真实反馈需求

状态：已完成（2026-07-23，过程与线上证据见 `phase-log.md`）

## 本轮范围

- “我的”提供“意见反馈”入口，默认“功能建议”。
- 刷题学习页提供低视觉权重“纠错”入口，默认“内容纠错”，关联当前题库、分类、主题和题目。
- 统一表单支持功能建议、内容纠错、其他；描述 5–500 字，联系方式选填。
- 最多选择 3 张 JPEG、PNG 或 WebP，每张不超过 5 MB；失败后保留当前表单。
- 提交成功仅展示不可枚举反馈编号。
- 反馈正文写 PostgreSQL，截图写私有 `feedback-screenshots` Bucket。

## 不在本轮

管理员页面和管理接口、用户反馈历史、状态通知、客服对话、推送、离线提交队列。

## 数据生命周期

- 截图到期时间为提交后 365 天；每日清理到期对象并保留已删除标记。
- 账号注销时数据库记录级联删除，并立即删除对应对象；对象删除失败由 24 小时孤立对象清理兜底。
- 未提交草稿不持久化。
