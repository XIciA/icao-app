# 全局整页中间状态统一

用户在本任务确认十个示例并授权实施：加载、会员、本机内容未就绪、失败、内容不可用、空态、验证、范围限制、账号注销、账号恢复失败。只使用等待与提示两套视觉模板。无顶部栏目、无说明小字，最多两个按钮；蓝色主按钮，浅底描边次按钮。

## 实现

- `CenteredState` 接口改为固定 `kind`，删除任意说明、图标、颜色和 ReactNode 操作槽。最多主/次两项操作，保持调用方提供的重试与本地返回。
- 所有原 CenteredState 调用迁移到固定类型；题库、词汇、文章、热点等整页状态移除栏目。局部列表空态、音频/图片/导出进度保留功能上下文。
- 题库路由准备与学习会话恢复采用同一 Screen/GlobalLoadingScreen 布局；移除内层加载的返回按钮，避免不同加载阶段产生位置和按钮跳动。
- 单词左上角加载、场景/复盘占位文字改为公共加载；LocalBackLoadingScreen 只保留本地系统返回归属，没有独立样式。
- 热点、反馈、学习记录整页空态统一，保留提交反馈和学习记录新手引导定位；Web 热点加载失败不再混入正常页面栏目。
- 会员限制合并；账号恢复失败只保留重新检查与退出登录；本机内容未就绪提供下载管理入口。
- 系统启动画面、系统权限弹窗、正常功能页及其局部状态不作为本次整页替换目标。未修改导航栈的常规转场动画，也未以隐藏错误或延迟显示伪造加载完成。
