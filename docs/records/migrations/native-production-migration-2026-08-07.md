正式 iOS Bundle ID `com.readyoufife.ios` 与 Android 包名 `com.readyoufife.app` 均与旧内测包不同，因此操作系统会把它们视为新 App。登录同一账号后，云端已同步数据会恢复；只存在旧包本机且从未同步的数据无法由服务器迁移。这是包名变更边界，不是服务器数据丢失。

## 安全基线

- SSH 仅允许密钥认证；root 密码登录和交互式认证已关闭。
- 已启用阿里云官方会话管理作为不依赖公网入站端口的应急运维通道；未开启会话记录投递。
- UFW 仅允许 80/443，22 使用连接限速规则。
- 阿里云安全组未暴露 PostgreSQL、Supabase、API 内部端口。
- Docker 日志启用单文件 10 MiB、最多 5 个文件的轮转。
- 已配置 2 GiB Swap 和自动安全更新。

## 回滚边界

- 旧 ECS 不再作为新版 Native 回滚目标；正式流量、数据库、Storage 与备份任务均不得依赖它。
- 旧网关切换前配置保存在
  `/opt/icao/runtime/gateway/Caddyfile.pre-readyoufife-cutover-20260807`。
- 一旦新数据库产生新写入，不得直接把流量切回旧数据库；回滚前必须先备份新数据库和
  存储增量并恢复到旧机，再验证数据哈希。

## 旧 ECS 退役结论

- 新域名 HTTPS、新机本地 API/Supabase、五套活动题库、6,761 个 Storage 对象及其扩展属性、
  五套代表音频 Range 请求和每日 PostgreSQL 本地备份均已复核通过。

- 旧内测 APK 下载子域名和仓库发布入口已退役；旧机磁盘残留不构成运行依赖。若以后需要
  物理删除，必须先明确选择“短时续费后定点删除”或“释放整机”，并重新评估同机其他遗留
  数据，不能把该操作并入普通 Native/Web 发布。
- 当前明确接受没有 OSS、快照、云备份或 Storage 异机副本的单机数据丢失风险。
