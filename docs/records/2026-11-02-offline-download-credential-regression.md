## 原因与范围

TestFlight 1.3.1 (3596166) 在下载准备阶段请求会员期限离线凭证。线上 API 已按已验证会员到期时间签发，但 `content_access_credentials_window_check` 仍要求最长 72 小时。会员剩余超过 72 小时时数据库拒绝保存，凭证接口返回 500，音频下载尚未开始。所有共用该接口的题库受影响。

生产只读核对确认旧约束仍存在；本地真实 PostgreSQL 调用 ContentAccessService 已复现同一 CHECK 失败。上一轮只使用模拟数据库的凭证单测，没有覆盖实际持久化约束。

## 最小修复

新增 0060_membership_offline_credential_window 迁移：保留 expires_at > issued_at，移除固定 72 小时上限。API 继续按真实有效会员期限限制签名到期时间；旧请求仍取会员到期与 72 小时的较早值。账号、权益段及环境联合外键、签名密钥、数据保留规则、RLS 和其他权限不变。不删除或重写已有数据，不增加客户端状态。API 最低数据库版本绑定到本次迁移，避免未来遗漏迁移仍启动并向用户返回下载 500。

本次未改变 App 版本或重新上传 TestFlight。当前 1.3.1 (3596166) 可直接重试下载；服务端验证不替代用户的整库下载、离开页面继续和离线播放验收。
