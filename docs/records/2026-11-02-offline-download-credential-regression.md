# 下载启动失败：离线凭证有效期约束修复

状态：修复及本地验证完成；生产数据库变更待单独授权。此记录不授予上线权限。

## 原因与范围

TestFlight 1.3.1 (3596166) 在下载准备阶段请求会员期限离线凭证。线上 API 已按已验证会员到期时间签发，但 `content_access_credentials_window_check` 仍要求最长 72 小时。会员剩余超过 72 小时时数据库拒绝保存，凭证接口返回 500，音频下载尚未开始。所有共用该接口的题库受影响。

生产只读核对确认旧约束仍存在；本地真实 PostgreSQL 调用 ContentAccessService 已复现同一 CHECK 失败。上一轮只使用模拟数据库的凭证单测，没有覆盖实际持久化约束。

## 最小修复

新增 0060_membership_offline_credential_window 迁移：保留 expires_at > issued_at，移除固定 72 小时上限。API 继续按真实有效会员期限限制签名到期时间；旧请求仍取会员到期与 72 小时的较早值。账号、权益段及环境联合外键、签名密钥、数据保留规则、RLS 和其他权限不变。不删除或重写已有数据，不增加客户端状态。

不需要改变 App 版本或重新上传 TestFlight；生产约束修复后当前客户端可以重试。线上尚未执行，因此不能视为用户下载体验已恢复或已验收。

## 验证证据

- 修改前：真实数据库回归测试在会员期限凭证 INSERT 时失败，约束名与线上一致。
- 修改后：真实数据库套件 68 项通过；覆盖五类题库、签名及落库到期一致、旧请求 72 小时、剩余一小时、会员过期/非会员拒绝、负/零时间窗拒绝、账号及环境外键、保留期约束。
- ContentAccessService 单测 25 项通过；API 类型检查、lint 和 Drizzle 迁移检查通过。
- 生产账本只读比对：60 项已应用，只有本次 0060 待应用，无漂移。

## 执行与恢复

从合入 main 的干净提交运行现有隔离数据库恢复演练。生产执行前取得本次数据库迁移明确授权，按现有迁移工具完成备份、账本校验、原子迁移和后置检查。

迁移未成功时事务回滚。新约束兼容旧 API；如需退回旧 API，保留兼容的新约束，不对已签发的长期凭证强行恢复 72 小时 CHECK，不删除用户数据。生产完成后另记执行证据及真实凭证/下载验证结果。
