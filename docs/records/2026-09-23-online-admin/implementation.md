# 线上管理后台交付

用户确认：将现有完整本地后台放到线上，一位管理员拥有当前全部权限，无注册入口；沿用已有域名 `/admin`，本地后台不变。

实现：`https://api.readyoufife.com/admin/` 复用证书，静态资源采用相对路径，线上 API 请求带 `/admin`，网关去除前缀交给独立 Ops API。普通用户 API 保留在 3101；后台 API 与静态站点分别只监听环回 3102、4180。管理员使用现有密码、动态验证码及恢复码机制，秘密仅保存在仓库外私有文件中。

范围：用户反馈、点击统计、AI 用量与费用、AI 规则、用户权益全部沿用现有实现。不新增权益类别、不重做用户页面，不操作真实用户权益来测试部署。

发布：代码通过 PR 合入 main 后部署。网关发布仅替换 API 虚拟主机，保留现有 cloud 等其他站点配置。使用现有备份、隔离恢复及回滚机制；未部署前不标记完成。

验证：本地和 `/admin/` 请求路径、Ops 登录鉴权与反馈测试、页面构建、网关局部替换及回滚未部署状态检查；线上验证登录、五个页面数据读取、未登录拒绝、普通 API 健康、本地入口仍可访问。管理员账号交付文件不得进入 Git。
