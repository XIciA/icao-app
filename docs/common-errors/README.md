# Common Errors

状态：长期维护

本目录记录已经在真实环境出现、可能再次出现、且需要跨阶段复用排障经验的工程故障。它不是临时修复日志，也不替代各能力的架构规范。

## 使用规则

1. 先阅读对应能力目录的 `README.md`，再开始修改代码。
2. 先用证据定位故障所在层级，再决定是否修改实现；禁止只根据界面报错猜测根因。
3. 每个能力目录用一份 `README.md` 维护关闭问题的简洁历史台账；复杂调查文档只在调查期间临时存在。
4. 修复必须尽量落为共享抽象、状态机约束、类型化错误、自动化测试或静态门禁；只有局部文案调整不能称为根治。
5. 已有架构文档仍是唯一规范来源。本目录只保存排障入口和事故知识，不复制新的 owner、状态机或生命周期定义。
6. 未完成真实设备验收时必须明确写为待办，不能用模拟器、确定性 E2E 或成功构建代替。

## 能力目录

- [`audio-recording/`](./audio-recording/README.md)：录音及相邻音频问题的单一历史台账；当前录音方案仍以规则和生命周期指南为准。
- [`web-content/`](./web-content/README.md)：Web 静态内容、同域交付、浏览器缓存和中国大陆网络可达性。

新增能力目录时使用全小写英文和连字符。临时调查文件使用
`incident-YYYY-MM-DD-short-description.md`，关闭后将结论合并进能力 `README.md` 并删除临时文件。
