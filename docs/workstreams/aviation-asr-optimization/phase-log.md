## Web 人工验收补充：无语音结果（2026-07-22）

- 本地 Web 录音结束时显式刷新编码器数据，并按 WebM/Opus 短录音特征调整完整性下限，解决只生成容器头而无法提交的问题。
- 阿里云近 24 小时任务记录确认，人工验收中的连续失败均为 `ASR_RESPONSE_HAVE_NO_WORDS`；同一线上链路使用有效 WebM/Opus 语音样本可正常转写，因此模型、热词、临时存储、签名地址和音频格式均已排除。
- API 将该供应商结果稳定映射为 `422 no_speech_detected`；App 显示“未检测到清晰语音”，引导回放并检查麦克风，不再把可恢复的转写失败写成会触发 Expo 红色遮罩的控制台错误。
- WebM MIME 参数在进入私有存储前统一为基础类型，避免浏览器 `audio/webm;codecs=opus` 与存储桶白名单产生兼容风险。
- 补充部署 ID：`asr-no-speech-20260722-1744`；回滚镜像：`icao-api:rollback-asr-no-speech-20260722-1744`；源码和运行配置备份位于 `/opt/icao/backups/api-asr-no-speech-20260722-1744`。
- 线上验证：健康检查、既有 API 冒烟、有效 WebM/Opus 转写和静音 WebM 的 `no_speech_detected` 映射均通过，临时音频均已删除。
- 完整检查：App 50 个测试套件、230 项测试通过；API 4 个测试文件、181 项测试通过；`pnpm check` 与 `pnpm check:audio` 通过。
