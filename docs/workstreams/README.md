# 任务文档

本目录保存任务方案与执行材料，不具项目级长期规则效力。任务文件只有在用户当前明确采用后，才在对应范围内指导执行。
历史“已确认”“待完成”和目录存在本身都不代表当前授权或进度，继续任务时先核对代码与真实状态。

各渠道交付与优先关注事项见[项目管理概览](../resources/project/product-state.md)。
本页提供任务入口，任务自身的首页或最终记录负责解释细节。
