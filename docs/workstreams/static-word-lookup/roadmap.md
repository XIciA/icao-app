# 静态查词替代运行时 AI 查词：路线图

状态：已确认，正在执行阶段 2

## 阶段总览

| 阶段 | 目标 | 核心产出 | 进入下一阶段标准 |
| --- | --- | --- | --- |
| 1. 内容契约与清单 | 固定静态词条边界并生成真实覆盖清单 | schema、词表清洗/校验脚本、缺口报告 | 能稳定列出并锁定全部待覆盖词形。 |
| 2. 内容生成与自动校验 | 生成全量固定词条并完成自动校验 | 版本化静态内容、批次与校验记录 | 校验无缺词、无结构错误，剩余语义风险已记录。 |
| 3. 本地接入 | 用本地 repository 替换查词运行时 AI 链路 | 原生静态查词 UI、相关测试 | 查词不调用 API，离线可展示且原学习交互无回归。 |
| 4. 双端验收与收口 | 完成真实渲染、回归和交接记录 | 验收证据、phase-log、closeout | 双端验收通过，文档与版本记录齐全。 |

当前进度：阶段 1 已完成；阶段 2 进行中；阶段 3 的本地接入骨架已实现，等待全量内容覆盖后收口。

## 阶段 1：内容契约与清单

- 主要工作：定义静态词条 schema 和规范化规则；用脚本从已确认的题库文本范围确定性提取、清洗和去重所有可点选英文词，并生成缺口报告和锁定词表；听力提取音频原文和四个选项、排除遗留答案键 `referenceText`；不由 Codex 逐题手工输入整理。
- 允许修改：`content/word-lookup/`、只读数据处理工具、该 workstream 文档和对应测试。
- 禁止范围：不改学习页、不改题库正文、不调用外部词典/模型、不部署。
- 验收：覆盖清单数量可复现；无重复规范化键；题库分词变化能触发覆盖缺口；词表输出可作为 Codex 唯一生成输入。
- 暂不做：不编写全部释义，不接入 UI。

## 阶段 2：内容生产与审校

- 主要工作：由当前 Codex 按锁定词表分批补齐显示单词、一个美式 IPA 音标、航空释义和常用释义；两个释义均包含词性加中文含义，多义词在所属区块内并列固定短义项；不调用外部 API、本机其他本地模型或第三方词典数据；每 200–300 条执行自动结构校验。
- 允许修改：静态查词内容、内容生成/校验工具、相关内容说明。
- 禁止范围：不得调用外部 API、本机其他本地模型或第三方词典数据；不得把未经自动校验的 Codex 输出写入正式数据；不得复制题库正文、替换题库或改变单词学习词书。
- 验收：当前题库词形 100% 有条目；每条均有一个美式 IPA 音标、航空释义和常用释义，且两个释义均含词性加中文含义；多义词完整列出固定短义项而不依赖句子消歧；自动校验和生成边界记录可审查。
- 暂不做：不改网络服务，不删除旧 AI 接口。

## 阶段 3：本地接入

- 主要工作：增加本地 lookup repository 与按需资源加载；将学习页的查词状态切换为静态词条；iOS / Android 文本与听力选项保留长按查词；Web 在现有工具栏增加显式“查词”开关，激活后单击题干或选项中的词查词且不作答；停止在听力学习页展示遗留答案键 `referenceText`；删除该入口的 AI 同意、加载、失败、缓存、原句、本句理解和全部多余文案/控件；补充单元和交互测试。
- 允许修改：`src/features/question-bank/` 内查词相关组件/测试、静态查词 repository、共享类型及必要文案。
- 禁止范围：不修改其他 AI 功能、认证、服务端路由、数据库、题库正文、音频和学习记录。
- 验收：在模拟离线条件下代表性查词不触发 API；普通词、缩写和多义词均只展示单词、一个美式 IPA 音标、航空释义和常用释义；听力只展示四个选项作为答案，选项可长按查词且短按仍正常作答，不显示参考答案区块；`pnpm check` 通过。
- 暂不做：不删除 `/v1/ai/word-lookup`，除非后续另有经过确认的服务端清理任务。

- Web 补充验收：查词关闭时单击单词不查词；开启后题干和听力选项中的可查词在鼠标悬停或键盘聚焦时显示圆角浅蓝背景和指针光标，单击后打开查词结果；选项单击词不改变作答状态。查词与高亮互斥，且不显示额外的“高亮中 / 完成”浮动状态条。

## 阶段 4：双端验收与收口

- 主要工作：执行 iOS/Android Development Build 渲染检查、手势回归、静态数据全量校验和 Git diff 审查；记录阶段结果与剩余风险。
- 允许修改：为修复本任务范围内的查词数据、UI、测试和文档所需的最小文件。
- 禁止范围：不部署 ECS，不推送或提交，不处理无关工作区改动。
- 验收：iOS/Android 学习页中的长按查词和 Web 学习页中已激活查词模式后的单击查词稳定可用；无网络和无 AI 同意状态不阻断；内容区无本句理解、AI、句子、按钮等多余元素；当前题库覆盖校验通过；不引入第二份题库或词汇权威源。
- 暂不做：不扩展为短语框选、通用全文词典或在线词典搜索。

## 执行前确认项

路线确认时已确定：词表由脚本从题库自动清洗、去重和锁定；当前 Codex 基于词表直接生成单词、一个美式 IPA 音标、航空释义和常用释义；以自动校验作为内容进入正式数据的门槛；生成过程中不使用外部 API、本机其他本地模型或第三方词典数据。

## 小流程执行授权

用户已授权阶段 1 至阶段 4 自动连续执行。词表锁定、分批内容生成、自动校验、UI 接入、测试、双端验收、普通失败诊断与收口均不需要逐阶段人工确认。

批量内容须保存词表版本、批次范围、输出文件和校验结果；中断或失败时只重跑受影响批次。自动校验是内容准入门槛；词义专业准确性作为已接受的剩余风险记录，不构成人工审核阻塞。

只有触碰项目硬约束、需要新的外部资源或不可逆操作、发现范围冲突，或当前路线客观无法达成时才暂停。
