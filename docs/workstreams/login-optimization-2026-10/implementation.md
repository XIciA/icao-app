# 登录与免费学习实施记录

范围：本次用户确认的 F 未登录引导页、E 登录页组合，以及免费学习与会员入口规则。版本准备为 1.3.10；本文只记录本任务，不新增长期规则。

## 用户行为

- 未登录「我的」只显示插画、学习记录价值说明与登录按钮；没有顶部「我的」、使用指南、协议或隐私入口。已登录个人页保留现有记录功能，删除手动使用指南入口，自动新用户引导与测试重置保留。
- 登录默认短信验证码，可切换密码；保留恢复流程、未勾选的协议确认、协议链接和暂不登录。Native 保留并排两个圆形 Apple / 微信图标按钮。
- 900 句全部免费；听力每模块前十题，共四十题；陆空通话首套完整题；OPI 前三个话题；故事复述前三题。选择以发布内容顺序为准，忽略已退役题，筛选或搜索不重新选择免费名额。
- 发现页可浏览，各项功能入口均需要会员；目的页面也校验权益，覆盖深链接。未登录先登录；登录后非会员进入会员页；权益生效后返回原入口。权益请求失败显示重试，不判为非会员。
- 免费学习的录音、回放不要求登录。主动 AI 请求先登录，保留原有 AI 额度规则，不增加发现页 AI 功能。登录过程不提前上传音频。
- 本机访客学习状态、记录详情、标注及词汇状态在首次登录时合入账号；持久化认领快照支持中断重试。原账号与访客工作区隔离。登录接续使用录音仓库已有真实资产所有权，不添加第二套音频存储。

## 后端与兼容

- API 题库目录、题目与免费媒体签名允许无 Authorization 读取；存在无效 Authorization 时仍拒绝，匿名不能访问 sandbox。
- 非免费媒体、发现文章和词汇接口仍检查身份及会员；免费媒体依据当前 active release 判断，旧版题库不会扩大匿名权限。
- 离线凭证继续使用 `content-access-v2`，避免破坏已发布客户端。免费选择规则通过独立的 `release-order-v1` 和目录缓存版本更新。
- 需要部署 API 新代码才具备完整线上匿名媒体和发现接口权限；本任务不执行后端生产部署。无需数据库迁移或题库重导入。
