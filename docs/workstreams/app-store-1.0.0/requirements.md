## 目标

- 完成“听你五个”iOS 1.0.0 的 Apple 付费商务、商店材料、TestFlight 真机验收、中国大陆 App Store
  提交及审核闭环；审核通过后自动发布。
- Android 共用账号、会员、点数、内容和服务端能力保持同步，但不阻塞 iOS 上架。
- 由协调 Agent 连续执行代码、材料和平台配置；只在密码、验证码、法律/税务事实及真机确认等必须本人
  动作时提示负责人。

## 必须完成

- Native 1.0.0 支持 Apple（iOS）、+86 手机号 OTP 和手机号密码登录，统一16+轻量声明；手机号只可
  绑定到未占用账号，不自动归并账号或商业权益；注销后同一身份不重复领取100点。
- iOS 使用五档非自动续期会员，支持购买、重复购买顺延、恢复、退款重算、Sandbox/Production 隔离
  和跨端权益；AI 点数按 `ai-points-v1` 结算。
- 900句和既定免费清单免费；会员内容由服务端鉴权并支持最长72小时离线授权，学习数据不因会员到期删除。
- 语音 AI 使用腾讯云 ASR，文本 AI 使用 DeepSeek；不启用通义千问。
- App 图标和加载页使用 `assets/images/icon.png` 唯一母版；1.0.0 隐藏体系课程和未完成的学习报告，
  并阻断直接路由。
- App、公开法律页面和 App Store Connect 的版本、年龄、功能、供应商、隐私、内容和支付口径一致。
- App 及五档 IAP 只在中国大陆销售，并关闭自动在新增地区供应；备案类别保持工具，App Store 主要
  分类教育、次要分类工具。欧盟不在销售范围，DSA 不适用于本次提交。
- 使用一个正常 Production 手机号密码审核账号。该账号以正常100点完成非付费 AI 验收，通过真实
  Sandbox/TestFlight 购买获得会员；同一账号覆盖购买、恢复和注销，注销最后执行，不设置审核后门。
- Build `1.0.0 (3493761)` / commit `fca7436d497430db88cf1a29410d61878fd85fc5` 仅作录音回归已通过的历史候选保留。
  Build `3493762` 在最终归档前因首页仍保留课程选择、课程语义和按课程过滤而被覆盖，不用于截图、TestFlight 验收或送审。
  最终候选必须是本轮代码合入后从干净 `origin/main` 归档的 `1.0.0 (3493764)`，并由负责人完成新的
  TestFlight 真机验收。截图、归档证据和送审均不得沿用 `3493761`。
- Paid Apps Agreement、Apple 银行和税务状态有效后，完成五档 IAP 真实沙盒验收、截图、审核材料、
  负责人 TestFlight 真机验收，并把 App 与首次五档 IAP 放入同一审核提交。

## 明确不做

- 不修改、构建或部署冻结的 Vercel 用户网页；不恢复体系课程、学习报告或相关营销。
- 1.0.0 启用微信开放平台移动应用登录，使用锁定的 NoPay OpenSDK、服务端 code 交换和 Universal
  Link/AASA；微信支付继续严格禁用。外部 AppID、Universal Link 和平台审核只阻塞微信最终验收，
  不阻塞其他独立收口工作。
- 可视化 Ops 后台、`ops.readyoufife.com` 部署和管理员初始化延后到上架后，不作为1.0.0提交门禁；
  现有 Ops 代码、API、数据库表及支付/权益/风控/审计服务端能力保留。
- 不建设自动续期、免费试用转付费、年度套餐、AI 加量包、账号归并、审核后门或外部购买引导。
- 不把题库描述为“全部原创”，不在当前阶段主动删除、缩减或逐题复核现有题库。
- 不把 DeepSeek“不用于训练”专项证明作为1.0.0阻塞，也不作未经证明的绝对隐私承诺。

## 验收效果

- 真实用户能登录、购买/恢复会员、读取正确权益、使用有权访问的题库和 AI、同步学习数据并注销。
- 一个审核账号无需短信或个人 Apple ID，即可复现免费、会员、Sandbox 购买/恢复、AI 和最后注销流程。
- App、五档 IAP、截图和公开材料只面向中国大陆；Apple 平台不再保留其他地区或自动新增地区。
- 最终包、生产服务、公开页面、商店材料和隐私标签一致，微信登录已披露且无微信支付、未披露 SDK、未验签支付、
  内容越权、生产密钥泄露或无法追溯的发布产物。
- 可视化 Ops 未部署不影响用户登录、学习、支付验签、权益、AI 风控、注销、隐私自助或审计。
