# Native App 1.0.0 正式商业上线总需求

状态：已确认，执行中
确认日期：2026-08-24

## 目标

- 完成“听你五个”iOS 1.0.0 的商业化能力、生产部署、TestFlight 真机验收和中国大陆 App Store
  提交；审核通过后自动发布。
- Android 共用账号、会员、点数、内容和服务端能力同步完成，首批官网 APK 独立交付，不阻塞 iOS。
- 由协调 Agent 连续执行代码、材料、平台配置和审核闭环，只在必须本人完成的身份、法律、银行、
  税务、短信和真机验收动作时集中提示负责人。

## 必须完成

- Native 登录支持微信、Apple（iOS）、+86 手机号 OTP 和手机号密码；统一16+轻量声明，支持绑定、
  账号归并、注销和同一身份不重复领取100点。
- iOS 使用五档非自动续期会员，支持购买、重复购买顺延、恢复购买、退款重算、Sandbox/Production
  隔离和跨端权益；AI 点数按 `ai-points-v1` 发放与结算。
- 900句和既定免费清单免费；其余会员内容由服务端鉴权并支持72小时离线授权，学习数据不因到期删除。
- 语音 AI 使用腾讯云 ASR，文本 AI 使用 DeepSeek；不启用通义千问。
- 修复加载页ICAO字标裁切；1.0.0正式包隐藏未完成的学习报告和体系课程入口，并阻断直接路由访问，
  保留相关代码供后续版本继续开发。
- 建设独立可视化运营后台，包含管理员/客服权限、TOTP、用户、权益、订单、AI 风险、反馈/隐私请求
  和不可删除审计。
- App、公开法律页面和 App Store Connect 的版本、年龄、功能、供应商、隐私、内容和支付口径一致。
- 准备两个正常 Production 审核账号；最终构建来自干净 `origin/main`，经负责人 TestFlight 真机验收
  后与首批五档内购一起提交审核。

## 明确不做

- 不修改、构建或部署冻结的 Vercel 用户网页；不恢复1.0.0体系课程、学习报告及相关营销。
- 不建设自动续期、免费试用转付费、年度套餐、AI加量包、审核后门或外部购买引导。
- 不把题库描述为“全部原创”，不在当前阶段主动删除、缩减或逐题复核现有题库。
- 不把 DeepSeek“不用于训练”专项证明作为1.0.0阻塞，也不作未经证明的绝对隐私承诺。

## 验收效果

- 真实用户能以任一已支持身份登录、购买/恢复会员、读取正确权益、使用有权访问的题库和AI、同步
  学习数据并在 App 内注销。
- Apple 审核员无需短信或个人微信/Apple ID，即可使用两个公司控制的手机号密码账号完成完整体验、
  沙盒购买和注销检查。
- 最终包、生产服务、公开页面、商店材料及隐私标签相互一致，无未披露SDK、未验签支付、内容越权、
  生产密钥泄露或无法追溯的发布产物。
