## 执行规则

- 协调 Agent 连续推进非阻塞任务；需要密码、验证码、法律/税务事实或真机确认时集中提示负责人。
- App Store Connect 写入先读取、再最小修改、最后反查；敏感值不进入仓库、日志或聊天。
- Build 3493761 仅作历史候选冻结。已确认的首页课程入口移除、AI 持续标识、模型备案口径与注销恢复稳健性修正必须先合入
  `origin/main`，再从干净主线归档 Build 3493764 并重新真机验收。之后只修正文档、截图、地区或平台字段时不重建。
- App 和五档 IAP 只供应中国大陆，关闭自动新增地区；不执行 DSA。Vercel 始终冻结。
- 可视化 Ops 延后到上架后；支付验签、权益、点数、风控、审计和隐私自助服务端能力仍是提交门禁。

## 验证基线

- 归档核对 Bundle ID、1.0.0、最终 Build、`origin/main` SHA、签名、权限、PrivacyInfo、生产 URL、
  微信 NoPay SDK/Universal Link/AASA/服务端真值一致且无微信支付，以及体系课程和学习报告隐藏路由。
- 平台核对 Paid Agreement、银行/税务、CHN地区、自动新增地区关闭、备案、通知、截图、审核账号和 Notes。
- TestFlight 核对登录、录音、AI、点数、免费/会员边界、五档购买、恢复、重购、退款、注销及后台恢复。
- 提交前反向核对 App、五个公开页面、隐私标签、截图、IAP 与审核说明；审核通过后自动发布。
