## 阶段执行规则

- 当前阶段内自动选择最小完整闭环，执行、审查、验证和修复后自动继续，不重复确认已冻结事项。
- 生产数据库先备份和副本演练；Vercel用户Web始终禁止修改、构建或部署。
- 需要负责人动作时只由协调Agent在当前任务集中提示；密码、验证码和密钥不进入聊天。
- 银行未完成时继续阶段0—3及阶段4非Apple付费部分；真实内购沙盒和阶段5等待付费协议Active。
- 正式代码按短期分支PR合入main；TestFlight、生产部署和App Store提交只来自干净origin/main。

## 验证基线

- 受影响模块聚焦测试、TypeScript类型检查、API检查和迁移计划检查。
- 合入前运行`pnpm check:ci`；具备完整媒体资源的正式发布机运行`pnpm check`。
- 最终iOS归档核对Bundle ID、签名、权限、生产URL、版本、SDK签名和PrivacyInfo清单。
- TestFlight由负责人真机验收；通过后才选择该Build提交正式审核。
