## 描述

```text
听你五个是一款面向航空英语学习场景的实用工具，提供题库练习、音频播放、口语录制、文本转写、学习标记和进度记录等功能。相关内容由团队整理、制作并持续维护。

主要功能：
• 按题库、模块和话题进行日常练习
• 播放配套音频，记录自己的口语表达
• 按需发起语音转写、语法纠错和表达优化
• 收藏、标注、笔记并查看学习记录
• 登录后同步支持跨设备恢复的学习数据

资源模块、900句及部分题库内容可免费使用，更多题库内容需要会员权限。部分智能功能会消耗 AI 点数，操作前会显示预计消耗。会员采用一次购买、到期不自动续费的方式，并提供恢复购买入口。

听你五个是独立的航空英语学习工具，不提供官方考试评分、认证或通过承诺。
```
