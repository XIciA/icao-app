## 唯一审核账号

- 只建立一个公司长期控制的正常 Production 手机号密码账号；真实凭据不进入仓库、日志或聊天。
- 新账号正常获得100点，用于非付费 AI 功能；会员权益通过真实 Sandbox/TestFlight IAP获得，不以
  可视化 Ops 人工赠送作为提交前置条件。
- 同一账号按“完整体验→购买→恢复→最后注销”的固定顺序覆盖免费边界、五档商品、会员内容、录音、
  转写和文本AI；注销后不再安排其他审核步骤。
- 该账号已设置密码，审核员无需接收短信。若审核中被注销，下次提交前按正常流程恢复
  可用账号状态，不使用固定OTP、隐藏审核模式或支付后门。

## 剩余负责人动作

协调 Agent 可操作页面和录入非敏感材料；以下动作必须由负责人在受保护界面完成或即时确认：

1. Apple Account Holder需要时完成登录、双重认证和验证码。
2. 确认法律实体英文名称/地址与官方资料一致，并完成Paid Apps Agreement法律签署。
3. 确认Apple银行账户、税务身份和表格中的真实事实；密码、账户详情和税务值不进仓库或聊天。
4. 接收唯一审核账号的短信验证码并设置/保存密码。
5. 验证公开支持邮箱的真实投递、收件、回复和值守。
6. 在 iPhone 上完成新 Build 3493764 最终非付费和 IAP 矩阵确认。
7. Apple若新增CAPTCHA、本人/企业核验或权利证明，按页面要求配合。
