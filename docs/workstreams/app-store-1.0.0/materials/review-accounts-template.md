# App Store 审核账号说明模板

状态：无凭据模板。不得把真实手机号、密码、验证码或恢复信息写入本文件或任何仓库文件。

## 平台填写原则

- App Store Connect 的主要登录字段填写“完整体验账号”。
- 审核备注另列“购买与注销账号”的用途，但真实凭据仍只放受保护审核字段或附件中的受控位置。
- 两个账号均为正常 Production 账号，使用中国大陆手机号和密码登录，不要求审核员接收短信、安装
  微信或提供个人 Apple ID。
- 不设置隐藏审核模式、固定测试验证码、跳过支付验签或只对审核员开放的后门。

## 账号 A：完整体验账号

| 字段 | 填写值 |
| --- | --- |
| 用途 | 会员内容、语音转写、文本 AI、恢复购买和重复购买入口 |
| 手机号 | `【仅在 App Store Connect 受保护字段填写：REVIEW_ACCOUNT_A_PHONE】` |
| 密码 | `【仅在 App Store Connect 受保护字段填写：REVIEW_ACCOUNT_A_PASSWORD】` |
| 会员状态 | `【待提交前确认：有效会员，到期日覆盖预计审核期】` |
| AI 点数 | `【待提交前确认：足够完成转写、语法纠错和表达优化】` |
| 订单状态 | `【待提交前确认：恢复购买入口可核验，且不会阻塞重复购买路径】` |
| 注销状态 | 不用于注销，避免审核中断完整体验 |

## 账号 B：购买与注销账号

| 字段 | 填写值 |
| --- | --- |
| 用途 | 免费边界、五档商品、Apple 沙盒购买、恢复购买和账号注销 |
| 手机号 | `【仅在 App Store Connect 受保护字段填写：REVIEW_ACCOUNT_B_PHONE】` |
| 密码 | `【仅在 App Store Connect 受保护字段填写：REVIEW_ACCOUNT_B_PASSWORD】` |
| 初始会员状态 | `【待提交前确认：普通免费账号，无有效会员】` |
| 初始 AI 点数 | `【待提交前记录实际余额，不为文案虚构】` |
| 可删除状态 | `【待提交前确认：不存在阻止正常注销的身份或订单异常】` |
| 注销后重建 | 如审核中已注销，下次提交前用公司控制的同一手机号按正常流程重建并设密；不会再次赠送100点 |

## 提交当天双账号检查

- [ ] 手机号 + 密码从干净安装可登录，未触发锁定或强制短信验证。
- [ ] 账号 A 的会员和 AI 点数覆盖全部审核路径。
- [ ] 账号 B 能看到免费边界和五档商品，并能进行 Apple 沙盒购买。
- [ ] 恢复购买、重复购买提示和服务端权益更新正常。
- [ ] 账号 B 能在 App 内发起注销；注销后会放弃账号、学习数据、会员和 AI 点数。
- [ ] 账号 B 已设置密码，注销时通过当前密码完成近期身份重新验证；仅未设置密码的普通手机号账号
  使用短信验证码作为替代方式。不使用固定 OTP、隐藏审核模式或人工跳过复验。
- [ ] 审核期间 Production 登录、API、ASR、文本 AI、支付验签和注销服务持续可用。
- [ ] 凭据只存在于公司凭据管理位置与 App Store Connect 受保护字段。
