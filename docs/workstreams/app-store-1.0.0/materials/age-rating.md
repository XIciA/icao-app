# App Store 年龄分级建议

状态：已冻结产品口径；最终问卷必须按提交当天 App Store Connect 字段和最终候选包如实填写。

## 建议结果

- 对外年龄口径：16+。
- 不选择 Made for Kids，不描述为儿童产品。
- 注册/首次登录前由用户主动勾选“已满16周岁”；不收集出生日期、身份证、人脸等额外年龄证明。
- 不建设未满16周岁用户的监护人授权或儿童账号流程。
- 若 Apple 问卷自动结果低于16+，仍按已批准口径设置为16+；若字段或定义变化，选择语义最接近的
  真实答案并记录截图。

## 问卷回答基线

| 类别 | 建议回答 | 事实依据 |
| --- | --- | --- |
| 家长控制 | 否 | 无家长控制功能 |
| 年龄确认机制 | 是 | 登录前主动声明已满16周岁 |
| 不受限制的网页访问 | 否 | 仅打开产品预设外部链接 |
| 用户公开内容 | 否 | 无公开发布社区 |
| 社交媒体、用户聊天或私信 | 否 | 无用户间通讯；AI 结果不是用户间聊天 |
| 第三方广告或付费广告位 | 否 | 不接广告 |
| 粗俗语言 | 无 | 当前首发基线 |
| 恐怖主题 | 无 | 当前首发基线 |
| 酒精、烟草或毒品提及 | 偶尔 | 航空题库/资讯可能引用事件语境 |
| 医疗或治疗信息 | 偶尔 | 航空运行和应急场景可能涉及 |
| 成熟或敏感现实主题 | 偶尔 | 事故、伤亡、劫机等行业语境 |
| 现实暴力 | 偶尔 | 题库可能出现事件引用 |
| 枪支或其他武器 | 偶尔 | 行业事件语境可能涉及 |
| 性内容或裸露 | 无 | 当前首发基线 |
| 赌博、模拟赌博、竞赛或抽奖箱 | 无 | 无相关功能或营销 |
| 年龄类别与覆盖 | 16+ | 全端统一；不进入儿童分类 |

## 最终内容抽查词表

在最终题库、图片、音频、AI 功能和可访问资讯中抽查下列主题，不以关键词命中替代人工判断：

- 炸弹、劫机、武器、枪支；
- 伤亡、事故、紧急医疗、疾病；
- 酒精、烟草、毒品；
- 暴力、威胁、成熟或敏感现实事件；
- AI 可能生成的超出题库基线的成熟内容。
