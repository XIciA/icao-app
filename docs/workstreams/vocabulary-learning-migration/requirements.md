# 单词学习功能与资源迁移需求

状态：已确认

更新时间：2026-07-13

工作目录：`docs/workstreams/vocabulary-learning-migration/`

## 1. 核心问题

当前 React Native App 已有单词学习页面和少量演示词汇，但仍属于本地示例：词书规模不真实，学习状态不能完整延续，发音、完成页、错词复习和词汇测评等行为也未形成正式闭环。

本任务以 `/Users/zhouyide/Desktop/icao项目/feizhuicu` 为**功能逻辑和单词资源参考**，把当前 App 的单词模块完善为可用于内部测试的真实功能。`feizhuicu` 不是本任务的 UI 设计稿，也不是可直接复制的代码或题库来源。

## 2. 目标

- 用真实词书资源替换当前 30 条演示词汇。
- 完成“选择词书 → 查看词书与单词 → 学习判断 → 发音与释义 → 本轮完成 → 错词复习”的完整学习闭环。
- 保留学习状态、收藏和测评结果，使用户退出 App、重新登录或更换同账号设备后仍能继续使用。
- 保持 `icao-app` 已有导航、视觉语言和原生交互方式，不照搬 Web 页面。

## 3. 参考与归属边界

- 功能与资源参考：`feizhuicu` 当前实际启用的单词学习、词汇测评和词书数据。
- 产品与 UI 归属：以 `icao-app` 当前 React Native 页面、设计令牌、导航和账号规则为准。
- 只取用实现本需求所需的规则与资源；不得复制 Web 组件、路由、DOM、CSS、浏览器存储或浏览器语音代码。
- 不迁移 `feizhuicu` 的题库内容、题库页面、生产路由和无关字段。
- 单词学习与“题库学习页内的 AI 查词”是两项独立能力；本任务不改造 AI 查词。

## 4. 功能范围

### 4.1 词书选择与详情

- 提供“ICAO 考前预习”“ICAO 4 必会”“ICAO 5 冲刺”三本词书。
- 支持选择一本或多本词书开始学习。
- 展示每本词书的总数、已学习数量、学习进度，以及认识、模糊、忘记、记错和收藏统计。
- 支持继续学习、重新学习和进入单词列表。
- 重新学习只重置该词书的掌握状态，保留已收藏单词，并在执行前明确提示影响。

### 4.2 单词列表

- 支持按英文词/短语、中文释义、例句和例句译文搜索。
- 支持按全部、未学、认识、模糊、忘记、记错和收藏筛选。
- 支持展开查看英文词/短语、中文释义、例句和例句译文。
- 支持收藏/取消收藏，并可直接学习当前搜索或筛选结果。
- 无结果或资源读取失败时提供明确状态和返回/重试入口。

### 4.3 单词学习

- 每轮按选中的一本或多本词书组成学习队列，展示本轮位置与进度。
- 单词出现时先让用户回忆民航语境中的含义，再选择“忘记了 / 模糊 / 认识”。
- 选择后展示释义、例句和例句译文；用户可把误判为认识或模糊的单词改为“记错”。
- 支持单词收藏、退出学习、进入下一词和发音重播。
- 单词首次出现时自动播放英文词/短语；答案揭示后可连续播放英文词/短语及英文例句。
- 发音不可用时不得阻断学习，应提供明确反馈并允许继续操作。

### 4.4 本轮完成与复习

- 完成一轮后展示本轮总数及认识、模糊、忘记、记错统计。
- 支持再来一轮、只复习本轮忘记/记错、查看本轮单词和返回词书选择。
- 没有忘记或记错单词时，“只复习错词”不可误触发空学习流程。

### 4.5 词汇测评（本稿默认纳入）

- 单词入口提供独立词汇测评。
- 测评共 30 题，每题 10 秒，用户根据英文词/短语判断“认识 / 不认识”，超时按不认识处理。
- 题目根据阶段表现调整 ICAO 3/4/5 级词汇比例，同一轮不重复出题。
- 用户选择“认识”后可在看到释义时改为“记错了”。
- 完成后展示总正确率、各级词汇表现、能力判断、学习建议和错词清单，并支持重新测评或回到单词学习。
- 测评必须明确为学习诊断，不代表官方 ICAO 等级或考试结论。

### 4.6 学习数据

- 单词掌握状态、收藏、显式重置和最近一次测评结果应被稳定保存。
- 数据遵循当前 App 的强制登录、账号隔离、自动同步、失败重试和同账号恢复规则。
- 网络波动或同步失败不得静默丢失用户刚完成的学习操作。

## 5. 单词资源范围

以 `feizhuicu` 当前实际启用的三本词书为迁移基线：

| 词书 | 数量 |
| --- | ---: |
| ICAO 考前预习 | 360 |
| ICAO 4 必会 | 372 |
| ICAO 5 冲刺 | 106 |
| 合计 | 838 |

资源要求：

- 每条保留稳定身份、所属词书/等级、英文词或短语、中文释义、英文例句、例句译文和来源追溯信息。
- 迁移后总数、分书数量、稳定身份和文本内容可与来源对账，不混入备份稿、替换稿或题库数据。
- 当前来源的 838 条记录均无音标和录音文件；本轮不额外生成音标或迁移真人录音，但用户仍须能使用系统英文发音完成学习。
- 不因迁移而批量改写、润色或扩充现有单词、释义、例句和译文；发现内容问题时先形成清单，不在本任务中擅自改题。
- 资源缺失、加载失败、网络不可用和访问超时时必须提供明确提示与重试入口。

- 不迁移任何题库内容、题库音频或题库学习逻辑。
- 不重做当前 App 的全局导航、品牌视觉或其它发现页功能。
- 不修改现有题库内 AI 查词、模型 Prompt、AI 额度或 AI 服务。
- 不在本轮新增真人发音库、批量补音标、资源下载包或完整离线学习。

## 7. 验收效果

- 三本词书共 838 条真实资源在 App 中可读取、可对账，演示词不再作为正式数据源。
- 用户可以完成多词书选择、词书详情、搜索/筛选、收藏、完整学习、完成统计和错词复习。
- 发音、释义、例句和译文在学习过程中的显示与播放时机正确，失败不会导致崩溃或卡死。
- 学习状态、收藏和测评结果在 App 重启后保留，并能按现有账号规则完成同账号恢复。
- 30 题测评的计时、难度调整、结果、建议和错词清单可完整运行，且不误导为官方等级。
- 页面继续符合 `icao-app` 当前原生移动学习体验，并通过真实渲染检查；Web 外观和代码没有被照搬。
- 未修改设计仓库、题库内容、AI 查词和本任务之外的功能。
