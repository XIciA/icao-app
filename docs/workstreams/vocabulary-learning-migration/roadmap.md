## 2. 阶段 1：内容资源与远程读取

目标：把 838 条来源资源转成 `icao-app` 可维护、可校验、可远程读取的正式内容。

允许范围：`content/vocabulary`、内容工具、contracts、API vocabulary 模块、App repository 和对应测试。

禁止范围：不改词义与例句，不复制题库或 Web 页面，不执行数据库迁移。

验收：三本数量为 360/372/106；合计 838；字段完整、ID 唯一；未登录 API 被拒绝；远程/ETag/cache/错误重试通过。

## 3. 阶段 2：本地状态与云同步

目标：让掌握状态、收藏、重置和最近测评结果先本地保存，再按账号同步。

允许范围：单词持久化模块、现有 learning sync 的单词文档接入、API document 合并逻辑及测试。

禁止范围：不新增表，不清空现有题库学习数据，不改变 annotations 行为。

验收：重启恢复、首次绑定、云端拉取、跨设备较新状态胜出、显式重置、退出/注销清理和失败 outbox 均通过。

## 4. 阶段 3：单词学习闭环

目标：用真实词书完成从选择到错词复习的原生学习流程。

允许范围：单词 feature 组件、现有 `/content/vocab` 接入、`expo-speech` 和 UI 测试。

禁止范围：不改全局导航、其它发现页或题库内 AI 查词。

验收：多词书队列、搜索筛选、收藏、认识/模糊/忘记/记错、自动/手动发音、例句、完成统计、再来一轮和错词复习均可用。

## 5. 阶段 4：词汇测评

目标：完成 30 题、10 秒、自适应难度和结果闭环。

允许范围：测评引擎、测评页面、最近结果同步和测试。

禁止范围：不新增官方评分、AI 测评或未确认维度。

验收：题目不重复；超时正确处理；模式按最近五题升降；认识后可纠错；结果、建议、错词和“非官方等级”提示完整。

## 6. 阶段 5：运行验收

- 验证 `/health/ready`、未登录拒绝、登录后的 838 条内容和 ETag。
- 重建 Development Build，在 iOS 模拟器与可用物理 iPhone检查发音、计时、后台/返回和核心学习链路。
