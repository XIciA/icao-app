# 全局动画生命周期代码审查

范围：当前 iOS、Android、EdgeOne 产品 Web。用户追加授权检查同类视觉跳位/闪动并修复；使用指南内部逻辑由并行任务负责。扫描原生与共享 Modal、BottomSheet、动画结束回调、数据/锚点清空和条件卸载；不以静态审查声明实机动画流畅度通过。

| 类别 | 代码发现 | 处理与依据 |
| --- | --- | --- |
| 题库范围菜单 | 关闭时定位锚点变undefined，原生fade仍保留子视图，top/left回退默认值 | visible与anchor分离；关闭只改变可见性，下一次打开才更新坐标。取消、系统返回、同范围与真实切换均验证 |
| 原生共享AppModal | 倍速、标注选择等父页关闭时同步清空位置或内容，淡出期间子树会先消失或回退 | 共享useLastVisibleValue保存最后已提交的可见内容；只影响呈现，不保留或复制业务状态，不改变回调/请求所有权。Web现有立即卸载的portal不增加退场等待 |
| 共享BottomSheet | 已保留原生外层到动画结束，但仍使用实时children/footer，关闭清空picker/lookup会改变高度和标题 | 同一保留机制冻结最后可见children/footer/scrollable/标签直到退场结束；关闭期间交互与无障碍访问仍禁用，快速重开使用新内容 |
| 个人资料、查词、导出选择、答题卡、随身听队列/间隔、会员说明/额度详情 | 检查各共享弹层调用，有的关闭后父状态清空/切换分支 | 由共享BottomSheet修复，不对每个页面添加延时或复制弹层 |
| 登录方式绑定/手机号验证 | 父页直接条件卸载整个弹层；成功验证的父回调也立即卸载 | 弹层本地控制visible，既有业务成功后退场，onClosed通知父页移除；手机号授权和发码链路不变，不等待网络延时充当动画 |
| 更新/到期提醒 | 条件渲染BottomSheet导致取消时没有退场机会 | 控制visible并保留组件，清空数据由共享呈现机制稳定退出；下载锁、账号/路由安全条件仍保留 |
| 登录法律文档 | 条件卸载带slide的原生Modal | 保留Modal节点并控制visible，内容沿用共享最后可见值；不改协议内容或同意逻辑 |
| 题目切换、时间轴、随身听呼吸动画、原生Stack | 检查动画完成与取消、重入保护和业务状态归属；题目离场finished后才切题，随身听effect清理cancelAnimation，播放进度与拖动状态隔离 | 本轮未发现与清空锚点/关闭内容同根因的新缺陷，保留现有实现；指南相关接入由另一任务复核 |
| 强制授权/退出账号/离开不安全页面 | 部分业务边界会主动移除整个页面或拒绝继续操作 | 安全与账号隔离优先；不为了视觉退场延后真实权限撤销，不为此扩大业务改动 |
| 非现行课程页/旧站平行实现 | 作为检索结果审阅；不属于当前产品交付目标 | 不修改、不构建、不部署；当前共享组件修复不增加旧站专用分支 |

回归验证包括淡出期间最后内容及坐标、不可交互、重开替换新内容、正常完成后通知一次、同范围不写入、真实切换保存失败可重试。原始扫描清单位于任务检查目录 `/tmp/icao-followup-five/overlay-inventory.txt`、`all-modals.txt`、`animation-inventory.txt`；最终结果写入本任务交付记录。
