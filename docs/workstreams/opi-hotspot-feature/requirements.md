# OPI 热点需求

状态：已确认

## 目标

将“发现 → OPI 热点”建设为按日期组织的 OPI 抽样练习包。每条资讯引用现有 OPI 题库中的话题和题目，不复制题目文本或答案。

## 用户流程

1. 热点列表按日期倒序展示标题、考点、话题数和题数。
2. 点击资讯进入独立全屏详情页。
3. 详情页按话题展示真实 OPI 问题文本。
4. 点击“开始学习”进入共享的 `QuestionBankStudyScreen`。
5. 退出学习或完成报告后返回对应热点详情。
6. 学习记录通过 `[热点]` 分类前缀与普通 OPI 记录区分。

## 数据边界

- `content/question-banks/opi-hotspots.json` 只保存日期、考点和 OPI ID 引用。
- 问题、答案、双语内容、音频和学习行为以统一 OPI 题库为唯一来源。
- 当前阶段使用打包 JSON，不接入新的 API、数据库或在线编辑后台。
- 图片题不进入热点练习。

## 验收

- 旧硬编码热点实现不再出现在运行代码。
- 所有热点 ID、日期、话题和题目引用通过强制校验。
- 列表、详情、学习、返回和学习记录链路均可用。
- Web Preview 与正式域名完成登录后的真实链路验证。
