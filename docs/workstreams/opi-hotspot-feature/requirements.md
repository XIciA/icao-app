# 需求文档：OPI 热点功能 (OPI Hotspot Feature)

## 1. 目标

将"OPI 热点"建设为基于现有 OPI 题库随机抽样的考点动态练习包功能。每条"考试资讯"即一套题，用户可按日期快速查阅当日涉及的话题与问题，并无缝进入与主题库体验完全一致的卡片学习模式进行高效备考。

## 2. 范围与模块要求

### 2.1 热点资讯列表页（第一级目录）
- 展示"每日考试资讯"列表（按日期倒序）。
- 每条资讯卡片包含：日期标题（如 `7月9日 考试资讯`）、考点地点标签（如 `广汉考点`、`绵阳考点`）、包含的话题数量。
- 提供"查看详情"入口。

### 2.2 考点资讯详情页（第二级目录 · 全屏导航页）
- 点击"查看详情"后 push 全屏导航页面。
- 呈现当日考试资讯包含的若干个话题（Topics）。
- 每个话题下展开列出具体的问题列表（Questions）。
- 页面提供"开始学习"主按钮。

### 2.3 一套题的组成规则
- **一条考试资讯 = 一套题**。
- 每套题从 OPI 题库中随机抽取约 5 个话题，每个话题下抽取约 6 张卡片，合计约 30 题。话题和卡片数量按需可调。
- 每个话题不一定包含该 OPI 原生话题下的所有卡片，可以只抽取部分。
- **题目来源硬性约束**：所有问题必须 100% 抽取自当前已有 OPI 题库（`content/question-banks/banks/opi/`），不引入平行题目文本。
- **Word 资料定位**：`原始资源资料/OPI热点/` 下的 Word 文档仅作为日期、考点地点及话题内容的参考，用于辅助使抽题结果更贴近真实考情。不要求与 Word 内容一一映射。可以先做随机抽题，后续再用 Word 辅助提高准确率。

### 2.4 卡片学习模式（学习交互）
- 用户在详情页点击"开始学习"后，将当日考试资讯包含的所有抽取题目组装为一个"热点练习包"。
- 学习交互、界面布局、录音/音频、参考答案展示、双语切换及卡片翻页体验，与现有 OPI 题库卡片学习模式（`QuestionBankStudyScreen`）**完全保持一致**。

### 2.5 学习记录区分
- 热点学习产出的 `LearningRecord` 需要区分来源，使其与常规 OPI 题库学习记录可分辨（如增加 `source: 'hotspot'` 标记或在 `categoryTitle` 中嵌入 `[热点]` 前缀）。

## 3. 明确不做（Out of Scope）

- **不做独立题目数据维护**：绝不在热点模块中新增或维护独立的题目文本/答案数据。
- **暂不做图片题**：本次迭代不包含图片类型考题（`opi-category-08`）的抽取与展现。
- **不做云端/实时后台同步**：第一阶段使用本地结构化的热点资讯配置文件（JSON 映射）。
- **不做偏离主题库的全新练习 UI**：卡片学习阶段直接复用现有题库练习组件，不做额外的自定义学习界面。

## 4. 验收标准

1. 用户在"发现→OPI 热点"点击任一日期的考试资讯，均能看到对应的考点地点标签及相关话题与问题列表。
2. 详情页展示的问题与其对应的 OPI 主题库题目（题目文本、参考答案、音频/TTS）完全一致。
3. 点击"开始学习"后能顺利进入卡片练习模式，卡片内容为当日热点抽取的题目集合，功能与体验与主题库学习完全一致。
4. 热点学习记录可与常规 OPI 学习记录区分。
