# 五套题库全量文本低级错误审查需求

状态：本地审查、修复和 ECS 发布已完成；Web 最终提升与交付收口中

## 目标

对 `content/question-banks` 五套正式题库的全部用户可见文本做一次可追溯的全量低级错误审查，
直接修复能够唯一判断的乱码、OCR、拼写、粘词、标点、空格和低级语法错误，只把必须依赖
音频或专业事实判断的极少数项目留给人工。

## 范围

纳入题库、分类、话题、卡片中的标题、说明、双语正文、参考答案、选项、学习标签和图片
无障碍文本。`audioText` 与 `audioTextZh` 作为文本纳入，但不读取、播放或识别音频文件。

不修改卡片 ID、目录顺序、题型、正确答案索引、音频路径、时长、资源映射和播放器；不做
答案正确性重审、翻译美化或普通书面英语式改写。

## 完成标准

- 正式维护源中的每一个用户可见文本值都有覆盖记录。
- 所有扫描候选均收敛为已修复、人工保留或超出范围，没有未分类项。
- 修复账本可以从原文指纹幂等重放，账本外正文变化为零。
- 题库构建、完整内容检查、静态词典、ASR 文本资产与全仓检查通过。
- App 内嵌、ECS、Web 正式内容与本地审定结果一致，且有回滚证据。
- 最终报告列出全部修复和人工审核项，并记录共享显示版本。
