# 五套题库文本质量执行路线

## 阶段

1. 冻结 release、数量、源文件和衍生资产摘要。
2. 建立抽取、扫描、指纹修复、覆盖和只读门禁。
3. 完成确定性扫描、全量语言复核、跨字段复核和二次审查。
4. 应用修复，封存人工清单和覆盖记录。
5. 升级内容版本，构建题库并同步查词与 ASR 文本衍生资产。
6. 运行完整内容、全仓和页面渲染验收。
7. 生成纯文本增量包，备份并发布 ECS/Web，完成线上验证和回滚记录。
8. 更新显示版本、阶段日志、长篇报告和收口结论。

## 暂停条件

只有需要听音、判断答案专业正确性、改变题意或遭遇无法隔离的并行题库修改时才停止自动
修复。普通拼写、格式、工具和验证问题在当前阶段内自主处理。
