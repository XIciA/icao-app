# OPI 参考答案补全与双语正式版路线图

状态：已确认并执行

更新时间：2026-07-28

## 阶段 0：新基线

- 以 v9 问题锁、最终英文答案审计和线上 v9 checksum 为输入。
- 冻结 899 个现有答案、158 个来源不足项、10 个图片延期项和 10 张图片 hash。
- 建立新的空白答案补全工作项；不继承旧生成状态。

## 阶段 1：补齐 168 份英文答案

- 先处理 28 张校准批，包含全部图片依赖题和代表性高风险题。
- 其余 140 张按话题分为 5 批。
- 每批执行“主 Codex 生产与同步校对—独立 Codex 一次全量只读复核—主 Codex 裁决—机器校验—hash 封存”。
- 英文关闭时确认 1067 份答案完整、899 个原锁值保持或有明确例外。

## 阶段 2：翻译 1067 份中文答案

- 只读取英文关闭锁。
- 按话题生成约 20 个翻译批次。
- 主 Codex 全量翻译和同步校对；机器全量检查数字、缩写、语言和段落对应。
- 航空程序、数值、公司/机型和图片答案逐项重点复核，普通项累计分层抽检不少于 300 张。
- 同批出现 3 项同类实质错误或抽检错误率达到约 2% 时，升级该批为独立全量复核。

## 阶段 3：全库锁定与正式应用

- 生成逐卡双语答案、来源、图片观察、复核、批次 hash、事实来源和最终质量报告。
- 构建 v10 候选并验证问题锁、数量、字段、重复、相似度和翻译对应。
- 一次性应用到唯一 OPI 正式维护源并更新 registry。

## 阶段 4：检查、iOS 与生产发布

- 运行 OPI 正式验证、内容构建、全量内容检查、项目检查和题库测试。
- 按用户 2026-07-28 最新决定，取消本轮 iOS 模拟器验收；发布后由用户自行完成 iOS 真机文本与展示验收。
- 精确提交本任务文件、同步并推送 main。
- 备份活动 v9 和生产数据库，验证隔离恢复后导入 v10。
- 验证健康、鉴权、数量、四字段、代表卡、checksum、ETag/304 和学习数据数量不变。
- 保留 v9、v8 和数据库备份作为回滚点。
