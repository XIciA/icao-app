# 响应式 Web 适配需求文档

状态：已确认  
更新时间：2026-07-22（轻量大屏方案已确认）

## 1. 目标

基于现有 Expo / React Native 项目交付一套响应式 Web，使同一 Web 应用同时适配手机浏览器与 PC 浏览器，并保持 iOS、Android、Web 三端可持续共享核心功能更新。

## 2. 范围

- 一套 Web 应用，同一套路由、账号、题库、学习数据和业务规则。
- 手机 Web：视觉与学习流程接近现有移动 App；使用真实浏览器尺寸；移除当前居中的手机外框模拟效果。
- PC Web：继续使用现有 App 页面、底部导航和单栏交互，只限制内容在大屏上的横向拉伸并居中显示；当前阶段不新增桌面导航或多栏结构。
- 三端更新：新增或调整业务功能时，优先共享数据、接口、状态、业务逻辑和基础组件；仅在布局、交互和系统能力存在差异时分别适配。

## 3. 模块要求

- 全局响应式布局：手机、平板、PC 宽度下均可正常使用。
- 导航：手机与 PC Web 均延续现有移动式底部导航和相同入口。
- 页面：题库、发现、我的、学习、内容、账户等既有页面均支持手机与 PC Web。
- 学习链路：题库、目录、学习卡、音频、记录、标注等核心流程在两类 Web 布局中可用。
- 复用边界：共享现有 `features`、通用 UI、设计 token、路由业务、API 与数据契约；允许 Web 桌面布局、浏览器存储、录音/音频等平台能力有独立适配。

## 4. 明确不做

- 不开发两套独立 Web 项目或重复业务逻辑。
- 不重新设计或重做现有 iOS / Android App。
- 不新增 AI、支付、会员、下载、离线学习等业务能力。
- 不改变后端、账号、同步规则或题库数据来源。
- 当前不单独建设桌面信息架构、侧边栏、顶部导航或多栏页面。

## 5. 验收效果

- 手机浏览器呈现无手机外框、适配真实屏幕的移动 Web。
- PC 浏览器中的页面背景、渐变和全屏遮罩保持铺满浏览器；现有 App 的卡片、按钮与主体内容居中显示，内容宽度为浏览器宽度的 88%，最大不超过 1280px。
- 同一账号下，手机 Web、PC Web 与 App 使用同一业务数据和核心学习流程。
- 后续业务功能可实现一次核心开发、三端复用，并以必要的平台适配完成交付。
- 现有 iOS / Android App 无核心功能和视觉回归。
