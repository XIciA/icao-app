# 响应式 Web 适配路线图

状态：已确认  
更新时间：2026-07-22
当前进度：W0、W1 已完成，等待 W2

## 1. 阶段总览

| 阶段 | 目标 | 核心产出 | 进入下一阶段标准 |
| --- | --- | --- | --- |
| W0 | 响应式基础 | 真实 Web 视口与布局模式 | 手机 Web 无手机壳且关键弹层尺寸正确 |
| W1 | Web 大屏轻量限宽 | 统一的比例宽度、最大宽度和居中容器 | 典型页面在手机与 PC 无异常拉伸 |
| W2 | 核心页面抽查与最小修正 | 题库、目录、学习页的溢出与定位修正 | 核心学习链路在手机与 PC 可用 |
| W3 | 全页覆盖与验收 | 全部既有 Web 页面响应式收口 | 关键路由、视觉和导出验证通过 |
| W4 | 收口 | 阶段记录与完成说明 | 无阻塞风险、文档收口 |

## 2. W0：响应式基础

- 目标：以真实浏览器宽高替代固定 `375 × 812` 画布，建立手机、平板、PC 布局模式。
- 允许：`src/components/platform`、响应式 Web 工具、直接依赖视口尺寸的布局组件及测试。
- 禁止：改变共享业务规则、原生布局或音频/录音生命周期。
- 验收：手机 Web 无外框；抽屉、弹层和播放器在不同手机尺寸无明显遮挡。

## 3. W1：Web 大屏轻量限宽

- 目标：保留现有 App UI 与交互，仅防止 Web 内容在 PC 大屏上无上限横向拉伸。
- 允许：Web 全局容器、宽度计算及对应测试。
- 禁止：新增侧边栏、顶部导航、多栏结构，或修改路由、页面和业务逻辑。
- 验收：手机和平板保持全宽；桌面背景铺满浏览器，主体内容宽度为浏览器宽度的 88%，最大 1280px，并居中显示；底部导航继续可用。

## 4. W2：核心页面抽查与最小修正

- 目标：抽查题库首页、目录、学习页、音频/答题/记录页面在限宽容器中的表现，只修复真实出现的问题。
- 允许：少量 Web 布局样式和测试。
- 禁止：复制题库数据、重写学习状态或改变音频/录音职责。
- 验收：可完成“题库 → 目录 → 学习卡 → 音频 → 记录/标注”链路；无明显溢出、错位或不可达操作。

## 5. W3：全页覆盖与验收

- 目标：覆盖发现、我的、内容、账户、认证、信息和状态等既有 Web 路由，修复响应式差异。
- 允许：相关页面的 Web 布局与样式、可访问性和测试。
- 禁止：新增业务功能、后端改动或生产部署。
- 验收：手机、平板、PC 抽查无明显溢出、遮挡或不可达操作；原生核心入口无回归。

## 6. W4：收口

- 目标：复查 diff、完成验证、记录未做事项和风险。
- 产出：`phase-log.md`、`closeout.md`。
- 验收：`pnpm check`、`pnpm check:web` 通过；关键路由完成三类宽度视觉检查；无未经确认的依赖、部署或范围扩张。
