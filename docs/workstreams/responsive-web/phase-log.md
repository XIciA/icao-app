## W0：响应式基础

### 已完成

- 移除 Web 固定 `375 × 812` 手机画布和外部手机框，应用直接使用真实浏览器视口。
- 建立统一 Web 布局模式：手机 `< 768`、平板 `768–1023`、桌面 `>= 1024`。
- Web 视口尺寸改为跟随 `useWindowDimensions`，供既有抽屉、弹层和播放器复用。
- 增加布局边界、真实视口和无手机框回归测试。

### 复用与边界

- 继续复用现有 Expo Router 路由、页面、主题、题库数据、学习状态和共享组件。
- 未复制业务数据，未引入第二套页面或生命周期所有者。
- 未修改原生布局、音频/录音生命周期、后端或部署配置。

### 验证证据

- `pnpm check` 通过：应用 48 个测试套件、216 个测试；API 3 个测试文件、177 个测试。
- `pnpm check:web` 通过，Expo Web 生产导出成功。
- 本地渲染检查覆盖手机 `390 × 844` 和桌面宽度，两者均无外部手机框。

### 未做事项与风险

- 桌面导航、内容最大宽度和多栏布局属于 W1/W2，尚未开始。
- 本地环境没有已登录会话，因此未完成学习页的登录后人工截图；这不阻塞 W0。学习页已进入同一 Web 导出并由现有测试覆盖，登录后视觉复核放在 W2。
- 未执行部署；W0 不包含后端或生产环境变更。

### 结论

W0 验收条件已满足，可以进入 W1；是否启动 W1 由用户另行确认。

## W0 补充：本地 UI 验收入口

- 登录页右下角增加“开发者 · 免登录验收”，仅在 `pnpm web:acceptance` 或 `pnpm web:acceptance:export` 构建中显示。
- 验收模式复用同一 Expo Router 页面、共享组件和本地题库，只放开路由；`session` 保持为空，不生成认证令牌，不触发账号绑定或云同步。
- 页面显示“UI 验收模式 · 退出”标识；刷新页面后内存状态自动清除。
- `pnpm web:export` 强制写入关闭值，验收与正常导出均清理 Metro 缓存，iOS 和 Android 无法启用；新增构建边界检查及路由、入口和平台测试。
- 该入口解决无本地账号时的页面视觉验收，不替代真实登录、云同步、AI、账号安全和生产集成验收。
- 验证通过：`pnpm check`（App 49 个测试套件、221 个测试；API 177 个测试）、正常 Web 导出、验收 Web 导出及 iOS 26.3 模拟器 Development Build；桌面渲染对照确认正常导出无入口、验收导出显示入口。

## W1：Web 大屏轻量限宽

### 已完成

- 根据用户重新确认的轻量方案，将 W1 从桌面导航与多栏壳缩减为全局大屏限宽；手机、平板、PC 继续使用同一 App UI、底部导航、路由与业务逻辑。
- 桌面 Web 内容宽度采用浏览器宽度的 88%，最大 1280px，并在浏览器中居中；手机和平板保持 100% 可用宽度。
- 根据首轮人工截图反馈，将限宽职责从根 `AppViewport` 下移到共享 `AppContentFrame`：页面背景、渐变、滚动画布和模态遮罩保持浏览器全宽，卡片、按钮及主体内容限宽。
- `useAppViewportDimensions.web.ts` 同步返回限宽后的应用内容宽度，使学习页弹层、工具栏和尺寸计算与实际内容容器一致。
- 更新需求、技术方案、技术盘点和路线图，移除当前阶段的侧边栏、顶部导航和多栏要求。

### 复用与边界

- 继续复用现有页面、底部导航、路由、题库、学习状态、认证与平台 adapter。
- 未新增 Web 页面副本、桌面导航或业务分支；未修改 iOS / Android 实现、后端或部署。

### 验证证据

- 响应式宽度及 Web 容器相关单元测试通过，共 3 个测试套件、16 个测试。
- `pnpm check` 通过：App 50 个测试套件、229 个测试；API 3 个测试文件、177 个测试。
- Web 验收导出和 TypeScript 检查通过。
- 真实浏览器渲染：390px 主体内容宽度 390px；1440px 主体内容宽度约 1267.2px，左右各约 86.4px；1920px 主体内容宽度 1280px，左右各 320px；页面根背景保持浏览器全宽。
- 题库首页、听力目录和听力学习页均无横向溢出，现有入口与路由可用。

### 明确未做

- 未新增 PC 侧边栏、顶部导航、多栏布局或键鼠增强。
- 未逐页重写 UI；W2 只抽查并最小修复限宽后真实出现的局部问题。

### 结论

W1 轻量限宽目标已满足，可以进入 W2 核心页面抽查与最小修正。
