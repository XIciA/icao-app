# 1.2.1 B 方案启动衔接

本任务采用用户选择的 B：原始 Logo、听你五个字标、READ YOU 5。三端均使用同一张预合成透明品牌图，原始 Logo SHA 保持不变；字标预渲染，避免字体加载引起尺寸变化。

iOS 原生启动图与 React 加载面均使用 320pt 画布，Android 使用 216dp 画布以适配 Android 12 系统启动图遮罩；画布均在全屏根视图中心，不使用安全区重复偏移。状态提示绝对定位，不参与品牌图排版。原生加载图解码后才隐藏原生 Splash；正常结束不设置最短等待。字体恢复和账号恢复沿用同一画面。

正式 Web 使用 EdgeOne 专用 HTML 启动壳，直到 React 账号恢复完毕才移除；不暴露下层的第二张加载面。冻结 Vercel 的组件与启动壳不变。约 1.5 秒后显示“正在打开…”，前后台恢复不重新创建启动壳。

保留所有账号恢复、注销待处理和安全检查；真实失败沿用现有可重试错误状态，不将超时伪装为成功。

此文件记录本轮实现，不新增项目长期约束。测试和发布结果另记发布记录。
