# 听你五个本地管理后台

## 打开
双击桌面「听你五个后台.command」，自动使用 Safari 打开。电脑联网时自动通过 SSH 连接服务器，本机 Chrome 屏蔽该地址时无需修改安全设置，使用 Safari 即可。浏览器地址固定为 http://127.0.0.1:4173 。不需要域名、不需要登录阿里云、不提供注册和网页登录。

## 五个页面
- 用户反馈：日期/类型筛选，打开反馈全文和图片。只查看。
- 点击统计：按日期、题库/附加功能、按钮统计次数；支持排序、分页、CSV。只收集接入后的已登录用户主动点击。没有历史点击补算。
- AI 用量与费用：按日期、用户 ID、功能和成功/失败筛选；用户汇总、调用明细、CSV。单位与人民币估算分别显示。费用缺失显示待确认，不当作零元。
- AI 规则设置：调整体验总量、会员每周总量、各 AI 功能消耗；先预览再保存，确认后立即全局生效，包括已有会员。保留已使用单位，按当前总额度重算剩余百分比；历史请求不按新单价重新计费。页面下方可查看操作记录，或预览、确认全员基础额度重置。
- 用户权益：以表格查看所有账户、手机号、ID、注册时间、订单和会员状态，支持筛选、分页及当前页CSV导出。点击详情打开权益、订单、AI用量、反馈、操作记录五个页签。可赠送 7/31/93 天或自定义天数，补满当前周期，额外赠送 AI 单位。额外赠送有效期固定 30 天，优先扣除较早到期批次。

## 生效与边界
保存后写入真实服务器。会员顺延、AI 消耗和余额在下一次服务端请求使用最新状态；客户端显示在刷新权益后更新，不承诺后台修改瞬间推送到每一个离线设备。本次新增客户端代码在个人页约每 30 秒刷新，并显示额外赠送可用提示。

规则统一适用于所有用户；补满按当前规则上限恢复基础额度，保持原到期时间，不删除历史消耗流水。赠送会员与购买订单分开保存，不伪造支付。

正式权益与 TestFlight 沙盒权益分开选择。单用户写操作需要先选用户、填写原因并核对确认页。全员重置先选择环境、填写原因，再显示受影响人数；确认后恢复所选环境的基础额度，包括已用完体验额度的普通账户，保留额外赠送与会员状态。普通额度配置为0时，重置后仍为0。预览10分钟有效；规则或账户状态变化需重新预览；有AI请求处理中则整批不执行，稍后重试。

点击上报和额外赠送提示属于本次新增客户端能力，需要用户安装包含该代码的新版本；旧 App 已有的服务端会员与 AI 请求仍按服务器权益执行。后台后续调整规则/赠送无需再重新发布 App。

## 本机配置
连接配置和自动服务身份只存在于 ~/.config/icao-app/local-ops/ ，权限 0600，不进入 Git 或浏览器。不要分享该目录。关闭浏览器不会修改数据。无需在阿里云开放数据库或后台端口。
