# D1 首发平台决策

状态：已确认
确认日期：2026-08-09
关联需求：[Native App 正式商业上线总需求](../requirements.md)

## 决策

- 首发平台为 **iOS + 国内 Android**。
- 两个平台均进入本轮设计、开发、测试、合规和发布准备范围。
- Google Play 和 Web 不属于本轮首发范围。

## 本决策未包含

- 国内 Android 的具体应用商店组合；
- iOS 与 Android 是否同日上线及先后顺序；
- 灰度比例、观察期、暂停和回滚标准。

以上发布细节留到 D9“发布策略”确认，不阻塞当前双平台技术准备。

## 对后续工作的约束

- 登录、同步、会员、AI、内容保护和账号注销均须覆盖 iOS 与国内 Android。
- 支付、隐私披露、权限和商店材料分别遵守两个平台及目标渠道的规则。
- 审核等待期内完成双平台开发配置、Release 构建和真机验收准备。
