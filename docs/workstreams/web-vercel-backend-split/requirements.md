# Web Vercel 独立运行需求

状态：已确认并执行

更新时间：2026-07-28

## 1. 产品结论

- iOS、Android 是正式学习产品，继续使用现有 React Native / Expo 工程、阿里云 ECS、Supabase、题库发布和 AI 链路。
- Web 是次级的独立体验产品，继续使用当前 Expo Web 页面、组件、主题、交互与业务规则，不创建 Web V2。
- Web 前端和 Web 专用服务端均运行在 Vercel；浏览器正常运行时完全不请求当前 ECS、其 Supabase 或其资源域名。
- Web 与 App 不同步账号和个人数据。邀请码仅用于进入体验版；学习记录保存在当前浏览器，清理站点数据后允许丢失。
- Web 可继续使用阿里 DashScope 模型，但密钥和调用只存在于 Vercel Functions，浏览器不经过阿里云 ECS。

## 2. 首版必须具备

1. 50 个已确认的 Web 独立邀请码可以稳定登录。
2. HttpOnly Cookie 让同一浏览器在 30 天内保持会话。
3. 页面明确显示“Web 体验版”和本机数据边界。
4. 本机学习记录、收藏、标注、笔记和词汇进度继续使用现有浏览器存储。
5. 完整稳定题库 `releaseVersion 8` 的文本、5777 个题目音频引用及图片资源可访问。
6. 题库镜像提供公开、不可变、版本化地址；Web 通过可更新指针跟随 App 内容发布。
7. 查词、语法检查、表达润色和录音转写使用 Vercel Functions。
8. 录音只为当次转写临时进入阿里 Model Studio 临时文件区，平台在 48 小时后自动删除。
9. 所有不适用于体验版的账号、同步或反馈入口隐藏或提供明确说明。
10. Web 生产构建中不得包含当前 ECS 主机名、IP 或 Supabase 公共配置。

## 3. 明确不做

- 不迁移、修改或关闭 iOS/Android 的 ECS 运行链路。
- 不建设 Web 完整账号、云端学习档案、跨端同步、跨设备恢复或长期 AI 历史。
- 不为 Web 创建第二套可编辑题库、音频映射、字幕或业务规则。
- 不承诺 Vercel 在中国大陆所有运营商、地区和时段 100% 可达。
- 不在首版建设 AI 用量、付费、会员或额度页面。

## 4. 验收标准

- `feizhuicao.com` 可通过独立邀请码进入并刷新恢复登录。
- 题库文本、音频、词汇、文章和代表性 AI 流程可用。
- 清理浏览器数据会丢失本机记录，页面此前已有清楚提示。
- 网络请求只到当前站点、公开 Vercel 静态镜像和页面必要的公共静态资源，不到 ECS。
- iOS、Android 的原生配置、依赖、服务器地址和运行效果未被切换。
- 内容同步失败不会改变线上当前指针；旧 Vercel 部署和旧内容版本可回滚。
