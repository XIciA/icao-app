## 查词

2026-11-04 用户确认：页面标题由“查词与收藏”改为“查词”；每个词条仍展示是否已收藏，保留此前确认的轻量“仅收藏”筛选。布局已选定为与标注题目配套的连续列表，暂不修改产品代码。

### 当前实现

“全部查词”实际上是一个切换按钮，点击后切换到“本次收藏”，不是单纯的标题；当前布局没有明确表达其筛选功能。收藏筛选读取学习记录中的 favorited，而星标读取当前收藏状态，二者可能出现不一致。

来源按钮通过匹配本次回顾题目的 audioText/referenceText 推导，可能为同一词生成多个居中的“回到…”按钮。现有记录只有单词及收藏标记，没有精确的查词来源题目 ID，因此不能直接宣称这些匹配结果就是用户当时查词的位置。

### 已选定布局

每条词条按以下顺序组织，沿用现有字体、颜色与列表气质：

1. 第一行：左侧单词，紧邻发音按钮，右侧收藏星标；实心金色星标表示已收藏，空心星标表示未收藏，点击可切换，沿用现有收藏能力。
2. 第二层：音标与释义，缩减目前不必要的纵向间距。
3. 最下方：小字号、左对齐的“来源：Sentence647 ›”入口，替换居中大按钮。点击进入对应题目，返回仍回到词条列表。

页面默认展示本次全部查词，取消独占一行的“全部查词”大按钮。轻量“仅收藏”筛选放在标题栏右侧，与选定参考一致；“本次全部”无需额外占行。多来源建议使用紧凑的来源入口展开选择，不连续堆叠多个大按钮。没有匹配来源时不生成虚假入口。

选定参考采用当前收藏状态进行筛选，并与星标实时一致；后续实现保持这个可见行为，不混用学习期间的收藏快照。若要精准定位当时查词的来源，需要单独确认记录数据的扩展，旧记录继续按可核实的关联题目处理。

## 下载状态清单和已确认颜色

用户已确认采用本节各状态配色，包括卡片状态与顶部检查更新反馈；本次只记录，不修改实现。

以下盘点依据当前 Native 下载管理代码。当前卡片颜色逻辑只有三类：已下载为浅绿；未下载、下载中、校验中、等待下载、等待中为灰；其余文案全部为浅红。文字统一为前景色。这正是准备中、暂停、等待网络等也显示红底的原因。

| 卡片状态文案 | 当前底色 | 已确认色系 | 含义 |

| 未下载 | 灰 | 灰 | 尚未开始 |
| 已下载 | 绿 | 绿 | 当前范围已完成且没有待更新内容 |
| 等待下载 | 灰 | 黄 | 已进入队列 |
| 准备中 | 红 | 黄 | 下载前准备 |
| 下载中 | 灰 | 黄 | 正在进行 |
| 校验中 | 灰 | 黄 | 下载后的完整性检查 |
| 已暂停 | 红 | 黄 | 暂停，可继续 |
| 等待网络 | 红 | 黄 | 等待网络恢复 |
| 等待 Wi-Fi | 红 | 黄 | 等待允许的网络条件 |
| 网络中断 | 红 | 黄 | 可恢复的网络中断 |
| 待登录 | 红 | 黄 | 需登录后继续 |
| 待验证 | 红 | 黄 | 等待权限或凭据验证 |
| 需会员 | 红 | 黄 | 当前权限条件未满足 |
| 资源未就绪 | 红 | 黄 | 资源暂不可获取 |
| 空间不足 | 红 | 黄 | 需释放空间后继续 |
| 有更新 | 红 | 黄 | 当前资源有新版 |
| 可扩展 | 红 | 灰 | 已有下载未覆盖所选范围，可继续扩展 |
| 校验失败 | 红 | 红 | 完整性检查失败 |
| 下载失败 | 红 | 红 | 实际下载失败 |
| 删除失败 | 红 | 红 | 删除操作失败 |
| 保存失败 | 红 | 红 | 本地保存失败 |
| 验证失败 | 红 | 红 | 反馈映射支持的明确失败文案 |

“等待中”目前只存在于卡片的灰色兼容名单中，当前状态生成函数不输出这个文案；若后续保留，归黄色。上表不把它伪装成一个正在使用的独立阶段。“验证失败”是反馈函数支持的文案，不能据此断言每种运行条件都会出现。

下载管理顶部另有检查更新按钮，其当前反馈采用统一中性色：

| 文案 | 已确认色系 |
| --- | --- |
| 检查更新 | 中性，普通操作 |
| 检查中 | 黄 |
| 已是最新 | 绿 |
| N 项有更新 | 黄 |
| 检查失败、部分检查失败 | 红，保留实际失败含义 |

管理器的“暂无下载”在页面上转换为“已是最新”，不是独立可见状态；文案是否调整不在本次已明确需求中。

配色采用浅色底和清晰的深色文字，绿系复用现有成功色，黄系使用现有 accent 的琥珀黄语义，红系复用 destructive，灰系复用 muted。具体浅底与文字搭配待视觉确认，不在各页面硬编码相近颜色。不扩大到题目标注的颜色含义，也不把整个卡片、进度环或操作按钮全部染色。

实现时建议在共享下载状态层明确颜色语义，不能继续用“未列入白名单就算错误”的方式；底层 paused 也可能承载校验失败等反馈，不能只按 phase 一刀切为黄色。继续使用卡片右上角现有状态位，不新增状态行或横幅，不改变下载流程。
