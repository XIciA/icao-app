# 统一使用教学实施记录

日期：2026-10-22。范围以本目录 requirements.md 和本轮用户确认意见为准。

## 实现

- `GuideTourProvider` 是唯一教学状态控制器。主动入口和首次入口共用 `GUIDE_FLOWS`、事件推进、完成与跳过记录。
- `TutorialContext.tsx` 仅作为学习页事件适配器，不再拥有独立教程状态或持久化。
- 删除固定示例学习包、固定单词和旧教程进度文件；旧 `/info/tutorial` 链接转到使用指南。
- 主动题库教学进入真实题库入口，用户选择实际题目。首次教学按当前题目支持的能力提供步骤；共用能力按完成记录去重，新增能力以后补教。
- 使用极简细线聚光灯：原控件镂空、灰色遮罩、细线与圆点、短标题与说明、唯一跳过入口。直接操作原控件，说明性步骤用“知道了”。
- 定位按动画帧测量，移动目标先隐藏遮罩，稳定后再显示；页面转场隐藏教学层，非焦点页面不注册目标，模态层独立定位。
- 教学跳过只移除教学并记录模块跳过，不调用学习结束与返回路由。导出教学关闭后保留实际导出页。
- 注册后的备考设置覆盖个人资料、等级、考试类型、保存及精选/最全题库范围。
- 账号接口新增可选业务账号 `createdAt`，不使用登录身份创建时间或“本机无数据”判断新用户。新用户分界为代码常量 `2026-10-22T08:00:00.000Z`；更早或缺失时间的账号不自动教学。旧 API 缺少字段时保持手动可用、自动不触发。
- 版本标识从 1.2.3 更新为 1.2.4。

## 进度存储与兼容范围

教学状态使用唯一账号隔离的 `icao.guide.v3.<accountId>` 本机记录；完成能力和跳过模块分开存储。旧示例教程完成记录不直接推定为新能力掌握，也不删除学习、录音、标注或词本数据。

本次未扩展云同步文档协议：跨设备及清除本机数据后的教学去重尚不由云端保证。账号注册时间判断仍保持稳定，老账号不会因重装被误判为新账号。
