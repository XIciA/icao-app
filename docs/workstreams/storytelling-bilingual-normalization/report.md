# 题库双语规范化与随身听真实数据接入报告

## 范围

- 故事复诵 296 张卡：统一为 `audioText` 英文原文、`audioTextZh` 中文译文。
- 听力 631 张：清理中英混排原文、选项块误占位与缺失译文；异常卡 `listening-main-595` 按用户要求彻底删除。
- 随身听：接入听力、900 句、故事复诵真实题库与本地音频。
- 本阶段不生成字幕时间轴，不做逐句跳动，不调用外部 API。

## 故事复诵处理结果

| 处理方式 | 数量 |
| --- | ---: |
| 按“翻译”标记拆分 | 81 |
| 按中英文边界拆分 | 110 |
| 缺失中文后完整翻译 | 56 |
| 提取复诵提纲、提取英文并完整翻译 | 49 |
| 合计 | 296 |

最终结果：

- 296/296 张卡均有英文 `audioText`。
- 296/296 张卡均有中文 `audioTextZh`。
- 英文原文中不再混入中文、翻译标记或复诵逻辑框架。
- 49 条管制 ICAO 基础题库的中文提纲已移入 `referenceText`，原有词汇解析继续保留。
- 对飞行 ICAO 的 192 张卡逐卡复核，修正 63 条既有译文中的错位、缺段、呼号/高度错误和航空术语问题。
- 卡片 ID、分类、顺序和音频挂载保持不变。

## 听力处理结果

- 110 张原空译文已根据英文音频原文完整翻译。
- 331 张把英文或中英选项/答案块误放入 `audioTextZh` 的旧数据，已改为完整音频原文译文。
- 另有 10 张只翻译了问题句，现已补齐完整陈述/通话及问题。
- 233 张中英混排 `audioText` 已清理为纯英文原文；中文完整移入 `audioTextZh`。
- 共应用 451 条听力双语覆盖；631/631 张均通过“纯英文原文 + 非选项块中文译文”严格校验。
- `listening-main-595` 的源备注无法作为可靠原文，已按用户明确要求删除。
- 删除后听力题库为 631 张，631/631 均有中文译文与本地音频。
- 主数据、播放时长索引和音频索引中均不再包含该题；旧题库重建脚本也已永久排除该 ID。

## 随身听结果

- 真实播放队列：听力 631、900 句 900、故事复诵 296，共 1827 条。
- 1827/1827 条均挂载本地音频，缺失文件 0。
- 音频时长通过本地 `ffprobe` 生成；时长不是字幕时间轴。
- 原文区域一次性显示完整英文；“中英文”模式一次性显示完整英文与中文。
- 播放、暂停、上一首、下一首、倍速、顺序、随机、单曲循环均由真实媒体事件驱动。

## 可重复执行

```bash
pnpm question-bank:check-bilingual
pnpm question-bank:normalize-bilingual
pnpm radio:durations
```

目标项目自有双语数据：

- `lib/question-banks/data/storytelling-bilingual.json`
- `lib/question-banks/data/listening-zh-overrides.json`

旧题库生成脚本已读取上述覆盖层，并永久排除 `listening-main-595`，避免后续重建恢复混排或已删除题目。
