# 1.3.6 / 3582990 用户逐项验收清单

三端分别验收、分别记录。先确认测试版本，不卸载、不清空原账号数据；可先在最常用设备走完，再在其他端重复。

- Web：https://readyoufife.com
- iOS：TestFlight 中选择 1.3.6（3582990），现有内部“测试”组可用。
- Android：官网下载页 https://readyoufife.com/download 的独立测试版入口，不替换正式安装包。

未出现的异常分支标记“暂未验”，不要当作通过。AI 正常评分少量执行即可；不为验收重复消耗额度。全流程不要求模拟器。

每项通过标准仅对应下述操作。验收发现问题时提供“项目号 + 平台/设备 + 点击步骤 + 实际表现”；闪动、卡住等可附短录屏。不要在反馈中填写密码、验证码或账号隐私。
