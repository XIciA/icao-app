## 实施说明与限制

- 教程沿用单一 GuideTourProvider。手动教学进入真实 LT（陆空通话）首题，自动教学保留当前题；删除备考设置、题库选择教程。笔记仅明确完成且保存成功时推进；AI 失败可继续教学，跳过单独保存，不伪装评分成功。
- 共享根因修复覆盖弹层生命周期、回调身份、遮罩焦点跟随及常规保存的反馈。没有为每个页面叠加延时或另建存储、录音、请求实现。
- Screen.header 统一当前二级页面固定导航，列表独立滚动；完整边框、明确“知道了”按钮、统计和图例字号进入共享组件。上边框缺失来自白色顶边覆盖，并非预期只画下半边；轻阴影可保留，不能代替完整边框。
- 题目标题在 repository 读取时按当前完整目录投影。只修改符合编号模式的听力/故事复述显示标题；描述性标题保留。稳定 ID、完整顺序、音频、正文、答案、用户关联、同步协议与内容源均不变。旧重排不回退，也不按显示编号挂载资源。
