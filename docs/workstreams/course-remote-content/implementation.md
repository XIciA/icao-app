## 内容来源与更新

唯一编辑源是 `content/courses/catalog.json`，`public/course-content.json` 是生成的版本化发布物，并作为 App 的内置兜底。旧宣传页面也从同一编辑源读取原有字段，避免两套手写数据。

通过 `pnpm courses:build` 生成版本、摘要和内容；`pnpm courses:check` 验证两者一致。数据发布物随 readyoufife.com 的 EdgeOne 部署发布到 `https://readyoufife.com/course-content.json`，不需要数据库迁移或 API 代码部署。该文件应按课程文案发布流程更新，而不是只改宣传站 HTML。

这与 OPI 热点／资源分享采用相同的“原生模板 + 远程数据 + 本地缓存”模式，但课程采用公开 JSON 发布物，不混入热点或资源文章接口。

已安装支持此功能的 App，每次进入课程页面先显示内置／缓存内容，同时检查远端。成功读取新版本后更新；如果用户已经开始滚动或操作，本次读取的新内容先缓存，下一次进入生效，避免详情阅读中跳动。断网、超时、格式或摘要错误保留可用内容，不清除旧缓存。修改结构、样式或新增交互仍需要客户端发版。

## 模拟练习录音补齐（3596176）

用户确认按此前轻量方案实施：完成模拟考试／练习后，从现有本次学习记录或答题卡进入原题卡，右侧回放播放该场次该题的录音。中间录音按钮照常可用，成功重录后替换该记录该题录音，失败保留原音频；不增加页面、控件或拖动功能。

原生录音仓库在提交学习记录前将有效录音复制到文档目录，以本机独立的学习记录附件关联保存；回顾时解析当前沙盒路径并载入原控制器。临时会话退出和缓存清理不再删除已保存附件。原始录音、转写、AI 和其他题库学习行为保持，录音内容及本机文件引用不写入云同步载荷。

重录成功后，旧记录引用更新；现有再练习生成新学习记录的行为保持，新记录持有独立文件。删记录只删除其自有附件；账号切换保存／恢复本机附件索引，游客登录归属原有认领流程。网页仍采用原有浏览器录音行为，本轮不新增网页跨会话录音存储。

边界：本机已保存的新录音可在重启／更新 App 后回听；换设备或卸载重装不会从云端恢复音频。旧版本已经清理的录音无法补回。自动检查覆盖末题保存、失败重试、重录、不同场次隔离、删除、账号切换和游客归属；实际麦克风与回听效果在新 TestFlight 候选中由用户验收。
