- 来源为本轮逐条审核后的 409 条：278 个单词、131 条表达，按刚过专四的航空英语学习者定位。
- `content/vocabulary/question-bank-core/source.json` 是唯一编辑来源；每条包含词形、航空释义、独立例句、中文译文、发音文本及审核来源。
- `node tools/question-bank-vocabulary.mjs build` 依据现有五题库 v26 的 `audioText` 生成 `book.json`，归并批准的词形和拼写，不计答案和选项。频率用于学习排序及区间提示，不作为逐次人工审计结果。
- 客户端展示 10+、50+、100+、200+、500+、1000+ 次区间，低于 10 次显示小计数；不增加精确统计详情界面。
