# 体系课程宣传内容原生同步需求

状态：已确认

确认日期：2026-07-23

## 目标

以 `https://feizhuicao.com/promo` 当前线上内容为基准，完整替换 App「发现 → 体系课程」中的旧示例内容。App 需要展示四个课程分类、九个课程、价格、周期、课程大纲、包过班权益、优势、暑期班信息、宣传承诺和两个咨询微信号。

## 已确认决策

- 采用版本化本地快照，不在运行时抓取网页。
- 当前线上文案原样迁移，不改写暑期日期、价格、“7 大课程”或包过/最低价等宣传表述。
- 微信号使用原生可选择文本支持长按复制，不新增 Clipboard 依赖。
- 课程信息只用于展示与咨询，不新增报名、购买、会员、支付或退款能力。

## 边界

- 使用 React Native 原生组件，不使用 WebView、DOM、CSS 或浏览器 API。
- 保留 `/content/courses` 路由和发现页入口，不改变其他发现内容。
- 只读设计仓库不修改；本需求是用户对原阶段“不迁移独立营销页内容”限制的明确页面级例外。
- 不修改 API、数据库、原生配置或 ECS 运行环境。

## 验收

- 四分类九课程及全部详情可在 App 中访问。
- 普通课程与包过班详情均使用可滚动原生 Bottom Sheet。
- 375×812 为视觉定稿基准，360、390、430 宽度不溢出、不遮挡。
- iOS、Android 构建和课程相关自动化测试通过；最终运行 `pnpm check`。
