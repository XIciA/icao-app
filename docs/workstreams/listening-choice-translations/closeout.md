# 听力选项中文翻译补全收尾记录

- 题库 release 从 v8 升级为 v9。

## 实现边界

- `QuestionBankTextCard` 新增可选 `choicesZh?: string[]`；图片卡显式禁止该字段。
- Schema 和内容构建器校验译文数组数量、非空文本、英文选项索引对应关系、孤立字段和图片卡边界；听力选择题必须提供完整译文。
- `ChoiceList` 默认只显示英文；答案展开或完成作答后显示英文、细分隔线和中文。
- 手动展开但尚未作答时不显示正确/错误状态；作答后保留原有绿/红反馈；收起后隐藏译文和结果，但保留选择记录。
- 英文查词交互保持不变，中文仅展示。
- 继续复用统一题库维护源、构建流程、内置快照、资源清单和现有作答状态，不引入第二份题库或播放生命周期所有者。

## 回滚说明

v5 数据和发布产物均保留。当前 API 按版本号倒序读取最高版本，再检查其 `active` 状态；因此不能仅把 v9 设为非活跃并重新激活较低版本，否则最高版本仍会导致 404。若需内容回滚，应把备份的 v5 负载按更高版本号重新导入并激活（例如 v10），保留 v9 记录作为审计证据，再复验健康、认证响应和 ETag。
