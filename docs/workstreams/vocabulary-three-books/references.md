# 本轮技术词义核对参考

本表记录少量容易混淆的词义核对，不声称全部词目获得外部认证；中文释义与例句为本轮编辑或复用本项目既有资料，没有复制外部教材段落。

- [FAA Runway Incursions](https://www.faa.gov/airports/runway_safety/resources/runway_incursions)：跑道侵入不只指未获许可进入。
- [FAA Runway Excursions](https://www.faa.gov/airports/runway_safety/excursion)：区分跑道侧向偏离与冲出末端。
- [FAA GNSS Interference Resource Guide](https://www.faa.gov/about/office_org/headquarters_offices/avs/offices/afx/afs/afs400/afs410/GNSS)：核对spoofing引入错误定位、导航与时间信息的含义。
- [ICAO Acronyms and Abbreviations](https://www.icao.int/acronyms-and-abbreviations)：缩写核对入口。
- [FAA Airport Acronyms and Abbreviations](https://www.faa.gov/airports/resources/acronyms)：辅助核对TCAS等正式全称；不同机构术语适用范围仍以具体语境为准。

QNH、QFE、QNE作为代码解释，不编造逐字母英文展开。CAVOK不简化成任何天气都“晴好”，MINIMUM FUEL不解释为自动获得优先权，词卡不制定运行决策程序。
