## 核心产出

- 固定五轮样本和原始 ASR 缓存，可重复回归。
- 后置引擎增加独立版本、规则 ID、风险等级和修改追踪。
- 覆盖航空数字、FL、跑道、航向、气压、频率、呼号、航空器型号、航路点、导航台、停机位、滑行道、时间和 Mach 数等明确结构。
- 84 个自动测试覆盖正例、负例、幂等性和 API 返回契约。

## 数据问题

- 题库卡片当前 `audio` 顺序与文本存在系统性错位；评测改用稳定 ID 推导原始音频编号，不修改题库源数据。
- 明显文本错误 3 条已排除；另有 3 条疑似音频/文本不一致，暂不排除、不据此增加规则，等待人工听音确认。
- 具体记录见 `evidence/reference-review.json`。

## 盲测

- 90 条未见样本与优化集零重叠，三个模块各 30 条。
- 排除 3 条明显错误文本后，有效样本 87 条。
- 原始 WER 34.99%，后置 WER 18.80%，下降 16.19 个百分点。
- 改善 46 条，不变 38 条，指标变差 3 条。
- 2 条为真实规则越界，1 条为参考格式造成的假回退；阶段结论为有条件通过。

问题分类和后续门槛见 `blind-classification.md`。
