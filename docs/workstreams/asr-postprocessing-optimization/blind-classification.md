## 问题分类

### 1. 后置程序问题

- `TIME-001` 将普通短语 `time to` 中的 `to` 当成数字 2。
- 影响 `sentence900-main-714`、`listening-main-112`。
- 处理方向：收紧时间规则，只接受明确数字序列，禁止单独将 `to/too` 当成时间数字。

### 2. 评测格式差异

- `sentence900-main-795` 的答案保留 `One Eight Degrees`，后置结果为 `18 degrees`；语义正确，但 WER 判为变差。
- 题库中的呼号代码与实际读音并不统一，例如 `BAW303` 与 `Speedbird 303`、`CES583` 与 `China Eastern 583`。
- `P:/C:/B:` 等说话人标签不在音频中，也会抬高 WER。
- 处理方向：建立独立评测归一化层，不改变展示给用户的转写文本。

### 3. 尚未覆盖的航空结构

- 连续航路编号与点名：`B213`、`R343`、`WHA`、`WUH`。
- 分开拼读的缩写：`R V S M`。
- 部分滑行道、径向线、时刻和航空公司呼号别名。
- 处理方向：只增加有明确上下文和负例保护的确定性规则。

### 4. 通用 ASR 模型问题

- 专名误识别：`OBLIK -> oblique`。
- 固定通话误识别：`Wilco -> we'll go`。
- 普通词误识别：`foamed -> firmed` 等。
- 普通英语同义改写、漏词和句式差异。
- 处理方向：不纳入后置规则，除非形成重复且可由航空上下文唯一确定的错误。

### 5. 源数据问题

- 明显错误文本 3 条：`listening-main-443`、`listening-main-402`、`listening-main-285`，已排除。
