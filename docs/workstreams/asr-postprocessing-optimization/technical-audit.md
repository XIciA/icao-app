# ASR 后置优化技术盘点

## 当前链路

```text
音频 -> Qwen3-ASR-Flash -> rawTranscript
-> normalizeAviationTranscript -> transcript -> App 展示
```

- API 已同时返回 `rawTranscript`、`transcript` 和 `hintsVersion`。
- 当前工作区已有纯 TypeScript 后置引擎及评测工具，但改动尚未提交。
- 规则已覆盖空格、常见缩写、FL、跑道、航向、气压、应答机、频率、高度、呼号、航路点和受限 ICAO 拼读。
- 当前自动测试共 171 个，覆盖允许转换、禁止越界、幂等性和 API 契约。

## 可用资源

| 模块 | 有文本卡片 | 有音频引用 |
| --- | ---: | ---: |
| 900句 | 900 | 900 |
| 听力 | 631 | 630 个可由稳定 ID 映射 |
| 陆空通话 | 1851 | 1851 |

题库卡片已提供稳定 ID、`audioText` 和音频路径，可用于抽样、冻结 ASR 输出和累计回归。

## 主要缺口

- 规则已有分级、独立版本和修改追踪，但尚未拆成可独立开关的模块。
- 已有批量抽样、原始转写缓存、自动对比和累计回归；盲测尚未执行。
- 领域文档资产尚未转成可执行、可验证的规则候选。
- 严格文本匹配与忽略大小写/标点的内容匹配尚未分开统计。

## 风险与保护

- 最大风险是过度替换普通单词，尤其是 ICAO 字母词和数字同音词。
- 后置程序不能演变为通用英语纠错器；普通内容识别问题应保留为模型结果。
- 新规则修复当前样本时可能破坏历史正确结果，必须累计回归。
- 题库文本格式可能不完全统一，测评规则必须先固定。
- 当前工作区已有其他未提交改动，本工作流不得覆盖或带入无关变更。
