# 离线学习与下载管理最终产品方案

日期：2026 年 10 月 30 日。

本方案整理本次讨论确定的离线学习行为，以及用户认可的折叠式下载管理设计。目标是让用户提前下载内容后，继续使用现有 APP 的学习页面和操作；联网时优先复用有效的本机资源，断网时学习已经下载的内容。

本轮同时包含启动与页面恢复体验优化：确认当前本机账号后先恢复可用内容，在后台完成在线检查，结果仅更新相关区域，避免反复出现整页登录恢复和会员确认等待。沿用既有页面与权限体系，不增加新的状态页面或离线开关。

用户于本轮明确授权按此方案实施，并交付 TestFlight。实施与验证进展见 [实施记录](implementation.md)，逐项真机操作见 [验收清单](device-acceptance.md)。本方案仅约束本次任务，不新增项目级长期规则。

## 产品范围

适用 iOS 和 Android APP。网页端不支持下载管理和离线包下载。

下载管理覆盖听力、900 句、陆空通话、OPI、故事复诵五个题库，以及各自关联的文本、翻译、参考答案、音频和图片。下载范围内的学习依赖应完整准备，不能只保存音频而漏掉题目或配图。

本轮不新增逐题下载、逐条音频下载、自动下载更新、云端离线 AI、录音长期保存或录音跨设备同步。不批量转换历史音频格式或统一码率，也不把音频重编码作为离线功能前置条件。

五类题库以外的 OPI 热点、资源分享文章和课程，不因“离线资源”这一表述自动增加下载入口或纳入完整离线承诺；后续若扩展，沿用相同机制。

## 下载单位与范围

用户按固定范围下载，不勾选单题或单个文件。

| 题库 | 页面提供的下载范围 |
| --- | --- |
| 听力 | 精选题库、最全题库 |
| 900 句 | 四级、五级 |
| 陆空通话 | 精选题库、最全题库 |
| OPI | 精选题库、最全题库 |
| 故事复诵 | 精选题库、最全题库 |

除 900 句外，范围名称与现有产品一致，使用“精选题库 / 最全题库”。最全题库包含精选题库；已下载精选后选择最全，补充未下载内容；已下载最全后选择精选，显示已包含，不重复下载，也不自动删除其余内容。

900 句提供“四级 / 五级”选择，复用现有学习目标的范围逻辑：四级包括三级和四级分类，当前共 721 句；五级包括三级、四级和五级分类，即全部 900 句。四级不等于只下载“4级”分类的 159 句，五级也不等于只下载“5级”分类的 179 句。

四级升级为五级时，只补充缺少的五级分类；已下载五级后选择四级，显示已包含，不重复下载或自动删减。默认范围跟随当前学习目标初始化，用户在下载页切换范围不修改全局学习目标。

每个题库只维护一个当前完整下载范围，不并列展示两个重复占空间的包。范围成员复用现有统一来源，不为下载功能另建精选名单或等级名单。下载与学习共用范围定义，下载页不额外改变现有题库可见性与权限。

下载包是用户管理单位，不要求把整个范围封装成一个巨大文件。内部可按现有资源清单下载和复用文件；用户始终执行整包下载、整包检查和整包更新，不暴露文件级管理。

## 下载管理页面

采用已确认的折叠展开设计，固定顺序为听力、900 句、陆空通话、OPI、故事复诵。默认展开听力，同一时间只展开一张卡片；再次点击可收起。

下载页始终显示全部五个题库，不跟随学习目标隐藏卡片。下载范围选择不修改学习目标、不增加访问权限，也不改变现有学习入口的题库筛选。已下载但不在当前学习目标内的内容仍可在本页管理；切换学习目标不自动删除下载。不为此增加常驻说明或额外确认。

顶部沿用 APP 的独立 TopBar：左侧返回、标题“下载管理”居中、右侧“检查更新”。顶部栏下直接展示听力卡片，不放容量概览、题库下载分区标题、整包下载标语或底部解释段落。

入口放在「我的」页面现有功能列表中、设置上方，名称为「下载管理」，只显示图标、名称和箭头，不附加容量或更新数量。点击进入独立二级页面，不新增主导航，也不藏进设置。正常学习页面不额外放下载按钮；离线遇到未下载内容时，在原位置提供「前往下载管理」，进入后展开对应题库，不自动下载。普通入口仍默认展开听力。

### 卡片信息顺序

| 区域 | 内容与表现 |
| --- | --- |
| 卡片头部 | 题库图标、名称；右侧统一状态与展开箭头。状态只表达一次 |
| 展开区上部 | 其他题库为精选题库 / 最全题库；900 句为四级 / 五级 |
| 展开区中部 | 固定位置显示下载大小；下载中和未完成时增加进度行与进度条 |
| 必要状态信息 | 有更新时显示版本变化及受影响提示；失败时显示具体原因。不长期堆叠通用说明 |
| 展开区底部 | 集中展示下载、更新、继续或删除按钮，与信息区用轻分隔线区分 |

容量、进度、百分比和说明采用相同字号的小字；数据行左右文字保持一致的字体、字重与字号，不放大容量或百分比。题库名称保留现有衬线标题层级。

下载和更新为品牌蓝主按钮；删除为红色描边次按钮；取消为次按钮。按钮均有明确的形状和触摸区域，删除不能以裸文字链接呈现。

### 容量展示

未下载、下载中、下载未完成、已下载和有更新都显示“下载大小”，位置和样式一致。切换精选 / 最全或四级 / 五级时，同步更新对应范围的容量，不能隐藏任何范围的容量，也不能在下载成功后仍显示“下载前计算”。

正式页面按清单计算所选范围完整内容的总大小，包括文本、音频和图片。容量信息应随目录或清单在下载前取得，不能先下载完整资源才能计算。已保存的范围容量可在离线时继续显示。

“下载大小”表示所选范围的总量，不表示本次还需传输的流量。内部复用已有文件时，不因总量显示而重复下载。若清单尚未取得，保留容量行并显示加载状态，不猜测一个数值；下载大小准备完成后再允许开始下载。

现有交互稿中的容量为音频估算。精选示意值取自当前精选范围引用的音频去重结果；900 句四级范围音频约 55.2 MB，五级范围约 79.7 MB。上述数值仅用于演示范围切换，不代替正式完整包大小计算；题库更新后，句数和容量按最新清单计算。

## 下载状态与交互

| 状态 | 卡片与展开区 | 可用操作 |
| --- | --- | --- |
| 未下载 | 显示未下载；范围和大小可查看 | 选择范围、下载 |
| 下载中或更新中 | 显示状态；展开后显示大小、百分比和进度条 | 收起、取消下载；当前任务范围不可切换 |
| 校验中 | 显示正在校验，尚不视为下载完成 | 等待校验结果 |
| 已下载 | 显示已下载；检查确认后可显示已是最新 | 查看范围和大小、删除、从精选补充到最全或从四级补充到五级 |
| 有更新 | 显示有更新；展开后显示版本及必要的失效说明 | 手动更新、删除 |
| 网络中断或已取消 | 保留进度和已完成文件 | 继续下载、删除未完成内容 |
| 下载失败 | 保留可复用部分，说明空间不足或校验失败等原因 | 处理原因后重试、删除 |

下载流程：选择范围 → 查看大小 → 点击下载 → 展示进度 → 校验完整性 → 更新卡片为已下载。

只有范围内必要内容完整且校验通过，才可标记为完整下载。不能以任务结束、单条音频可播或进度显示 100% 代替校验成功。

下载完成后，卡片自身状态变化，下载按钮退出当前操作区；不再显示黑色 Toast、成功弹窗或底部完成说明。删除成功、取消成功也直接更新原卡片。保留无障碍状态播报，不新增可见浮层。

下载任务不依赖卡片持续展开，收起或切换卡片不会取消任务。网络中断后可重试或继续；首版复用已完整校验的文件，不以实现单个文件的字节级断点续传为前提。APP 重启后保留已完成文件和可恢复的未完成状态，不把未完成任务标成已下载。

不承诺 APP 被系统挂起、锁屏或退出后仍持续执行下载；这些情况再次进入时应可继续，不增加后台下载系统作为首版前置要求。

### 下载异常与任务恢复

首版同一时间执行一个题库下载任务，其他任务在对应卡片显示“等待下载”，内部复用少量文件并发。不增加任务管理页面。排队任务可取消，重复点击不创建重复任务；收起卡片或离开下载页不取消任务。系统挂起后不保证继续传输，返回 APP 时核对实际状态，暂停的任务显示“继续下载”，不能长期停留在虚假的下载中。

已完整范围与正在扩充的目标范围分别记录。精选升级最全、四级升级五级中断或取消时，原完整范围仍可用，新增部分保留用于继续；不能将整个题库改成未下载，也不能将扩充范围误标完整。卡片必要时用一行说明“精选已下载，最全未完成”或“四级已下载，五级未完成”。下载中锁定任务范围，结束后再允许切换。

开始前检查剩余文件与临时文件所需空间；更新不能只按最终净增加容量估算。空间不足在卡片内显示原因，清理后可继续；中途写入或校验失败保留已验证文件，不误报完成。进度达到 100% 后进入“校验中”，校验成功才切为已下载。容量清单获取失败时，原容量行显示“暂无法获取”并提供重试，不无限加载。

允许使用移动网络下载或更新。用户在移动网络发起下载时，确认框只提示本次预计传输量并提供继续或取消；同一批明确授权的任务不逐文件重复询问。Wi-Fi 切换到移动网络时，未获本批移动网络授权的任务暂停，用户确认后继续。正常学习中的在线播放沿用现有规则，不因本功能增加播放确认。

容量行仍显示所选范围总大小。升级或更新时，仅在操作区按需增加一行“本次需下载 …”，表明复用已有内容后的预计传输量；不增加统计卡片或第二个确认步骤。

## 在线与离线学习

用户继续从现有题库、专题、练习和随身听入口使用内容。下载管理只管理本机副本，不成为独立学习专区，也不要求手动开启离线模式。

| 能力 | 离线行为 |
| --- | --- |
| 题目、原文、翻译、参考答案、配图 | 已下载、有效且有访问权限的正常查看 |
| 示范音频、题目音频 | 使用有效本机文件，保留现有播放操作 |
| 随身听 | 使用有效本机音频；不可用条目明确标识，连续播放时跳过 |
| 手动作答和选择题本地判分 | 依赖内容完整时正常使用；标准答案判分不依赖云端 AI |
| 临时录音、回听和重录 | 正常完成当次练习，不依赖 AI 请求成功 |
| 收藏、高亮、标签、笔记和手动回答 | 本机保存，联网后同步 |
| 学习位置、完成状态、练习记录 | 本机保存，联网后同步 |
| 查词与发音 | 本机词库和有效音频可用；在线获取的部分需要联网 |
| AI 转写、评分、语法分析和润色 | 离线不可发起，在对应操作处提示需要联网 |
| 已有 AI 结果 | 已保存到本机且仍有访问权限的可查看 |

录音只为当次练习录制、回听和重录，不长期保留，不创建录音备份或上传队列。练习记录同步不意味着录音文件同步，也不承诺之后可对历史临时录音补评分。

学习中途断网时，有效本机内容继续可用；未下载部分给出明确的局部提示，不能反复弹通用网络错误。断网冷启动也应允许原账号凭有效本地授权进入已下载内容，不能先等待在线账号恢复成功才能学习。首次登录、切换到未准备本机授权的新账号仍需要联网。

## 资源读取与在线回退

权限校验在资源读取之前。会员授权失效、账号无权访问或内容已下架时，不能通过在线回退绕过限制。

| 资源情况 | 有网络 | 无网络 |
| --- | --- | --- |
| 本机文件完整且有效 | 优先本机读取 | 本机读取 |
| 已确认本机音频被替换 | 获取当前版本在线资源 | 旧音频不可播放，提示需要联网更新 |
| 本机文件缺失、损坏或读取失败 | 自动尝试在线渠道 | 提示本机资源不可用 |
| 未下载 | 在线获取 | 提示未下载 |
| 在线渠道也失败 | 显示失败和重试操作 | 不反复尝试在线渠道 |

在线回退不把整个题库自动变成下载任务。用户未手动更新之前，失效的下载范围仍保留可更新或未完成状态；普通播放缓存不冒充完整离线包。

主动暂停、耳机断开、音频被其他应用打断等情况不判定为文件损坏。网络或版本检查不阻塞本机正常起播。

本机读取失败只进行有限的在线回退，不在本机与网络之间循环重试；在线签名过期时刷新后重试一次，仍失败则在播放器显示重试。无网时区分“未下载”“内容需更新”“本机资源不可用”“需联网验证”，不统一报网络错误。有网可通过现有下载或更新按钮修复损坏包，不另设修复页面。随身听跳过不可用条目；本轮没有可播条目时停止并给出一次局部提示，不能无限跳过。

AI 请求中途断网时，当次临时录音仍可回听，原评分位置显示失败与重试；网络恢复不自动重新提交或消耗额度。学习数据写入本机失败时不显示保存成功，保留当前输入并允许重试；这种失败不能当作普通的待同步处理。

## 版本检查与失效

用户在下载管理手动检查已经下载的范围。联网加载相关题库或学习内容时，也可顺带检查资源版本；复用检查结果，不要求每次播放都单独请求一次版本。

检查只获取版本和清单，不自动下载更新。未下载题库不触发离线更新提醒。清单必须覆盖题目、文本、音频、图片和范围变化，不能只检查音频链接是否变了。

检查按钮依次表达检查更新、检查中、简短结果，再恢复检查更新。结果可以是有若干项更新、已是最新、当前离线、检查失败或暂无下载。失败时保留已有可用状态，不在页面底部常驻一段检查报告。

部分题库检查失败时显示“部分检查失败”，成功发现的更新照常保留；失败题库在卡片内提供重试，不能把未检查、失败或跳过的范围计为最新。检查与下载共用版本结果，不启动重复任务；只有所有待检查的已下载范围都成功核对且无变化，才能显示“已是最新”。

| 检查发现的变化 | 处理 |
| --- | --- |
| 当前范围无变化 | 继续使用本机副本 |
| 某条音频替换 | 只停用对应旧音频，在线播放新版；断网时不可播 |
| 文本、图片或题目变化 | 停用受影响旧内容，在线获取相匹配版本 |
| 文本与音频关联共同变化 | 按关联内容一起更新，避免旧题目配新音频 |
| 题目被撤回或下架 | 联网确认后停止访问对应本机内容 |
| 仅当前下载范围以外的内容变化 | 不要求用户更新当前完整下载 |
| 检查失败 | 不据此判定已有资源失效 |

包版本用于检查入口，资源清单用于定位受影响文件。即使全题库版本发生变化，也只让实际受影响的本机资源失效，不让整套下载同时不可用。

完全离线的设备无法得知服务器刚发生的更新，继续使用最近确认仍有效的版本；一旦联网确认资源失效，记录该状态，随后断网也不能重新启用旧资源。按既有会员离线授权控制连续离线访问，不另加一套内容有效期。

普通版本检查不强行中断正在播放的音频；下一次加载或播放时使用已确认的新状态。

## 手动更新流程

检查发现变化 → 对应题库显示有更新 → 受影响旧资源停止使用 → 用户点击更新下载 → 下载变化部分 → 校验并切换本机版本 → 恢复完整离线使用。

用户操作的是当前下载范围的整体更新，系统复用未变化文件，不引入复杂的二进制差分算法。更新仍以原下载范围为准，不在用户更新精选时顺带下载最全，也不在用户更新四级时顺带加入五级分类。仅五级分类变化不应让完整四级包被误标为需要补充五级内容。

更新期间，有效的未变化资源仍然可用；已确认失效的旧资源走在线渠道。新版文件未校验成功前，不能把它标记为可用。更新失败不损坏其他完整资源，也不重新启用已失效旧版。

下载中版本再次发生变化时，最终按完整清单核对，不能将混合版本标为最新。可保留已验证且可复用的文件，再获取需要变化的部分。

每次任务固定目标清单，并在完成时复核。服务端再次变化时不无限追逐最新版：保留已验证内容，卡片显示仍有更新，用户再手动更新。更新和范围扩充不能并发修改同一题库。文件与包状态采用可恢复的提交方式，重启后核对实际文件，避免文件已删除但状态仍显示完整。

## 学习数据同步

离线操作先提交到本机并进入现有同步队列，包括收藏与取消收藏、笔记和标注的增删改、手动回答、学习位置和练习记录。保存成功即在当前页面生效，不等待网络响应。

恢复联网且账号可用后，自动推送本机变化并拉取服务端变化。同步失败保留本机数据和待同步操作，继续学习并稍后重试。复用现有同步状态，不在下载页面增加学习数据统计卡片。

同步应保证：

- 重试不会生成重复练习记录。
- 同一收藏、笔记或标注的连续操作保留最终结果。
- 删除和清空操作不会被旧离线副本恢复。
- 切换账号时，旧账号的待同步操作不会上传到新账号。
- 多设备冲突沿用并验证现有同步机制，不另建一套独立同步系统。

现有同步需要补齐标注合并：不同笔记按稳定标识合并，同一笔记发生无法安全合并的修改时保留冲突副本，在原笔记入口按需查看，不弹全局冲突处理流程。明确删除的原记录不被旧副本恢复；若删除与另一设备未同步的编辑冲突，编辑内容作为独立可恢复副本保留，不能偷偷复活原记录。收藏、完成状态等非文本数据沿用统一版本规则，重试保持幂等。

联网不自动提交 AI 请求，不自动上传临时录音，不自动消耗 AI 额度。学习内容更新与个人学习数据同步分别处理；下载失败不影响个人数据保存，同步失败也不损坏本机学习包。

若题目更新或下架导致旧笔记无法直接挂接，保留用户笔记和记录，不因题目删除而静默删除个人内容，也不把标注盲目套到变化后的文本位置。

下架后保留用户自行输入的笔记及可保留的练习元数据，原入口按需标记“原题已不可用”；不保留可访问的下架原文、音频或含这些内容的历史快照。纯原文高亮无法继续展示时不硬套新版文本，附带的用户笔记仍保留。此行为需要调整现有退役题目清理逻辑，不能直接沿用整条过滤作为最终实现。

## 删除下载与内容保护

点击删除下载后，显示确认对话框，明确题库名称，并用一句话说明仅删除本机内容，收藏、笔记和学习记录保留。取消不改变任何下载；确认后清除对应范围的本机副本和未完成文件，卡片恢复未下载。共享资源仍被其他有效下载引用时不误删。

删除后，有网仍可在线学习；无网时不能使用已删除内容。重新下载可继续关联原有个人数据。删除下载不等于清除学习数据，也不触发云端个人数据删除。

删除对象是该题库实际保存的完整范围及其扩充残留，不是当前范围选择器临时选中的子集。确认框明确题库和实际范围，例如“删除听力最全题库下载？”。有在途任务时先使任务失效，阻止迟到结果重新写回，再清理文件；正在播放该内容时，在同一个确认框补充会停止播放，确认后停止并释放文件。取消下载只停止任务并保留可复用内容；删除才清除本机副本，不增加第二次确认。

下载内容存于 APP 内部，采用与现有内容保护体系一致的账号隔离、文本保护和密钥管理方式；音频保护需补齐，不能仅改扩展名。播放器使用过程中产生的必要临时文件应受控清理。

不提供新增的学习包、音频、文本导出或外部播放器打开入口。目标是正常使用时仅在 APP 内学习，不承诺杜绝破解设备提取、录屏或外部录音。

现有 900 句 PDF 功能明确保留，入口、生成与导出行为正常保持。禁止导出针对新增离线学习包及下载的音频、题目文本等资源，不借下载管理新增试题或资源导出入口；不将该限制扩展到既有 900 句 PDF 功能。

## 会员与账号边界

离线下载不等于永久取得内容访问权，访问仍受当前账号与会员权限约束。沿用既有离线授权，不因本轮功能新增另一套有效期。当前服务端授权实现的上限为 72 小时，且不超过会员到期时间；本方案不调整这一时长。

联网且权限有效时可刷新已有离线授权。授权到期或需要重新确认身份时，提示联网验证；此时不删除个人学习数据。退出、切换账号或注销时沿用并核对现有清理与隔离逻辑，不能让下一账号直接读取上一账号的下载。

保留最长 72 小时且不超过会员到期时间的授权期限。临近到期时仅在相关下载或学习入口按需提示联网验证；到期时在受限操作处提示，不新增常驻倒计时和反复弹窗。正常联网时自动续验；验证成功且资源有效时无需重新下载。

原账号断网冷启动使用受保护的本地身份、账号映射、既有协议接受状态及有效授权恢复访问，后台网络失败不能先挡住学习入口；本地材料缺失或授权过期时提示联网验证，不能伪造协议同意或绕过权限。首次登录与新账号切换需要联网。

身份过期、单项无权访问和明确账号撤销分别处理。暂时验证失败保留有效本机状态；明确无权限时停止受影响内容访问，不将任意资源的 401/403 直接转成全账号下载删除。凭证到期暂停访问，保留资源供有效续验后复用。主动退出和切换账号则沿用清理下载机制，在原退出或切换确认中说明本机下载将被清除；有待同步数据时同时提示并提供先同步的选择，不静默丢弃，也不串入新账号。注销沿用既有账户删除流程。

在线播放的短期签名链接不能代替本地离线授权。网络故障与明确的无权限响应须区分，不能把身份失效误当成一般网络失败继续读取受限内容。

## 启动与页面恢复体验

### 先恢复本机内容，再后台检查

启动时先确认本机账号归属并恢复其受保护的身份材料、资料和学习数据，再展示可用页面；完整在线检查仍执行，但不作为所有页面展示的统一前置条件。不能只凭上次截图、昵称或 VIP 标签视为登录成功，也不能在账号归属未确认时展示私人内容。

同账号可用数据包括头像、昵称、学习目标、学习进度、记录以及下载状态。账号、协议、会员、学习同步和内容版本检查由现有对应模块统一负责；可以独立的检查后台执行，有依赖的检查按顺序执行，多个页面共享结果和在途请求，不各自重复恢复登录。离线学习权限仍按前述有效授权判断，显示资料不等于授予会员访问权。

后台检查无变化时界面不变；有变化时只更新对应字段或卡片，不整页重载、不重新挂载当前学习页面。页面切换或回到前台不能先清空有效数据再重新加载。保留当前滚动位置、展开状态、下载范围选择、阅读位置、输入和播放状态；同步按冲突规则合并，不用服务器旧结果覆盖刚产生的本机修改。普通内容更新不强行打断当前播放，明确权限撤销则及时停止相关受限访问。

### 各区域的展示

| 区域 | 本机数据可用时 | 缺少数据或验证依据时 |
| --- | --- | --- |
| 我的页面 | 显示正常资料、进度和功能入口，不等待会员与同步全部完成 | 保持现有页面布局，缺失区域简短占位；无法确认账号时使用既有登录或恢复入口 |
| 题库页顶部与目录 | 使用可信的当前账号资料及本机学习目标，避免先显示默认题库再突然切换 | 公开目录可浏览，私人信息未确认前不展示；不假装恢复为默认学习目标 |
| 会员徽标 | 有有效授权和到期依据时先显示会员状态，后台核对 | 仅徽标显示「待验证」，不据此显示未开通、不阻塞整页 |
| 下载管理 | 先恢复已保存范围、容量和真实任务状态，后台检查版本 | 缺少清单的容量行按原规则加载或重试，不影响其他完整下载展示 |

会员剩余天数按到期时间与可信时间依据重新计算，不能直接保留上次显示的数字，也不能依靠修改设备时间延长授权。授权已到期或无法可靠判断时进入待验证；正常联网自动续验，不增加用户确认。首次登录、首次加载或本机数据被清理后不承诺展示不存在的历史内容，也不虚构零进度、默认会员结论或已下载状态。

### 操作权限与失败反馈

浏览已确认归属的本机资料、查看本机学习记录，以及凭有效离线授权学习，可先使用。购买、恢复购买、AI 评分和账号安全操作仍按各自在线验证要求执行，点击时仅在该操作位置等待或反馈。协议需要重新确认、账号注销中或明确撤销访问时沿用现有必要流程，不为减少等待绕过这些限制。

网络慢或暂时失败不清空页面、不切为游客、不清除下载，也不把会员改成未开通。有可用数据时后台刷新不常驻「正在恢复登录」「正在确认会员」提示，不弹成功提示；缺少必要条件的操作才显示一条原因与恢复动作。请求超时应结束对应等待，保留可用数据并允许重试，不能永久显示加载中，也不能靠固定延时假装恢复完成。

账号切换、退出和注销即时隔离旧账号状态；取消或忽略上一账号迟到的请求结果，不能闪现其头像、笔记或会员信息。明确会话失效时更新账号状态并按需引导登录，不能把已确认失效伪装成暂时离线。

这项优化与离线冷启动共用同一套身份恢复和权限来源，不新增第二份登录状态或独立恢复系统。实施时测量本机恢复、账号请求、协议检查和会员读取等环节的耗时，定位实际等待原因；以可用内容及时呈现和后台检查正确完成为目标，不仅替换提示文案。

## 实施衔接

| 现有来源 | 后续职责 |
| --- | --- |
| 题库仓储、统一学习范围与资源清单 | 下载目录、范围成员、体积、资源关联和版本依据 |
| 会员内容缓存与资源解析服务 | 扩展主动下载、离线包状态、失效标记和读取回退，保持同一资源所有者 |
| 内容凭证签发和本地校验 | 维持账号及会员访问边界 |
| 账号恢复、页面访问控制与会员状态来源 | 区分本机可展示状态和在线验证状态，后台共享检查，局部更新页面 |
| 现有播放体系 | 接受有效本机资源或授权在线资源，维持原有播放操作 |
| 现有学习数据同步 | 保留离线修改和恢复联网后的同步 |
| 临时录音体系 | 保持当次录音回听，不增加长期资产管理 |

现有题目加密缓存、音频文件缓存和同步能力不等于本方案已实现。后续重点补齐主动下载、完整范围状态、音频保护、版本失效、下载恢复、账号断网冷启动以及统一管理页面。

不在页面内创建第二套播放器、内容仓库、账号状态或同步队列，不因下载功能更换现有应用技术栈。

代码审查已定位的衔接差异包括：账号恢复依赖在线账户请求；资源解析先请求网络、部分权限错误会清理全账号缓存；机会性缓存达到并发上限可跳过；标注同步存在整份文档覆盖路径；退役题目过滤会移除个人标注。实施时需在这些现有模块内补齐本方案行为，不能把“已有缓存与同步”视为已满足离线承诺。音频现有文件缓存的保护也需补齐，完整下载不能只有文件存在而缺少账号保护。

反馈保持简单：成功、取消、删除和下载进度只更新原卡片；失败仅在受影响操作处展示一条原因及一个主要恢复动作。只保留删除、移动网络传输、退出或切换账号等有明确后果的必要确认，复用现有弹窗，不叠加第二层确认。不增加统一离线开关、冲突处理中心或独立离线学习页。

| 更新期间再发布新版本 | 不混版、不无限重试，仍有变化时保留手动更新入口 |
| 删除时有在途下载或正在播放 | 停止相关任务及播放，迟到结果不能恢复被删文件 |
| 选中精选但实际保存最全后删除 | 确认说明实际删除范围，避免误以为仅删精选 |
| 随身听全部不可用 | 停止并给出局部原因，不循环跳过 |
| AI 请求途中断网 | 当次录音可回听，评分可手动重试，不自动重新扣额度 |
| 本机保存笔记失败 | 不显示保存成功，当前输入可重试 |
| 两台设备离线修改不同或同一笔记 | 不同笔记合并，同一笔记必要时保留冲突副本，不静默丢失 |
| 删除笔记与离线编辑冲突 | 原记录不复活，未同步编辑可作为独立副本恢复 |
| 题目下架或正文变化 | 用户自写笔记保留，下架原文不继续展示，标注不盲目迁移 |
| 授权到期后联网续验 | 验证成功可复用有效资源，无需整包重下 |
| 单项资源权限异常 | 停止受影响访问，不直接清空所有下载 |
| 退出或切换账号 | 原确认说明下载清理；有待同步操作时提示并允许先同步，不串账号 |
| 使用既有 900 句 PDF 功能 | 生成与导出正常保持，下载管理不提供资源导出 |
| 从我的页面进入下载管理 | 设置上方的独立入口，普通进入展开听力；缺失内容跳转展开对应题库且不自动下载 |
| 同账号冷启动且本机数据有效 | 先恢复正常页面，不等待全部在线检查；受限内容仍校验有效授权 |
| 页面切换、前后台切换或弱网刷新 | 有效内容不清空，不反复出现整页恢复登录；共享在途检查 |
| 后台检查完成 | 无变化不刷新，有变化仅更新相关区域，滚动、输入、播放与选择不重置 |
| 无本机资料或首次登录 | 缺失区域占位，不展示上一账号或伪造的默认数据 |
| 会员缓存跨日、到期或时间依据失效 | 天数重新计算；缺少有效依据时局部待验证，不错误授予权限 |
| 在线操作发生在后台验证期间 | 该操作完成必要验证，其他可用页面不整体阻塞 |
| 账号切换后旧请求返回 | 不写入新账号，不闪现旧账号私人信息 |
| 后台网络失败或明确权限失效 | 网络失败保留可用状态，明确失效及时限制对应访问；等待可结束、可恢复 |
