## 状态与异常（最新确认）

异常只替换卡片右上角状态，不新增说明行，不改变卡片高度；展开与折叠均能看到状态。进度与容量位置固定。

| 情况 | 右上角文字 | 行内主操作 |
| --- | --- | --- |
| 未下载 | 未下载 | 下载 |
| 排队 | 等待中 | 取消等待/暂停 |
| 下载进行中 | 下载中 | 暂停 |
| 用户暂停、退到后台 | 已暂停 | 继续 |
| 下载完毕正在校验 | 校验中 | 暂禁重复开始 |
| 完成 | 已下载 | 无，保留删除 |
| 已下载内容有更新 | 有更新 | 更新 |
| 网络断开 | 网络中断 | 重试/继续 |
| 需要重新确认登录 | 请登录 | 沿用登录入口 |
| 会员授权正在恢复 | 验证中 | 避免重复请求 |
| 授权暂时无法确认 | 待验证 | 重试验证 |
| 服务端确认为会员到期 | 会员到期 | 沿用会员入口 |

| 内容版本变化 | 内容更新 | 获取最新清单后继续 |
| 其他下载错误 | 下载失败 | 重试 |

状态优先显示当前阻断原因，不同时堆叠多个状态；精确技术错误留在诊断信息，不展示原始错误码。检查更新按钮自身显示检查中/已是最新/检查失败，更新存在时对应卡片显示有更新。上述状态映射待统一实施和测试，预览为模拟交互。

## 代码核对发现

### 题库图标不一致

全局唯一来源为 `src/features/profile/StudyBankIcon.tsx`：Headphones、SentenceNine（现有轮廓 9）、RadioTower、MessagesSquare、BookAudio。
下载页 `DownloadManagementScreen.native.tsx` 另行使用 Mic、BookOpen 和文本 9，与全局不同。后续应复用 StudyBankIcon，不另画或新建一套图标。展开箭头沿用 ChevronUp/ChevronDown。

### 900 句下载被误报为会员验证问题

代码存在明确不兼容：900 句真实分类 ID 使用 `sentence900-3级`、`sentence900-4级`、`sentence900-5级`；服务端 `ContentAccessService.validateScopes` 对 categoryId/topicId 仅接受 ASCII 字母、数字、下划线和连字符，拒绝含中文的合法分类 ID，返回 `invalid_content_credential_request`。
客户端 `downloadError` 只要英文错误包含 credential 就映射为“请联网验证会员权限后继续”，导致请求格式错误被包装成会员提示。其他题库可下载与该问题相符，截图无法提供该次真实请求日志，最终闭环仍需复现请求及真机验证。

后续统一修正：与现有内容 ID 契约一致地验证合法 scope，保留账号、会员、环境、签名和真实题库归属检查；不能用放弃鉴权解决。按结构化错误区分参数错误、会员到期、网络错误和凭证失败。覆盖四级/五级、中文分类 ID、非法 ID、无权限及会员正常账号回归。用户无需因此重新购买会员。

## 全局离线进入与恢复逻辑（2026-10-31 补充）

### 用户实测与代码证据

用户实测：已下载内容能离线学习；未下载的故事复诵显示“该内容尚未下载”，900 句却显示“学习内容加载失败”。这是待修正的一致性缺陷，不能仅替换 900 句某处文案。

核查发现：

- `index.native.tsx` 将目录加载错误直接映射为通用错误页。
- 学习路由 `[topicId].native.tsx` 只对 topicState 的 `offline_*` 错误作特殊判断，其他目录错误、缺少分类/题目、指定卡片缺失都汇入通用加载失败；而 offline 错误除授权外又被笼统解释为未下载。
- `useQuestionBank`、`useQuestionBankTopic` 分别维护目录和主题状态，目录可能来自本机缓存或内置公开目录；能展示目录不代表题目已下载，旧目录找不到某题也不等于服务器已下架。
- `repository.native.ts` 在明确离线时生成未下载/待验证错误，但网络状态未知、请求途中断网等仍可能返回一般请求错误。
- `useQuestionBankAsset` 另有音频未下载、过期、授权及损坏映射；主题与资源状态需协调，不可把局部音频缺失升级为整页错误。
- `QuestionBankStudyScreen.native.tsx` 与通用版本都存在独占一行的离线横幅；`QuestionBankCatalog.native.tsx` 存在额外缓存说明和重载区，均纳入此次清理。

上述证据说明有多条状态路径；尚未捕获用户该次 900 句运行日志，不能宣称已确认该截图的唯一触发分支。实施时需使用相同账号、四级/五级及冷热缓存复现并闭环。

### 统一原则与行为

在现有内容仓库、授权来源与连接状态基础上统一判定内容可用性，向目录、学习页和相关入口提供结构化结果。路由负责导航与展示，不在每个题库复制网络、缓存和会员判断；不新增另一套下载、授权或缓存所有者。

| 条件 | 统一行为 | 恢复入口 |
| --- | --- | --- |
| 离线且所请求内容与授权有效 | 直接进入同一学习页，保持题目位置 | 无需操作 |
| 离线且所请求内容未下载/不在已下载范围 | 统一“该内容尚未下载”空态，不显示红色加载失败 | 下载管理，展开对应题库 |
| 离线且下载未完成，目标题目不可用 | “下载未完成”阻断态，不把残缺包宣称已完成 | 下载管理，继续对应任务 |
| 本机内容存在但授权需要续验 | “需要联网验证”，不误判未购买或删除资源 | 联网后重试授权 |
| 本机内容已明确失效 | “内容需要更新” | 下载管理，定位更新 |
| 本机文件损坏 | 保留可用文字与学习记录；仅受影响资源不可用 | 对应资源重试/下载管理修复 |
| 联网且本机内容不可用 | 沿用在线内容渠道；已知失效音频不继续使用 | 在线请求失败再显示准确状态 |
| 无本机内容且请求途中断网 | 重新归类网络与本机可用性，不能直接落入通用失败 | 未下载/网络重试按实际情况 |
| 服务端明确确认题目退役 | “原题不可用”，保留历史记录 | 返回来源/题库 |
| 目录缓存不完整、网络未知 | 不推断下架或会员失效；有有效本机包则按包元数据解析 | 缺目录且离线则“目录暂不可用”，联网重试 |
| 在线未知服务故障且无可用缓存 | 统一“加载失败”阻断态 | 重试，保留返回入口 |

同一优先级须覆盖目录、主题和目标卡片，避免先出现会员购买页、下一帧又变成未下载。恢复中的身份与网络未知不直接视为无权限。已确认撤权、退出及账号切换仍及时隔离内容，不以缓存绕过权限。

### 导航与恢复闭环

- 覆盖五库首页/目录、继续学习、学习记录、我的标注/收藏、电台跳转、深链接和返回恢复；相同目标内容得到相同状态，保留各入口既有范围语义。
- 跳转下载管理携带 bankId，展开对应卡片；仅浏览管理页不自动下载、不修改学习目标、不隐式删包。
- 返回学习页时重新检查内容可用性，下载完成后可恢复原题；离线仍缺内容时保留一致空态，不在两页间自动来回跳转。
- 有历史栈则回来源，无历史栈则回对应题库/首页；不产生重复页面栈。
- 联网恢复后台验证与同步，不重置当前题目、答案、临时录音或滚动位置；用户正在播放时避免无关刷新打断。真正授权撤销按既有边界处理。
- 已有可用目录与题目先展示；检查失败不清空可用内容。网络波动不持续在加载页和内容页之间闪动。

### 学习页离线标签

删除独占一行的“当前处于离线状态；文字学习和本机标注仍可使用。”横幅。既有顶部操作栏从左到右为返回、弹性留白、灰底 `WifiOff 离线模式` 小标签、纠错、题号；离线标签字号与纠错相同，使用既有主题令牌和共享图标。

本项“禁止额外状态文字行”已按用户明确授权加入 `docs/rules/ui-style-guide.md`。没有扩展为禁止必要空态、阻断页或删除确认。

## 固定位置与状态底色（2026-10-31 最新设计修订）

本节覆盖前文单行排序：展开行固定为「范围 → 进度环 → 容量 → 主操作 → 删除」。各槽位宽度固定，不因未下载、暂停、完成而改变顺序或左右跳动。主操作共用一个位置，在下载、继续、暂停、更新之间切换。

- 未下载仍显示 0% 环和当前范围容量；删除灰显。
- 下载中与暂停均保留进度环和百分比。
- 完成保留原进度环，环满且中心显示勾；去掉环外独立勾号。右上角始终保留“已下载”。主操作隐藏但保留占位，删除位置不变。
- 右上角状态仅三类柔和底色：绿色为已下载，红色为暂停/异常/需要处理，灰色为未下载/下载中/等待/校验。文字保持主文字色，不为每种错误新增颜色，不染色整张卡片。
- 标题下方第一行左侧显示“题库更新时间”和日期，右侧为检查更新按钮。日期表示最近确认的题库内容发布时间，不是用户点击检查的时间；多库独立发布时取最近一次内容发布时间。无可靠日期显示“—”，检查失败保留上次已知值，不伪造新日期。预览中的 2026-10-31 仅为示例日期。
- 此次继续仅调整设计与记录，APP/API 修正待统一实施。

## 900 句在线不可用的专项排查（2026-10-31）

用户补充：联网时 900 句正常学习也不可用。只读排查确认了可导致该现象的完整代码链路，不仅是离线下载提示错误。

1. Native 在线主题接口返回已鉴权的会员题目后，`repository.native.ts:195` 继续请求离线内容凭证并写入缓存。
2. 900 句分类/主题 ID 含“级”；凭证接口 `validateScopes` 拒绝这些 ID，抛出 400 `invalid_content_credential_request`。
3. `repository.native.ts:214` 将此凭证 400 再抛出，因此不会执行后续 `return release.topic`，已成功取得的在线内容也被丢弃。
4. 外层 catch 不允许该 400 走缓存恢复，并对相应主题调用 `invalidateOfflineTopic`。因此影响不仅是提示，还可能使本机主题标记失效。
5. 上层将此错误显示为通用学习内容加载失败；下载管理则因错误码含 credential 而误报会员验证。

验证证据：

- 本地五库数据扫描：听力 4、陆空通话 319、OPI 238、故事复诵 4 个主题均通过同一 ID 字符规则；900 句 3 个主题全部被拒绝。
- 从实际服务源码提取 `validateScopes`，经 TypeScript 转译后直接调用：四级、五级均抛出 `invalid_content_credential_request`，ASCII 对照范围通过。此验证不改生产代码、不修改账户或数据。
- 只读 GET 正式公开目录 `/v1/question-banks/sentences900`，返回版本 27，分类及主题 ID 仍包含“级”，与本地证据一致。
- 尚未读取用户设备请求日志，也未使用用户身份复现生产凭证请求。因此结论为已复现代码缺陷并与线上 ID 核实，不冒充该次真机请求追踪。

修正方向：首先统一 scope 与真实题库 ID 的契约，保留范围存在性、会员与签名校验；同时把“已鉴权在线读取结果”和“离线凭证/缓存写入结果”的错误边界理清，不能把所有凭证 4xx 一律视为在线内容不可用或内容撤权。真实会员撤销、账号切换、安全校验失败仍需按其明确语义处理，不能笼统吞掉所有 400/403。不迁移已有题目 ID，避免破坏历史记录、标注和链接。

后续必须补足真实五库 ID 的契约集成验证，以及“在线主题成功、离线凭证失败”的错误分类回归。当前没有进行功能修复、API 部署或新包上传。

## 本轮完整修复方案与冲突复核（2026-10-31 汇总版）

### 2. 下载管理页面

独立居中标题栏；下方同一工具行左侧题库更新时间及日期，右侧轻边框检查更新按钮；五库折叠卡片与现有全局题库图标。下载页面显示全部题库，不随学习目标隐藏。

展开行顺序固定为范围、进度环、容量、主操作、删除。主操作在下载/继续/暂停/更新/重试之间切换；完成后主操作空位保留。未下载垃圾桶灰显，已有部分或完整内容时可删除。点击区域至少 44×44。

未下载进度环显示 0%；传输中显示百分比；传输结束而校验未结束时可以显示 100% 但仍是“校验中”，只有完整校验完成才显示圈内勾及绿色“已下载”。更新任务开始后显示该任务进度；无任务的旧包“有更新”不显示成功勾，环内用共享刷新图标表达待更新。容量为所选范围完整下载内容大小，不是已下载字节、剩余流量或磁盘实际占用；移动网络确认按实际待下载量提示。

状态位固定在右上角：绿色已下载；红色暂停、错误、授权待处理、有更新；灰色未下载、等待、下载中、验证中、校验中。只改变文字和柔和底色，不染整卡、不增加说明行。保留必要删除确认；完成不弹提示。系统字体放大需要适配布局，但同一字号下状态切换不得导致额外行或布局跳动。

### 3. 范围与已下载内容

900 句四级包含现有三级与四级句子，五级包含全部句子；其他题库精选是最全的子集。仍按模块范围下载，无逐题下载入口。

无任务时允许选范围，选择本身不下载、不删除、不改变学习目标。已有最全/五级包时，切到其子集仍显示已覆盖、完成环及绿色已下载，不重复下载。已有精选/四级包而选择更大范围时，显示“可扩展”，保留下载入口；点下载才建立扩展任务。旧范围仍可正常学习。

排队、下载、暂停待继续、校验期间锁定该任务范围，避免一行同时代表两个任务；下一次进入默认展示任务范围，其次已保存范围，再用稳定默认值（精选/四级），不跟随学习目标变化。完成后解锁。不要另加“替换包/缩小包”等流程。

每库一份完整包加至多一份进行中任务；大包降为小包不自动释放空间，用户如需缩小可删除后重新下载。垃圾桶删除该题库本机完整包及未完成任务，确认标题明确题库和实际保存范围，不伪装为仅删除当前选择的子集。删除串行停止相关任务并清理，仅释放不被其他内容引用的资源；学习记录、收藏、笔记不删除。

### 4. 更新、失效与日期

检查更新只自动检查已下载范围，不启动下载、不改范围；无完整包但存在任务时，继续操作必须重新确认任务清单。更新由用户手动发起，复用已完成且摘要一致的文件，不承诺二进制差分下载。校验完成后才提交新完整包。

仅服务器成功确认相关内容变更才失效对应资源；超时/断网/服务失败不等于内容失效。新版本只改了未下载范围时不要求重下载当前包。旧包中未变化且授权有效的内容仍可使用；变化/退役的资源不可因更新中断而重新启用。

本机有效内容在线优先；已知失效或损坏则在线回退，离线时准确提示对应不可用原因。更新失败保留可用旧内容及已完成的新文件，允许恢复。

“已下载”表示完整包校验完成，不承诺永远最新；“已是最新”只用于一次成功检查结果。有更新后卡片替换为有更新，不同时保留绿色成功态。检查按钮短暂显示检查中/已是最新/检查失败等结果后回到检查更新，宽度不随文字变化。

“题库更新时间”表示最近已确认的内容发布时间，不是点击时间；多库取最新发布时间，不能用于推断每个本机包已更新。目前 OfflineManifest 无发布时间字段，实施时核对现有发布元数据并以兼容可选字段提供，优先不做数据库迁移。拿不到可靠时间显示“—”，检查失败保留原已知日期，绝不填当前日期伪装真实时间。

### 5. 全局学习状态与跳转

五库、目录/继续学习/历史/标注/电台/深链接统一可用性判断，保留不同入口原有学习范围语义。先确认当前账号、授权与目标内容，再按请求结果和本机资源区分未下载、部分完成、待验证、待更新、局部资源损坏及真正服务错误。

网络未知不等于离线或会员失效。请求途中断网后重新判断本机可用性。目录展示成功不能替代题目权限验证；明确撤权优先于缓存可用。有可用内容先展示，后台失败不清空页面。

下载后返回重新判断并恢复原题，不自动循环跳转；返回保持原入口栈。恢复联网在后台验证/同步，保留当前题目、答案、临时录音及播放归属；真正内容撤销时按既有边界处理。
