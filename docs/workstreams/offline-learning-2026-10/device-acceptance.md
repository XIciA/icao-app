# 离线学习与页面恢复：真机验收清单

本清单对应本轮实现；上传前代码复核与自动化结果见 [实施与验证记录](implementation.md)。真机结果由用户操作后填写，代码检查通过不代表已经完成真机验收。

本轮候选：**iOS TestFlight 1.4.0 (3586479)**，Apple 已处理完成，现有内部“测试”组可安装；Android 测试版为 **1.4.0 / 3591513**，在 [官网下载页](https://readyoufife.com/download) 的测试版入口安装。代码与 API 来源为 `72ce6c96`。这份清单所有勾选仍待实际操作，不预先标记通过。

建议先完成入口/范围、900 句四级下载、飞行模式冷启动、音频回听、PDF 导出、联网同步这六项，再按下列分组检查异常。

## 准备

- 在 TestFlight 安装本轮最新候选（版本及构建号以交付记录为准），保留原账号与学习数据，不先卸载旧版。
- 准备一个有有效会员权限的账号、Wi-Fi 和可切换的移动网络。需要跨设备同步时使用同账号另一台设备。
- 先联网登录一次，再测试断网冷启动。离线授权沿用现有最长 72 小时且不超过会员到期时间的限制。
- 先测 900 句四级，再测听力精选；其他题库至少各下载一个范围并抽查文本、音频及配图。大包可以分次验收。
- 不为验收删除真实学习数据、修改生产题库或更改手机时间。需要资源更新、授权过期或文件损坏的条件，按文末的专项方法安排。

| 勾选 | 操作 | 应看到的结果 |

| ☐ | 精选下载后扩充到最全，途中取消 | 原已下载范围可用；新增部分保留供继续；不误标最全完成 |
| ☐ | 完整最全/五级包切换到精选/四级 | 显示已包含；不重复下载、不自动删减 |
| ☐ | 点击删除，先取消再确认 | 只有一次确认；取消不变，确认后恢复未下载。删除的是该题库实际保存范围及扩充残留 |
| ☐ | 播放题库音频时删除下载 | 确认内容说明将停止播放；确认后停止并清理，不出现文件占用或被迟到下载恢复 |
| ☐ | 删除后联网学习、再断网打开被删内容 | 联网仍可走原学习流程；未重新准备的离线内容不可用；原有笔记、收藏、学习记录仍在 |

## 第四组：版本更新与同步

| 勾选 | 操作 | 应看到的结果 |
| --- | --- | --- |
| ☐ | 联网点击检查更新 | 检查只针对已下载内容；无变化不下载；结果在按钮/卡片内体现，不弹全屏提示 |
| ☐ | 断网点击检查更新 | 原有效内容不被判失效；按钮提示当前离线，联网可重试 |
| ☐ | 有真实已发布更新时检查并暂不更新 | 受影响卡片显示有更新；已确认过期资源不再作为有效本地资源使用，有网走在线播放 |
| ☐ | 已确认旧资源失效后断网 | 失效旧资源不会重新启用；未受影响的其他资源仍可用 |
| ☐ | 手动更新，途中断网，再恢复继续 | 原有效部分保留；失效旧版不会恢复；完整校验后才显示完成 |
| ☐ | 只下载精选/四级后检查更新 | 不因最全/五级之外的变化扩大下载范围，也不无故要求重下整个题库 |
| ☐ | 离线个人操作后联网，查看同账号第二设备 | 收藏、笔记和记录按既有同步机制同步，不重复生成同一记录 |
| ☐ | 两设备分别编辑不同笔记，再联网 | 两边修改都保留；重复同步不产生重复笔记 |
| ☐ | 两设备同时改同一笔记，再联网 | 无法安全合并的用户文本在笔记入口保留冲突副本，不弹复杂冲突中心 |
| ☐ | 一设备删除，另一设备持旧离线副本再同步 | 已删除原项不悄悄复活；如有并发用户笔记编辑，保留为冲突副本 |
| ☐ | 删除下载后重新下载 | 学习数据仍可关联；删除下载不会向云端发送个人数据删除 |

## 需要安排测试条件的专项项

- 题库更新、资源替换与下架：只在确有授权的内容更新或受控测试数据上测，不为验收任意改生产题库。上传前由清单比较、失效与资源校验测试覆盖；真机在下一次真实更新时补测。
- 本机文件损坏/丢失、磁盘不足：代码测试验证回退与重试；真机可在受控测试设备上验证，勿删除手机私人文件或填满日常设备。
- 授权到期、账号撤销：使用自然到期或专用测试账号，不通过修改系统时间伪造通过结果。
- 无法完全靠代码证明的项目：手机系统后台调度、真实存储权限、播放时延、蓝牙/扬声器回听、窄屏实际观感。必须以本轮候选真机结果为准。
