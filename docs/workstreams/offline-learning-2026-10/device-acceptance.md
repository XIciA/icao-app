# 离线学习与根因修复：真机验收清单

目标候选：1.4.2，iOS / Android 测试构建 3593081。1.4.1 的900句存储键问题未通过验收，请使用后续热修候选测试。实际上传、Apple 处理和渠道可用状态以本轮发布记录为准；本清单不代表已完成真机验收。保留现有 PDF，网页不支持下载。

## 准备与优先顺序

- [ ] 从 TestFlight 安装本轮最新候选，确认设置中的版本 / 构建号；Android 使用官网独立“测试版”，不要覆盖正式版。
- [ ] 使用有效会员账号，先保持联网；准备 Wi-Fi、移动网络、飞行模式三个条件。
- [ ] 优先完成第 1–5 组，再检查更新、同步和边界。每项记录“通过 / 不通过 / 未测”。失败时记录题库、范围、操作顺序、网络、版本及截图，避免只写“加载失败”。
- [ ] 如需删除下载可放心操作，但退出账号前先确认学习数据已同步。不要为测试手动修改生产真实题目；第 6 组由下一次正常内容发布配合确认。

## 1. 下载页面与视觉

- [ ] 从“我的”的下载管理入口进入。顶部只有居中标题和返回；下一行左侧“题库更新时间”与日期，右侧边框“检查更新”按钮。
- [ ] 顺序显示听力、900 句、陆空通话、OPI、故事复诵、单词，所有题库都显示，不跟随学习目标隐藏。
- [ ] 展开卡片，下方固定顺序为：范围 → 进度环 → 容量 → 下载 / 暂停 / 继续操作 → 删除。状态变化不移动这些位置，不添加解释行。
- [ ] 题库图标与主页一致；正文、容量、环内百分比均为统一小字。下载和删除使用黑色图标，可点击区域足够；没有红色大删除按钮或蓝色大下载按钮。
- [ ] 已下载右上角为绿色标签，异常 / 暂停为统一问题色，普通状态为中性底色。下载完成仅更新原状态与环内勾，不出现下方黑色提示。
- [ ] 未下载也有容量；切换范围后容量对应所选范围。折叠后仍显示状态；大小不重复写“下载大小”。
- [ ] 900 句为四级 / 五级，其余四库范围使用精选 / 最全；单词下拉显示产品现有三本词书，不出现精选 / 最全。
- [ ] 小屏和系统较大字体下，无内容被遮挡，范围菜单、操作图标和返回均可达。

## 2. 五库在线、下载与恢复

- [ ] **先不下载**，联网进入 900 句四级、五级及不同场景，覆盖实际三级/四级/五级分类，文字、播放、上一题 / 下一题正常，不误报会员异常。升级保留旧账号与下载，不需卸载清空；再测下载、飞行模式冷启动、续验、删除重下。
- [ ] 同样抽查其他四库，在线功能与原流程一致；首次进入不要求先下载。
- [ ] Wi-Fi 下载一个小范围，进度增长；暂停后状态 / 进度保留，再继续能完成。
- [ ] 下载中切飞行模式，右上角短状态变化，不新增警告行；联网后继续，无重复完整下载。
- [ ] 下载中锁屏、切后台、强制关闭后重开，任务可恢复。系统不保证后台持续下载，已完成文件应保留。
- [ ] 下载中从 Wi-Fi 切移动网络，不未经确认继续消耗流量；主动选择继续时沿用流量确认。
- [ ] 连续点击开始 / 继续 / 检查不会创建重复任务；不同库可以排队。
- [ ] 完整大范围覆盖小范围时不重复占用下载；切换选择本身不删除已有包。活动任务不被范围切换偷偷替换。
- [ ] 删除弹窗取消不改变内容；确认后状态恢复未下载，收藏、笔记、学习记录不被删除。

## 3. 离线学习与统一跳转

- [ ] 下载完成后开飞行模式并冷启动，进入已下载范围：文字、答案、解析、音频、倍速、切题可用。
- [ ] 学习工具栏在“纠错”左侧显示灰底 WifiOff“离线模式”，字号接近纠错；没有原来独占一行的长横幅。
- [ ] 分别进入五库未下载范围，均明确显示“该内容尚未下载”或适用的“下载未完成”，不能只有 900 句显示通用加载失败。
- [ ] 从目录、继续学习、历史、标注进入同一内容，权限和可用性结果一致。下载管理返回后重新判断原目标，不循环跳转。
- [ ] 部分下载时，完整可用题目可学；仅音频缺失时文字保留，播放控件反馈失败，不清空整页。
- [ ] 已知更新 / 失效的题目不被旧缓存冒充最新版；未变化且授权有效内容继续可用。
- [ ] 录音用于当次回听，退出后不增加长期录音保存功能；评分 / AI 等联网功能离线不假成功、不偷偷排队上传。
- [ ] 恢复网络后后台同步，不重置当前题号、答案或当前学习操作；明确撤权仍按原权限边界处理。

## 4. 随身听

- [ ] 联网随身听保持原目录、筛选、循环 / 随机 / 顺序、间隔及后台播放行为。
- [ ] 飞行模式进入随身听，只呈现已下载且音频可用的内容，与当前范围 / 学习筛选取交集；显示同款轻量离线标签。
- [ ] 连续下一首、上一首、随机播放不会进入未下载曲目，也不会无限跳过失败内容。
- [ ] 在线播放时切离线，当前已可播放曲目尽量保持；后续队列清除不可离线播放曲目。
- [ ] 删除下载或检查发现资源失效后，已预加载的后续曲目同步移除；当前不可用曲目停止，不继续把旧资源当作可用。
- [ ] 离线无可播内容时显示可操作空态；授权待续验时显示对应原因，不错误引导重复下载。

## 5. 三本词书下载与离线学习

- [ ] 在同一个“单词”卡片中分别选择现有三本词书，容量、下载状态各自独立；切换选择不删除前一本。
- [ ] 下载一本后飞行模式冷启动，进入单词：只提供已下载可用内容，单词、释义、例句、翻卡、熟悉度 / 记忆状态正常。
- [ ] 单词发音和例句播放均可离线使用，包括含括号或斜线的条目，不因路径归一化不一致而失败。
- [ ] 未下载的词书不能误显示离线可学；未下载齐三本时，依赖完整题库的词汇量测试明确引导下载，不用残缺词表给出误导结果。
- [ ] 依次下载第二、第三本，先前完成状态保留；删除其中一本不破坏另一本引用的共同音频。
- [ ] 重新联网后学习进度、收藏沿用现有同步；删除下载不删除进度。
- [ ] 检查更新后，变化 / 删除的旧词条不再作为离线有效内容；未变化词条保留；手动更新后包含最新版新词条。
- [ ] 换账号时不显示前账号下载；旧请求返回不会把前账号内容写入新账号。

## 6. 内容发布与更新（正常发布时复核）

下面流程已用隔离数据库的真实发布服务自测，不要求用户为了验收破坏生产内容。实际正常发布时可按表复核。

| 发布变化 | 检查更新后的预期 | 手动更新后的预期 |
| --- | --- | --- |
| 修改已有题干 / 答案 / 解析 | 对应下载范围显示有更新；变化题目的旧副本失效 | 在线和离线均是新内容 |
| 新增题目 | 所属范围有更新 | 下载包、目录和学习列表包含新题 |
| 删除题目 | 最新目录移除，旧题不再当作可用 | 包中无旧题；原笔记 / 历史保留可保留信息 |
| 原路径替换音频 | 摘要变化使旧音频失效；在线回退新资源 | 离线播放新音频 |
| 改变精选归属 | 相关范围指纹变化 | 精选 / 最全包含正确题目 |
| 只修改未下载范围 | 当前包不无故要求重下载 | 当前范围保持有效 |
| 同一天多次发布 | 日期可能相同，版本 / 摘要仍识别更新 | 得到最后成功确认的版本 |

- [ ] 页面日期来自真实发布时间，不是检查时间；无新内容反复点击不改变日期。
- [ ] 有更新时不自动下载；点击更新后才执行，未变化文件复用。
- [ ] 更新中断后保留可用旧内容和已完成新文件，继续能完成；不会混合两个版本却宣称已下载。
- [ ] 部分接口失败时不显示全局“已是最新”，保留上次已知日期；只更新按钮 / 卡片原状态，不增加提示行。
- [ ] 完成更新后重启、飞行模式验证实际内容，不能只以下载图标变绿作为通过。

## 7. 登录恢复、同步、权限和保留功能

- [ ] 已登录账号冷启动、切“题库 / 我的”等页面，先显示可恢复状态；后台检查不反复整页“正在恢复登录”。
- [ ] 弱网下可浏览已恢复页面；第一次无缓存使用正常加载态，不展示其他账号信息。
- [ ] 离线新增 / 删除收藏、标注、笔记并学习几题，重启后保留；联网后另一设备确认同步，不重复、不被旧数据覆盖。
- [ ] 同一笔记两设备冲突时按原冲突保留规则处理；删除后不会被迟到旧副本复活。
- [ ] 有效会员不会因临时验证请求失败被误报到期；明确到期 / 撤权不继续开放受限内容。
- [ ] 离线授权沿用原签名有效期（最多 72 小时且不超过会员到期），过期显示需要联网验证，文件不被无故全删。
- [ ] 900 句 PDF 的生成、预览与原有导出路径正常；下载题目 / 音频不出现新导出入口。
- [ ] 浏览器仍能正常在线学习和使用既有 PDF；没有原生下载管理入口或误导到不可用下载页。
