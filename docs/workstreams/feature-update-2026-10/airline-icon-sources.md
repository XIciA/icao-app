# 本轮航司图标依据

- QFA/SIA/AFR/BAW/KLM/JAL/ACA/CCA/CES/CSN：依据 [Simple Icons 官方矢量库](https://github.com/simple-icons/simple-icons/tree/develop/icons) 对应 qantas、singaporeairlines、airfrance、britishairways、klm、japanairlines、aircanada、airchina、chinaeasternairlines、chinasouthernairlines 的 CC0 路径，改为统一蓝色轮廓描边。
- QFA 对照 [Qantas 标志历史](https://www.qantas.com/en-fr/about-us/logos)，KLM 对照 [官方媒体标志](https://news.klm.com/asset/678099/logoklm-427773)，JAL 对照 [官方鹤丸说明](https://press.jal.co.jp/en/release/201907/005241.html)。
- UAL 保留当前方形裁切地球标志的轮廓，减少细密经纬线以适应小尺寸。
- NWA 保留历史西北航空的圆形、NW 字形和西北指向三角；不替换成其他现存航司标志。
- 图标仅识别题库对应航司，不表示官方合作。浅蓝底与线条颜色来自现有设计令牌。
