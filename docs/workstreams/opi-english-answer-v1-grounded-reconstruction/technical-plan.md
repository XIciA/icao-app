# OPI 英文答案 v1 语料约束二次重建技术方案

状态：已确认并执行

更新时间：2026-07-23

## 1. 数据链

```text
当前 v8 问题锁
+ v1 分类 1–7 原始答案
+ v2 分类 8 原始答案
+ v8 源卡到目标卡映射
-> 当前卡来源池
-> 主 Codex 摘取、最小修订和逐题决定
-> 独立 Codex 只读复核
-> 主 Codex 裁决
-> 批次 hash
-> v9 英文答案验收版
```

## 2. 工具职责

`tools/opi-rebuild.mjs` 增加：

- `build-grounded-answer-baseline`：通过 `git show` 读取固定历史提交，冻结问题锁、语料、映射和回滚摘要。
- `verify-grounded-answer-baseline`：重算历史语料、来源映射和初始工作项。
- `verify-grounded-question-lock`：只校验当前问题、ID、归属和排序锁，允许后续答案字段发生受控变化。
- 后续校准/批次命令只校验来源 ID、片段 hash、编辑合同、格式、机器报警和封存 hash。
- v9 构建命令从锁定工作项确定性投影至现有题库结构，不读取 v8 答案。

脚本不得判断片段语义是否适合、不得选择最终观点、不得自动生产答案、不得调用任何模型。

## 3. 数据合同

历史语料记录至少包含 release、提交、源分类/话题/卡片、源问题、原始答案、原始 hash、英文片段、片段序号和片段 hash。

当前工作项至少包含问题锁、来源策略、来源池、最终决定、选用片段、编辑动作、答案、来源充分性、风险说明、生产者、复核结论和批次 seal。来源及复核字段只进入 workstream 审计，不进入 App 运行时卡片。

## 4. 质量与权限

- 生产文本写入权只属于主 Codex。
- 独立 Codex 只输出通过项 ID 或问题清单，不提供替换答案、不修改生产文件。
- 每个答案至少引用一个合法历史片段；延期项除外。
- 机器报告新增词、禁用模板、中文字符、编号、多版本、异常换行、长度、句数、完全重复和高相似候选；语义裁决仍由主 Codex完成。
- 后续发现共性规则错误时，按规则和受影响批次整体重开。

## 5. v9 投影

v9 保持 8 分类、144 话题、1090 卡、1067 文本卡和 23 纯图片卡。当前中英文问题、卡片 ID、话题和顺序逐字段保持不变；可答项写入新 `referenceText`，所有文本卡删除 `referenceTextZh`，延期/来源不足项同时省略答案字段。

正式四字段维护源在中文答案完成前作为 v8 回滚基线；v9 使用与英文问题验收版同类的确定性临时发布机制。内容更新不部署或重启无关 API 源码。
