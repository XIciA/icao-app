# OPI 英文答案 v1 语料约束二次重建需求

状态：已确认

更新时间：2026-07-23

## 1. 目标

在完全锁定 OPI v8 现有 1067 道英文问题、中文问题、卡片 ID、话题归属和排序的前提下，重新制作英文参考答案，并构建 OPI v9 英文答案验收版。本轮不制作中文答案。

最终逐卡决定为：1057 个来源受限的新英文答案，或实际发现的 `source-insufficient`；另有 10 个依赖具体图片的既有延期项。23 张纯图片卡保持不变。

## 2. 唯一语料边界

- 分类 1–7 的 1003 道问题只允许使用提交 `d32f10f`、`releaseVersion: 1` 中的英文答案。
- 分类 8 的 23 个图片话题、64 道文本问题只允许使用提交 `b95d541`、`releaseVersion: 2` 中的英文答案。
- 当前 v8 英文和中文答案全部是废弃生产资产，只保留回滚备份，不得进入新答案、候选池或语言判断。
- 官方资料仅可排除明显错误或不安全内容，不能补写旧语料未表达的实质内容。
- 不调用外部 API、外部模型或本地模型。生产文本全部由主 Codex 逐题完成；独立 Codex 只复核并提出问题，不写生产答案。

## 3. 允许和禁止的编辑

允许摘取、删除、合并、调整顺序，以及最小限度修正拼写、标点、冠词、时态、主谓一致、代词一致和必要连接词。

禁止新增旧语料没有表达的航空事实、程序、数值、个人经历、公司政策或机型细节；禁止编号、多版本答案、中英文混排、教材说明和模板免责声明。个人、公司和机型题允许直接使用第一人称示范回答，不在正文重复解释“示范答案”身份。

每题只保留一份可直接练习的答案，通常 3–5 句；素材有限时允许更短，复杂题可分两个短自然段，不用空话填充。来源不足或删除风险内容后不足以回答时，标记 `source-insufficient` 并留空。

## 4. 锁定与展示

- 每一批开始和结束都验证问题锁；锁字段为卡片 ID、分类、话题、顺序标题、英文问题和中文问题。
- v9 保留全部中英文问题，写入新英文答案，并删除所有 `referenceTextZh`。
- 无中文答案时，答案区不显示分隔线或空中文区域。
- 10 个图片延期项和 `source-insufficient` 项不写答案字段；图片资源与 23 张纯图片卡保持不变。
- 不恢复旧问题音频，不建立第二套题库、音频映射或资源解析逻辑。

## 5. 质量门

先完成约 40 张代表性校准批。主 Codex逐题生产并同步校对，独立 Codex执行一次全量复核，主 Codex关闭全部发现并提交可读对照表。用户确认校准批前，不得进入剩余全量生产或写入正式题库。

校准通过后的每批约 25–30 张，执行“主 Codex 生产与同步校对—独立 Codex 一次全量复核—主 Codex 裁决—机器全量校验—hash 封存”。主 Codex 不对普通通过项做第三次全文复核。

## 6. 完成标准

- 1067 张文本卡均有可追溯决定，且问题锁零变化。
- 每个答案的实质观点均能回溯到指定 v1/v2 英文片段。
- 1057 个可答项完成英文答案或有明确的 `source-insufficient` 记录；10 个图片依赖项继续延期。
- 旧中文答案不与新英文答案同时上线。
- 全量审计、机器门禁、双端验收、main 推送、生产备份、v9 导入及线上 checksum/ETag 验证全部通过。
