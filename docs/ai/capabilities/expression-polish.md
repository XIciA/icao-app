# 表达润色

## 能力定义

| 项目 | 要求 |
| --- | --- |
| 目的 | 在保留学习者原意的前提下，提供更自然、简洁的民航口语表达对照。 |
| 适用题库 | OPI。 |
| 用户入口 | OPI“分析表达”。 |
| 最小上下文 | 题目 ID、题目文本、学习者原始回答，以及已有的语法修正文本。 |
| 前置能力 | 先完成语法复核，再对复核后的文本进行润色。 |

## 输入

```json
{
  "module": "opi",
  "questionId": "string",
  "questionText": "string",
  "transcript": "string",
  "correctedText": "string"
}
```

`correctedText` 在接口层可以缺省；组合调用时应优先传入语法复核结果。

## 结构化输出

```json
{
  "polishedText": "string",
  "promptVersion": "string"
}
```

| 字段 | 要求 |
| --- | --- |
| `polishedText` | 更自然、简洁、适合口头回答的英文表达。 |
| `promptVersion` | 标记本次润色规则版本。 |

## 必须满足

- 保留学习者的核心事实、立场、处置顺序和不确定性。
- 结果应适合口头回答，优先清楚和自然，不追求复杂句式。
- 润色结果是对照表达，不是唯一答案。
- 如果原回答信息不足，只优化已有内容，不主动补全标准处置流程。

## 禁止行为

- 不新增机型、数值、机场、航路、故障原因或处置结果。
- 不生成 ICAO 等级、评分、能力评价或学习建议。
- 不为了“更专业”改变学习者实际表达的含义。
