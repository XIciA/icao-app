# 上下文查词

## 能力定义

| 项目 | 要求 |
| --- | --- |
| 目的 | 解释用户在当前题目句子中点选的英文单词或短语。 |
| 适用题库 | 听力、900句、陆空通话、OPI、故事复诵。 |
| 用户入口 | 学习页点选单词或短语，打开“AI 查词”。 |
| 最小上下文 | 当前题库模块、题目 ID、点选内容、点选内容所在的完整句子。 |
| 不需要的数据 | 录音、用户其他学习记录、整张卡片之外的内容。 |

## 输入

```json
{
  "module": "listening | sentence900 | atc | opi | story",
  "questionId": "string",
  "word": "string",
  "sentence": "string"
}
```

## 结构化输出

```json
{
  "word": "string",
  "definition": "string",
  "sentenceMeaning": "string",
  "promptVersion": "string",
  "cached": false
}
```

| 字段 | 要求 |
| --- | --- |
| `word` | 原样返回本次查询的单词或短语。 |
| `definition` | 用简洁中文解释当前民航语境中的含义，不罗列无关词义。 |
| `sentenceMeaning` | 解释该词或短语在当前句子中的作用和整句含义。 |
| `promptVersion` | 标记生成结果所用规则版本。 |
| `cached` | 表示结果是否来自缓存，不由模型生成。 |

## 必须满足

- 解释必须服从当前句子语境；通用词典释义与民航语境冲突时，以当前句子为准。
- 单词和短语使用同一能力，不为短语建立另一套输出结构。
- 相同用户、相同模块、相同点选内容和相同句子允许复用缓存。
- 模型原始输出只能包含 `definition` 和上下文解释；公共字段由服务端补齐。

## 禁止行为

- 不生成题目答案、学习建议、评分或能力等级。
- 不虚构词性、音标、例句或词源。
- 不因为单个词义查询而上传录音或保存 AI 学习记录。
