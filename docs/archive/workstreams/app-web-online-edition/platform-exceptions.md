# 历史归档：Web 平台例外

状态：已确认，无阻塞例外

更新时间：2026-07-18

| 例外 | 原因 | 用户效果 / 处理 | 是否阻塞 |
| --- | --- | --- | --- |
| 麦克风权限弹窗 | 由浏览器和操作系统控制 | 产品内保持申请、拒绝和重试状态；系统弹窗外观不同 | 否 |
| 系统键盘与地址栏 | 浏览器 UI 不受 RN 页面控制 | 固定画布整体适配，不承诺原生键盘/地址栏动画 | 否 |
| 后台播放与锁屏控制 | 浏览器生命周期和媒体政策不同 | Web 首版保证前台播放；不承诺原生后台/锁屏能力 | 否 |
| 首次自动播放 | 浏览器需要用户手势 | 用户点击播放后进入相同播放状态 | 否 |
| 录音容器格式 | Chrome/Safari 与原生编码不同 | repository 接受 `webm` 等浏览器格式，上传仍走同一资产契约 | 否 |
| 本地会话安全级别 | 浏览器没有 Keychain/Keystore | 个人设备长期登录、HTTPS、明确退出；显示“浏览器本机存储” | 否 |
| 浏览器返回与刷新 | 浏览器历史栈属于系统行为 | 页面和会话可恢复，不要求手势/动画与原生完全一致 | 否 |
| 注销后的 403 | 服务端先删除 Auth 用户，随后 Supabase 本地退出请求发现会话已失效 | 请求被吞掉，个人数据和会话仍正确清除，界面回登录页 | 否 |
| 邮件找回与换绑 | 当前不配置正式 SMTP | Web 明确显示暂未开放，不假发送 | 否 |
| Android 体验验收 | 用户决定本轮暂不执行 | 保留共享测试与产品支持，不宣称 Android Chrome/真机已验收 | 否（已确认延期） |

目前没有需要回到大流程重新决策的平台差异。
