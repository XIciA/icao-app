# 历史归档：飞猪 ICAO App README

> 本版本只描述早期 Native 阶段，于 2026-07-30 归档。

Native iOS and Android learning app built with React Native, Expo Development Builds,
and TypeScript. The high-fidelity Web project at
`/Users/zhouyide/Desktop/icao设计稿` is a read-only design and product reference; it is
not a source of React Native UI code.

## Toolchain

- Node.js 24.4.1
- pnpm 11.7.0
- Expo SDK 55 / React Native 0.83
- Xcode 26.3
- Android SDK 36 / OpenJDK 17

Expo SDK 55 is intentionally pinned because SDK 57 requires Xcode 26.4 or newer,
which is not available in the current local toolchain.

## Commands

```bash
pnpm install
pnpm check
pnpm ios
pnpm ios:phase2a
pnpm ios:phase2a:build
pnpm android:emulator
pnpm android
pnpm start
```

`pnpm ios` and `pnpm android` compile and install local Development Builds. Native
directories are generated by CNG and remain untracked.

Use `pnpm ios:phase2a` for the cloud-backed iOS simulator environment. It opens the
project SSH tunnel, reads the Supabase publishable key from ECS without saving it
locally, exports the three public client variables, opens the installed Development
Build, and closes the tunnel when Metro exits. Use `pnpm ios:phase2a:build` when the
native Development Build also needs to be rebuilt.

Do not use plain `pnpm ios` to verify cloud audio or account sync: without the public
runtime variables it only has the local asset fallback, which requires
`pnpm assets:serve` on port 3100.
