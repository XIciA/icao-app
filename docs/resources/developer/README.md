# 开发者笔记

本目录用于人工开发者的本机操作提示、个人环境排查、手动发布步骤和可选模板。

- 这些内容不是 Codex 的默认执行规则，也不自动扩大部署、提交、签名或外部操作权限。
- Codex 仅在用户明确要求，或任务确实依赖某项本机人工流程时读取对应文件。
- 产品边界、架构决策和必须通过的验证不能只写在这里，应写入当前规范。
- 笔记中的本机路径、账号标识和命令可能随环境变化，使用前必须核对。
