# 商业化负责人清单

本清单只提醒必须由产品/主体负责人持有或决定的事项，不是 Codex 的默认前置门槛。具体法律、
商店和平台要求会变化，真正执行前应核对对应官方规则和专业意见。

## 负责人长期持有

- 公司或个人运营主体、域名、品牌和内容授权；
- Apple、Google、中国 Android 渠道及云服务主账号；
- iOS 权限、Android 正式签名密钥与可恢复备份；
- 收款、税务、合同、发票和平台结算资料；
- 短信、邮件、AI 等外部服务的主账号与账单权限；
- 隐私政策、用户协议、退款、账号注销、数据删除和客服渠道的最终版本。

## 在对应任务开始前确认

- 上架：目标市场、开发者主体、包标识、签名、审核材料和测试账号；
- 收费：价格、权益、订阅/购买、退款、恢复购买、财税与客服规则；
- 用户数据：收集范围、保留期限、删除流程、第三方处理与用户同意；
- AI：供应商、发送范围、保留/训练政策、标识与合规要求；
- 外部发布：域名、证书、备案、商店账号与最终审批人。

Codex 可以在明确任务和权限内准备代码、检查、迁移方案与材料草稿；付费、实名、签约、最终
提交审核和不可逆生产操作仍由负责人确认。
