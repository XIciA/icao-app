# 可选 Workstream 启动 Prompt

这是一份给人工开发者复制使用的可选模板，不是 Codex 的必读规则，也不要求创建固定数量的
文档。简单任务直接描述目标即可。

```text
目标：
【希望得到的用户/工程结果】

范围与非目标：
【必须做什么；明确不做什么】

当前事实或入口：
【相关页面、代码、文档、问题证据】

验收：
【怎样证明完成】

权限或风险限制：
【是否允许部署、迁移、删除、提交、发布；没有则写“无额外授权”】

请先核对当前实现与权威文档，再决定使用普通小循环还是大流程。只创建后续确实需要维护的
文档；在范围内自主推进，遇到会改变产品结果、不可逆操作或新的外部权限时再询问。
```

大小流程定义见：

- `docs/bigandsmall-workflows/orchestration-loop.md`
- `docs/bigandsmall-workflows/document-driven-development-workflow.md`
