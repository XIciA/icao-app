# 项目长期边界

本文件承接原 AGENTS.md 中的项目边界，由用户维护。用户未明确要求时，Codex 不得自行改变这些边界。

## 架构与实现

- iOS 和 Android 使用 React Native、Expo 和 TypeScript，通过 Development Build 与 CNG/Prebuild 开发；Web 使用仓库中的 Expo Web 目标。
- 未经明确架构决策，不得引入 WebView 或第二套应用技术栈。
- 新增功能专用的数据、资源加载、播放、持久化或运行时配置前，先查找现有唯一来源，不得建立相互竞争的所有者或平行实现。
- 使用 pnpm 和仓库锁定的依赖版本。

## 权限与改动边界

- 密钥、证书、签名材料和本地环境文件不得进入仓库、日志或聊天；保留用户的无关修改。
- 生产部署和数据库迁移必须获得明确授权。[产品更新与发布流程](product-update-workflow.md)规定了产品更新任务中测试渠道交付与 EdgeOne 产品 Web 上线的既有授权；不自动授权后端部署或数据库迁移。
- 当前产品客户端仅维护 iOS、Android 和 EdgeOne 产品 Web。旧 Vercel 端已经退役；用户于 2026-10-24 撤销其冻结约束，不再要求保留旧端行为、冻结基线或为旧端拆分共享实现。历史源码与记录不构成现行发布目标，其他独立项目不属于本项目发布范围。
- 只有任务改变正式交付的用户可见行为、内容、运行时行为或发布产物，或者用户明确要求提升版本时，才更新 `src/config/app-version.ts`。

## 专项约束入口

- 分支、正式代码来源、提交、发布与清理：[仓库管理规则](repository-and-github-management.md)。
- 视觉身份和核心交互：[UI 风格规范](ui-style-guide.md)。
- 最终验收环境、必要验证和交付状态：[交付与验收规则](delivery-and-acceptance.md)。
- 录音资产、职责边界和防回归：[录音维护原则](recording.md)。

历史产品决策不在此自动续期。新增或恢复长期产品约束，必须来自用户明确要求，不能由 Codex 从旧任务中自行提炼。
