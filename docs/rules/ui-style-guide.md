# UI 风格与实现规范

状态：当前设计基线
更新时间：2026-10-23

本文保护飞猪 ICAO 的视觉身份和核心交互气质。除非用户明确要求改变整体风格方向，不得另起
一套品牌配色、字体角色、圆角体系、导航模型、卡片气质或图标语言。

## 1. 权威来源

| 内容 | 当前可执行来源 |
| --- | --- |
| 颜色、间距、圆角、排版、阴影、动效 | `src/theme/tokens.ts` |
| 字体 family 映射 | `src/theme/font-families.ts` |
| 通用 UI | `src/components/ui/` |
| 跨平台容器、弹层和 Web 布局 | `src/components/platform/` |
| 实际页面与路由 | `app/`、`src/components/`、`src/features/` |
| 历史视觉证据 | `docs/records/evidence/ui-screenshots/`、只读 `icao设计稿` 仓库 |

代码令牌是精确数值来源；本文是语义和变更边界。旧 Web/Tailwind 配方已归档，不再以
`app/globals.css`、`PhoneFrame` 或旧组件路径指导当前实现。

## 2. 不可漂移的视觉身份

### 品牌颜色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| Background | `#FBFAF7` | 温暖、安静的页面底色 |
| Foreground | `#11161F` | 主正文和高层级信息 |
| Primary | `#1F5ED9` | 主要操作、选中态、品牌识别 |
| Accent | `#B77610` | 少量强调、勋章和重点提示 |
| Destructive | `#DB2B33` | 错误与破坏性操作 |
| Correct | `#34C98A` | 学习反馈中的正确状态 |
| Card | `#FFFFFF` | 内容承载面 |
| Muted | `#F4F2EC` / `#5D636F` | 次级背景与说明文字 |

- 不用随机相近色替代令牌，不把 Primary 扩散成大面积高饱和背景。
- Correct 与 Destructive 表达语义状态，不能只靠颜色区分；同时使用文字、图标或结构。
- 边框和遮罩使用 `tokens.ts` 中透明度令牌，保持轻、柔和、低噪声。

### 字体角色

- 页面标题、章节标题、卡片主标题：Noto Serif SC 半粗体，形成克制的编辑感。
- 正文、按钮、说明、表单：Geist，保证清晰和现代感。
- 数据或严格等宽内容：Geist Mono。
- 当前字号与行高以 `type.pageTitle`、`sectionTitle`、`cardTitle`、`body`、`caption`、
  `micro` 为准；不在页面内创建另一套命名体系。

### 形状、层级与动效

- 圆角梯度为 `10 / 13 / 16 / 22 / 29 / 35 / full`，按元素层级选用。
- 主要间距来自 4px 基础序列；优先复用 `spacing`，避免连续出现无语义的任意数值。
- 卡片、悬浮元素和模态层使用 `shadows.card/floating/modal`，保持低对比、轻浮起。
- 点击反馈基线为 `pressScale: 0.98`，常规时长 `140ms / 220ms`；动效服务于状态理解，
  不做装饰性抢夺。

## 3. 组件气质

- 页面以内容为中心，留白充足，层级依靠排版、间距和轻边框建立。
- 卡片是信息分组，不是每个元素的默认容器；避免卡片套卡片和过量阴影。
- 主按钮清晰但克制；同一区域只保留一个最高优先级操作。
- 输入、标签、提示和状态组件优先复用 `src/components/ui/`，新增变体先扩展共享组件。
- 图标使用既有 Lucide React Native 体系；相同语义保持相同图标和线性气质。
- 空态、加载、错误、禁用和完成态都属于设计，不以临时文本替代。
- 标题、列表和操作已能说明用途时，不添加重复说明或无助于操作的辅助小字；仅保留会影响用户选择、理解状态或恢复错误的必要提示（2026-10-25 用户要求）。

### 状态反馈不得额外挤占内容行

用户于 2026-10-31 明确要求：禁止为离线、同步、下载、恢复、后台检查或可恢复异常，在原本可用的页面上新增独占一行的状态文字、说明横幅或提示区，造成内容下移和布局跳动。

- 状态应更新在既有状态位、按钮内，或并入既有操作栏的简短图标标签；相同语义在全局保持一致，不在各页面临时堆叠文案。
- 下载卡片的正常与异常状态共用右上角位置，不因错误增加提示行。学习页离线状态使用纠错左侧的 `WifiOff` 图标与“离线模式”灰底小标签，字号与纠错一致，不新增横幅。
- 简化展示不能隐藏必要反馈。页面确实没有可用内容时，使用统一空态或阻断态及必要操作；删除确认等需要用户决定的交互仍使用既有确认组件。此类状态不与可用内容上方的附加提示行混为一谈。
- 窄屏与字体放大时应在既有操作区内适配，保持信息可读、操作可达，不靠缩小到不可读或新增状态横幅解决。

## 4. 导航与学习流程

- 保留现有主导航的信息架构与返回逻辑，不在单页发明第二套全局导航。
- 学习页应让题目、音频/录音、作答、反馈、解析和前后题进度形成连续闭环。
- 关键操作在状态变化后保持可理解：播放归属、录音状态、答案是否提交、数据是否保存都要明确。
- 平台差异可以改变容器、弹层或布局，但不能改变核心业务语义和学习顺序。

### 登录与会员入口（2026-10-27 用户确认）

- 游客可用的免费功能直接进入；需要账号的操作未登录时直接进入登录页，不经过会员说明中间页。
- 会员功能先确认登录，再确认权益；已登录非会员进入实际会员开通页，有效会员直接进入功能。
- 从具体功能发起登录后继续原目标，普通登录入口保持题库首页；取消登录返回原入口，不保留被拦截的中间页。
- 恢复账号或读取权益期间沿用既有加载、确认和失败恢复，不将未知状态误判为游客或非会员。

### 听力选项的查词、高亮与作答

以下交互约定由用户于2026-10-26明确要求纳入长期维护规范；记录约定不代表已完成代码修复。

- 听力属于选择题交互，维护时应单独考虑选项和答题卡的特点，不能直接套用口述题的处理；答题卡的具体改动需按对应任务确定。
- 保留选项文字查词能力，未选择答案时也能查词；查词操作不能误触选项作答。
- 开启高亮模式后，选项文字支持高亮；此时选项作答不可用，操作选项文字只用于高亮，不能选择或改变答案。
- 再次点击高亮按钮退出高亮模式后，恢复正常点击选项作答的交互；恢复仅适用于原本允许作答的状态，不解除模考或历史记录等场景已有的只读限制。
- 切换高亮模式本身不提交、清空或改变已有答案。

## 5. 响应式与平台适配

- Native 以真实设备安全区、键盘、触摸区域和系统生命周期为准。
- Web 使用 `src/components/platform/` 中的 viewport、content frame、modal 等既有抽象。
- 窄屏维持移动端内容优先；宽屏增加可读宽度和空间组织，不把手机画框机械放大。
- Web 与 Native 可以有不同弹层和导航表现，但需共享颜色、字体角色、组件语气和核心状态。

## 6. UI 工作方法

1. 找到最接近的现有页面、共享组件和令牌。
2. 核对 `docs/records/evidence/ui-screenshots/` 或只读设计基线中的视觉意图。
3. 在现有设计语言内适配真实内容、状态和平台，不复制旧 Web 技术配方。
4. 在目标视口/设备渲染，检查正常、长文本、空态、加载、错误和交互状态。
5. 如果需要改变全局颜色、字体角色、圆角体系、导航模型或组件气质，先获得用户确认，
   再同步令牌、共享组件、本文和必要的视觉基线。

## 7. 资产保护

- 历史设计指南保存在 `docs/records/archive/design/`，原始截图保留在 `docs/records/evidence/ui-screenshots/`。
- 不删除设计基线或截图，除非已确认有等价可追溯替代且用户明确同意。
- 页面局部适配不等于改变品牌；全局风格变更必须形成明确决策。

## 固定页面标题与可读性（2026-10-24 用户要求）

- 二级页面采用安全区、固定标题栏、独立滚动内容、必要底部操作区。题库与发现各功能遵守同一结构；标题和返回不能随列表滚走。
- 复用 Screen 的 header 和 TopBar，题库切换沿用共享切换标题栏；标题角色、居中方式、底色和分隔线一致，点击区域至少44×44。
- 统计、答题卡图例和教学主要说明使用正文层级，次要信息使用caption；不以micro承载重要信息。并列统计保持字体角色、字号和行高一致。
- 卡片四周边框完整，选中轮廓不被特殊顶边覆盖；阴影不代替边框。教学“知道了”等操作使用明确按钮样式。
