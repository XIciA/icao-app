# D9 首发渠道与顺序决策

状态：已确认；App Store 1.0.0 仅中国大陆销售，DSA 不适用，单一审核账号与 Ops 上架后边界已确定
初次确认日期：2026-08-12
最近确认日期：2026-08-31
关联需求：[iOS 1.0.0 最终上架总需求](../../workstreams/app-store-1.0.0-final-release/requirements.md)

## 决策

- iOS 先通过 TestFlight 测试，验证完成后发布到 App Store。
- Android 首批通过公司官网提供正式 APK 下载。
- iOS 与 Android 分别达到各自上线门槛后即可独立发布；哪一端先准备好哪一端先上线，不要求同日，
  也不以另一端的审核、支付或分发进度作为阻塞条件。
- 国内 Android 应用商店不属于首批发布范围，后续需要时再决定具体渠道和顺序。
- App Store 1.0.0 启用微信开放平台移动应用登录并继续禁用微信支付。最终包包含经过审核的登录
  OpenSDK、入口、URL Scheme/Universal Link、生产认证路由及一致的商店材料；不得包含微信支付 SDK、
  支付入口或支付生产路由。Apple 登录、`+86` 手机号 OTP/密码和 Apple IAP 继续按既定门禁交付。
- 当前用户 Web 产品和 Vercel 部署继续冻结。官网 APK 下载只属于 Android 安装包分发能力，建设时
  必须与用户 Web 商业化隔离；本决策不授权修改或恢复现有 Web/Vercel。
- App Store 1.0.0 和随版本首次送审的五档 IAP 都只选择中国大陆作为销售地区，关闭自动在新增地区
  供应。欧盟不在销售范围，DSA 交易商验证不适用于本次提交；以后扩区前重新完成地区、税务、隐私、
  内容和 DSA 合规审查。本结论只适用于当前 China-only 的1.0.0范围。
- 可视化 Ops 后台的生产部署和管理员初始化延后到1.0.0上架后，不作为 TestFlight、IAP 或 App Store
  提交、审核或发布门禁；现有支付验签、权益、点数、风控、审计和隐私自助服务端能力必须保持可用。

## App Store 年龄分级

- 首发使用 **16+** 作为全端统一年龄口径，覆盖 iOS、Android、全部登录入口、用户协议、隐私政策、
  官网或其他公开发售材料及 App Store。App Store 不选择 `Made for Kids`，产品不描述为儿童产品；
  不建设严格年龄核验或未满16周岁监护人流程。
- 不使用4+申报。航空英语题库和资讯存在少量炸弹、劫机、武器、伤亡、酒精和医疗事件引用；问卷必须
  按正式包全部可访问内容及 AI 能力如实填写，不能为了获得更低分级隐瞒内容。
- 当前首发问卷基线如下；App Store Connect 字段或定义变化时，以提交当日 Apple 页面为准并选择
  语义最接近的真实答案，最终仍覆盖为16+：

| 类别 | 首发回答 |
| --- | --- |
| 家长控制 | 否 |
| 年龄确认机制 | 是，登录前主动声明已满16周岁 |
| 不受限制的网页访问 | 否，仅能打开产品预设的外部链接 |
| 用户公开内容、社交媒体、聊天或私信 | 否 |
| 第三方广告或付费广告位 | 否 |
| 粗俗语言、恐怖主题 | 无 |
| 酒精、烟草或毒品提及 | 偶尔 |
| 医疗或治疗信息 | 偶尔 |
| 成熟或敏感现实主题 | 偶尔 |
| 现实暴力 | 偶尔 |
| 枪支或其他武器 | 偶尔 |
| 性内容或裸露 | 无 |
| 赌博、模拟赌博、竞赛或抽奖箱 | 无 |
| 年龄类别与覆盖 | 不选儿童分类，覆盖为16+ |

## 首发版本与构建编号

- Native iOS、Native Android、App Store 元数据、公开发售材料和 App 内普通用户可见版本统一使用
  **1.0.0** 作为正式首发版本；当前候选包和源码中的正式用户可见版本已统一。
- iOS `CFBundleVersion`（Build）和 Android `versionCode` 是平台内部用于区分安装包的单调递增整数，
  不等于用户看到的1.0.0。App Store Connect 当前最高已上传 Build 为 `3493764`；包含登录闭环、微信
  NoPay 登录、商业、热点、唯一 Logo/UI 与录音代次修复的下一送审候选预留为 Build `3493765`。该版本号
  必须先经短期分支和 PR 合入，再从对应的干净 `origin/main` 归档和上传。最终 Git SHA 以合入后的
  `origin/main` 为准。
- Build `3493761` / commit `fca7436d497430db88cf1a29410d61878fd85fc5` 只作已完成录音回归的历史候选保留，
  不得用于最终截图、TestFlight 验收或 App Store 提交。
- Build `3493762` 仅是合并 AI/注销修正后的源码候选；在最终归档前发现首页仍有课程选择与按课程过滤缺陷，
  因此已被 Build `3493763` 覆盖，不用于截图、TestFlight 验收或送审。
- Build `3493763` 已上传并关联版本页，但建立唯一审核账号时复现 OTP 登录成功后被迟到的启动会话恢复清除；
  该包已冻结为历史失效候选，并由包含完整会话竞态修复的 Build `3493764` 覆盖。
- Build `3493764` 已上传至 App Store Connect，是当前平台最高 Build；它形成于最终登录/微信、商业、
  热点、品牌/UI 与录音修复全部合入之前，仅作历史候选，不用于最终截图、TestFlight 总验收或 App Store
  提交。最终候选由 Build `3493765` 覆盖。
- 内部构建编号不重置。本轮正式产物变化已触发 Build `3493765`；之后仅文档、截图或平台字段收口不再
  重复构建，若新候选验收发现真实代码缺陷，再从更新后的干净 `origin/main` 生成更高 Build。
- App Store、启动后的普通版本展示和对外发布说明只突出1.0.0；Build 编号只放在 TestFlight、
  诊断信息、反馈上下文和内部发布记录中。后续补丁、功能和重大升级原则上分别递增为1.0.1、1.1.0
  和2.0.0，不用日期型字符串替代商店版本号。

## 审核通过后的发布方式

- App Store Connect 选择“审核通过后自动发布（Automatically release this version）”，不进入等待
  开发者手动发布状态，也不设置最早发布日期。审核通过后由 Apple 自动开始上架，中国大陆商店的
  可见时间仍受 Apple 处理和缓存传播影响。
- 首发审核被拒但尚未公开发布时，继续使用用户可见版本1.0.0：仅材料问题优先修正元数据和审核回复；
  涉及代码或资源时上传更高 Build，经 TestFlight 真机验收后替换送审 Build 并重新提交。
- 1.0.0 已公开发布后发现的问题不得继续作为同一商店版本重新发布；需要新安装包时按补丁规则使用
  1.0.1，并先经过 TestFlight 验收再提交更新审核。

## TestFlight 在正式上架前后的角色

- 上架前，TestFlight 是负责人进行 iPhone 真机验收和复核候选 Build 的预发布渠道；通过 TestFlight
  测试不等于通过正式 App Store 审核。
- 上架后，TestFlight 继续作为下一补丁、功能版本和紧急修复候选包的测试渠道，不会因为1.0.0进入
  App Store 而消失。Apple 允许受邀测试者在同一 Build 上架后继续测试，直至开发者停止测试或该
  Build 自上传起满90天失效。
- TestFlight 与 App Store 可以同时分发，但 Production TestFlight 和 App Store 使用同一个 Bundle
  ID，同一台 iPhone 不能并排安装两份；安装 TestFlight 版本会替换该设备上的商店版本。账号和学习
  数据必须保持兼容，切换渠道不得丢失或串号。
- TestFlight 下载的 App 内购买自动运行在 Apple 沙盒环境，不发生真实扣款；正式 App Store 包使用
  生产交易环境。两者共用正式账号和学习服务时，服务端必须按 Apple 环境隔离订单和会员权益，沙盒
  交易不得污染正式账本。
- 正式上架后，普通用户只从 App Store 获得稳定版本；只有被邀请的负责人或测试人员使用 TestFlight
  候选版本。两条渠道职责不同，不构成发布冲突。

## 发布底线

- 两端分别建立可核验的发布清单，至少覆盖正式登录、支付验签、跨端权益、AI 点数、隐私合规、内容
  授权、监控告警、客服承接和回滚能力。
- Android 正式 APK 必须提供稳定下载入口、明确版本号、文件摘要和来源说明，不能将测试包当正式包
  分发；签名密钥和渠道凭证不得进入仓库或公开日志。
- 任一端出现支付、权益、数据删除、内容越权或重大稳定性问题时，可以单独暂停或回滚该端，不影响
  已满足门槛的另一端继续运行。

## App Store 隐私提交门禁

- 首发隐私标签采用 D7 已批准基线，但只能在 StoreKit 内购、支付验签、腾讯云 ASR、DeepSeek 和微信
  登录正式配置全部进入最终候选包，并确认归档中的微信登录数据流已披露且不含微信支付后填写最终答案。
- 提交前必须从最终 iOS 归档包生成原生依赖和隐私清单盘点，确认主应用及全部 SDK 的
  `PrivacyInfo.xcprivacy`、SDK 签名、所需原因 API、网络请求、数据用途和实际版本与 D7、第三方
  服务清单及 App Store Connect 完全一致。
- 归档依赖清单、URL Scheme/Associated Domains、权限和网络请求必须证明 1.0.0 只包含已批准的微信
  登录 OpenSDK 与生产认证数据流，不包含微信支付；SDK 版本、签名、隐私清单和商店标签按 D7 复核。
- App 内隐私政策、无需登录的公开 HTTPS 隐私政策、隐私选择/账号删除页面、第三方清单和 App Store
  元数据必须使用同一主体、版本、生效日期和处理口径。现有旧版、通义千问或未满16周岁监护人等
  冲突描述未全部替换前不得提交。
- 不使用未经合同、控制台设置或正式技术文件证明的“供应商零留存、绝不训练、绝不出境”表述；
  腾讯云 ASR 和 DeepSeek 的已知保留、训练/改进及处理地区按发布时可核实事实披露。DeepSeek 的
  “不用于训练”专项证明缺口记录为后续风险，但不单独阻塞1.0.0定稿或提交。
- App Store 的隐私政策 URL 必须可公开访问；同时填写公开 Privacy Choices URL，说明查阅、导出、
  删除、撤回 AI 同意、注销和无法登录时的联系路径。
- 任一数据流、权限、SDK、政策、商店标签或归档隐私清单不一致，都属于阻断提交的问题，不能仅靠
  审核备注解释放行。

## App Store 审核访问方案

- 采用 D2 确认的一个正常 Production 审核账号，使用公司长期控制的中国大陆手机号和密码登录；不
  要求 Apple 审核员接收短信或提供其个人 Apple ID。
- App Store Connect 的主要登录凭据填写该账号；Notes 不重复存放第二套凭据。凭据只进入受保护的
  审核信息字段和公司凭据存储，不进入仓库或公开材料。
- 同一账号用于免费边界、五档内购、Apple 沙盒交易、会员内容、AI、恢复购买和账号删除；提交前检查
  密码、100点初始余额、Sandbox 购买后的会员状态、可恢复状态和可删除状态，注销放在审核路径最后。
- 审核流程固定为同一账号先完成完整体验，再完成 Sandbox 购买和恢复购买，最后注销；注销后不再安排
  其他功能检查，避免单账号在审核中途失效。
- 审核账号通过当前密码完成近期身份重新验证和注销，不要求审核员接收公司手机号短信；短信
  仅作为未设置密码的普通手机号账号的替代重新验证方式。
- 审核备注提供中英文操作路径，至少覆盖登录、免费与会员边界、五档商品、购买和恢复购买、语音
  转写、文本 AI、麦克风权限、微信登录、账号注销及支持联系方式；只描述最终包真实存在的微信登录，
  不描述微信支付。
- 审核期间 Production 登录、API、腾讯云 ASR、DeepSeek、内购验签和账号注销服务必须持续可用，
  并能从 Apple 审核所在地正常访问；不得以测试桩、审核专用数据流或人工临时放行代替正式能力。
- 首次提交时五档 App 内购买项目与 App 版本一并送审。审核账号准备完成不代表可以提交，仍需同时
  满足银行与付费协议、商品状态、最终候选包和本文件其他发布门禁。

## App Store 分类与公开定位

- 已完成的中国大陆 App 备案继续保持工具类，不因 App Store 分类调整而变更。
- App Store 的主要分类确定为“教育（Education）”，如实反映航空英语题库、语言练习和考试准备等
  核心体验；次要分类使用“工具（Utilities）”，反映录音、转写、标记和学习记录等实用能力。
- App Store 分类与备案服务分类分别按各自平台的真实口径填写；不得为了延续备案分类而把明显以
  语言学习和考试准备为核心的 App Store 体验错误申报为工具主分类。
- App 名称保持“听你五个”，副标题使用“航空英语练习工具”。首发公开定位为帮助用户完成听、说、
  记、练和学习记录等任务的航空英语工具，不定位成课程平台、培训机构或官方考试服务。
- 宣传文本采用简洁功能口径：“围绕航空英语使用场景，提供听、说、记、练和学习记录等实用功能，
  帮助用户按自己的节奏完成日常练习。”
- 首发关键词基线为“飞行员、ICAO、OPI、900句、陆空通话、航空词汇、听力训练、口语表达、飞行
  英语”；提交时按 App Store Connect 的字符限制去重并使用英文逗号分隔。
- App Store 主描述只概括题库练习、音频播放、口语录制、文本转写、学习标记、进度记录、账号同步
  及部分内容需会员或 AI 点数，不写具体价格、逐项免费数量、供应商实现、保留期限、通过率、保过、
  内部题库、真实考题或大段责任声明。必须披露的法律、隐私和 AI 边界放在对应政策及功能页面。
- 首发公开描述采用简洁基线：“听你五个是一款面向航空英语学习场景的实用工具，提供题库练习、
  音频播放、口语录制、文本转写、学习标记和进度记录等功能。相关内容由团队整理、制作并持续维护。”
  不公开说明逐题来源、AI 加工过程或宣称全部内容均为公司原创。
- 截图只使用最终候选包的真实界面，首发依次展示按模块练习、音频播放、口语记录、按需转写、收藏
  笔记与学习记录、登录后同步；不使用课程销售、通过率或无法由正式功能证明的宣传图。

## 体系课程首发边界

- Native iOS、Native Android 和与首发 App 相关的公开发售页面在1.0.0暂时隐藏“体系课程”及相关
  宣传；不删除现有五类学习题库，也不改变 D4、D5、D6 已确认的会员和内容边界。
- 实现时同时移除公开入口并阻断直接路由展示，不能只隐藏首页卡片。课程代码和资料可以保留，但不得
  被正式包用户、审核员或公开页面访问。
- 首发不展示课程价格、站外咨询购买、包过、通过率、内部题库或真实考题等课程营销内容，也不写入
  App Store 描述、截图、审核备注或相关公开页面。
- 未来重新开放课程前，须单独确认服务形态、支付方式、内容权利、宣传证据、Apple 支付规则和全端
  展示口径；本决策不授权课程销售或相关网页部署。

## 学习报告首发边界

- 当前学习报告尚未完成，Native iOS 与 Android 的1.0.0正式包隐藏发现页入口并阻断直接路由访问；
  代码可以保留，但正式用户和审核员不可见、不可达。
- App Store描述、截图和审核备注不宣传学习报告；未来功能完成并通过独立验收后再随新版本开放。
- 用户提供并已存放为 `assets/images/icon.png` 的蓝色“5+飞机+声波”正方形图作为 Native App 图标的
  唯一母版；iOS、Android和加载页图标均从该母版引用或确定性派生，不再维护独立ICAO文字图。加载
  页必须完整、居中显示，不能因容器尺寸、缩放或裁切只显示部分图形。

本决策只确认首发渠道、独立发布原则和发布底线；灰度规模、观察周期、暂停阈值、具体回滚步骤和
后续商店扩展等发布运营方案，在发布大流程建设阶段确定。
