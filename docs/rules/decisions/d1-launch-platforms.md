# D1 首发平台决策

状态：已确认
确认日期：2026-08-12
关联需求：[Native App 正式商业上线总需求](../../workstreams/app-store-1.0.0/requirements.md)

## 决策

- 首发平台为 **中国大陆 iOS + 国内 Android**。
- 两个平台均进入本轮设计、开发、测试、合规和发布准备范围。
- Google Play 和 Web 不属于本轮首发范围。
- 现有 Expo Web/Vercel 整体冻结，不接入正式手机号账号、会员、支付、内容授权或 Native 云同步，
  也不因本轮商业化修改其代码、配置或部署。

## 发布衔接

- D9 已确认 iOS 先通过 TestFlight 测试，再发布中国大陆 App Store。
- Android 首批通过公司官网提供正式 APK，国内 Android 应用商店后续另行决定。
- iOS 和 Android 各自达到发布门槛后独立上线，不要求同日发布，也不互相等待。

## 对后续工作的约束

- 登录、同步、会员、AI、内容保护和账号注销均须覆盖 iOS 与国内 Android。
- 支付、隐私披露、权限和商店材料分别遵守两个平台及目标渠道的规则。
- 两端使用同一 Production 正式账号和服务端权益；任一端购买的有效会员在另一端登录同一账号后
  可用。
- 审核等待期内完成双平台开发配置、Release 构建和真机验收准备，但分别保存发布证据和回滚点。
