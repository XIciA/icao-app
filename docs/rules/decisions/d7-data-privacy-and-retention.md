# D7 数据隐私、保留与用户权利决策

状态：已确认；1.0.0 不含微信数据流，首发隐私边界和 App Store 隐私标签基线已批准；可视化 Ops
延后到上架后
初次确认日期：2026-08-12
最近确认日期：2026-08-29
关联需求：[Native App 正式商业上线总需求](../../workstreams/app-store-1.0.0/requirements.md)

## 原则

- 学习成果在账号存续期间保留，保障换机和跨设备恢复；高敏感原文、临时文件和原始日志只保存
  完成目的所需的最短时间。
- 只收集账号、学习、交易、AI、安全和客服所必需的数据，不接入广告或用户画像能力。
- 用户可以分别删除单条 AI 结果、清除学习数据和注销整个账号，避免为重置学习进度而注销账号。
- 法定交易和安全记录与活跃产品数据隔离，达到期限后自动删除或匿名化，不用于营销或画像。
- 保留期、清理任务、注销编排、备份过期和第三方清单均由服务端统一维护，不能依靠人工逐条处理。
- 首发注册仅面向已满16周岁的用户；不建设未满16周岁用户的监护人同意流程。
- 1.0.0 不启用微信登录或微信支付，不包含微信原生 SDK、入口、生产路由或商店材料，因此首发隐私
  标签、第三方清单和正式政策不得按“已接入微信”申报。未来 schema 预留不构成实际收集或启用。

## 首发收集与权限边界

- 不展示第三方广告，不出售个人信息，不接入数据经纪商，不做跨公司广告画像或广告归因，所有
  App Store 数据类型均选择“不用于跟踪”；没有跟踪行为时不申请 ATT 权限。
- 首发只在用户主动发起对应功能时申请麦克风和系统照片选择器权限。不申请定位、通讯录或相机
  权限，不采集广告标识、稳定设备标识或设备指纹。
- Apple 账号可以不绑定手机号；但手机号登录、绑定或安全验证会处理手机号，因此商店的
  App 级隐私标签仍必须申报手机号。
- 支付仅处理商品、订单、渠道、金额、状态、退款和平台交易标识。App Store 1.0.0 的支付账户凭据
  由 Apple 处理且本产品不可访问，因此不申报“付款信息”；购买历史仍按实际数据流申报。
- 原始语音只为用户主动发起的识别请求上传。即使正常完成后立即删除，考虑到第三方语音服务参与、
  异常任务可能短期暂存以及语音是核心功能，首发按“音频数据”主动申报，避免低报。

## App Store 隐私标签基线

App Store Connect 的首发回答为“是，会收集数据”。下表是最终代码和 SDK 未增加其他数据流时的
批准基线；“与用户关联”全部选择“是”，“用于跟踪”全部选择“否”。英文名称以提交当天 App Store
Connect 界面为准。

| Apple 类别 | 首发申报的数据类型 | 与用户关联 | 用途 |
| --- | --- | --- | --- |
| 联系信息 | 姓名、电子邮件地址、电话号码、其他用户联系信息 | 是 | App 功能 |
| 标识符 | 用户 ID | 是 | App 功能 |
| 购买项目 | 购买历史记录 | 是 | App 功能 |
| 用户内容 | 其他用户内容、音频数据、照片或视频、客户支持 | 是 | App 功能 |
| 使用数据 | 产品交互 | 是 | App 功能、分析 |
| 诊断 | 性能数据、其他诊断数据 | 是 | App 功能、分析 |

具体映射如下：Apple 首次登录可能提供的姓名和邮箱归入联系信息；手机号用于登录或绑定；反馈中的
可选联系方式归入其他用户联系信息；账号、平台身份和会话关系归入用户 ID；订单和会员交易归入
购买历史记录；回答、笔记、转写、AI 输入输出和导入内容归入其他用户内容；主动语音识别归入音频
数据；反馈附件归入照片或视频；工单归入客户支持；学习进度、收藏和自有产品事件归入产品交互；
请求耗时、状态、错误、系统/App 版本以及只用于安全的 IP/网络记录归入性能数据或其他诊断数据。
IP 不用于推断用户位置，因此不以粗略位置申报。

在当前首发范围不申报精确或粗略位置、通讯录、健康与健身、敏感信息、电子邮件或短信正文、浏览
历史、搜索历史、设备 ID、广告数据、付款信息和跟踪。当前未接入客户端崩溃采集 SDK，因此不申报
崩溃数据；Apple 自身收集且本产品及其合作方不可访问的数据不重复作为本产品收集申报。最终包只要
新增了对应采集或可访问能力，就必须先更新本表、正式隐私政策和 App Store Connect，不能沿用本
基线直接提交。

不选择“产品个性化”：学习进度用于向用户恢复其自己的学习状态，首发没有基于画像的推荐或内容
排序。若以后新增个性化推荐，必须先重新决策和更新申报。开发者广告、第三方广告和其他目的均不选。

## 账号与登录数据

### 手机号

- 保存标准化手机号、验证状态、绑定时间和更新时间；存储和展示分别采用加密与脱敏措施。
- 验证码不得明文长期保存，最长5分钟失效；验证完成或过期后删除。
- 短信安全记录只保留脱敏号码或不可逆摘要、发送结果、时间、用途和风险状态。
- 不收集通讯录、实名、身份证或非必要运营商信息。

### 设备与会话

- 保存平台、App 版本、会话编号、最近登录时间和便于用户识别的设备名称。
- 不采集广告标识、定位、通讯录或稳定硬件指纹；IP 仅进入受限安全日志。
- 用户可以查看并退出当前或全部设备。

## 学习、录音与 AI

- 学习进度、收藏、标注、笔记、回答和 AI 文字结果按 D3 同步，在账号存续期间保留。
- 用户可以删除单条 AI 结果或清除全部学习数据；删除通过同步机制传播到其他设备。
- 原始录音只保存在当前本机学习会话，不跨设备同步；学习会话结束时清理，孤儿文件最长24小时。
- 只有用户主动点击转写并完成 AI 同意后才上传录音；服务端和对象存储在处理完成后立即删除，
  异常残留最长24小时。
- AI 用量和成本日志不得保存录音、完整回答、转写正文或 AI 结果正文。
- 产品自身不使用用户内容训练模型。DeepSeek 是否将开放平台输入用于模型或技术改进登记为已知后续
  风险，1.0.0 暂不把取得“不用于训练”专项证明设为阻塞；正式政策按发布时能够核实的供应商规则
  如实披露，不作未经证明的“绝不训练”承诺。
- AI 同意撤回后停止新的上传和分析，不影响非 AI 学习；既有 AI 文字结果由用户决定是否同时删除。
- AI 生成或辅助生成的内容按照适用规则进行显著标识；上线前完成实际模型、算法或生成式 AI 服务所需
  的备案/登记、公示核验，并建立输入输出安全审核、投诉和应急处理能力。

## 同意与权限体验

- 注册或首次登录时展示用户协议、隐私政策和登录所需处理，勾选框不得默认选中。
- 麦克风在第一次主动录音时按需申请，不在 App 启动时申请。
- 第一次 AI 操作或 AI 政策发生实质变化时，单独说明用途、接收方、数据类型和保留期限并取得同意。
- AI 同意不能与账号注册、普通题库学习或会员购买捆绑。
- 非实质性文案修订不重复打扰用户；处理目的、供应商、数据范围或保留方式重大变化时重新确认。
- 注册时要求用户主动确认已满16周岁；未确认或明确未满16周岁时拒绝注册。首发不为年龄核验额外
  收集出生日期、身份证、人脸或其他非必要个人信息；主动勾选形成轻量自我声明即可。

## 保留期限

| 数据 | 首发期限 | 注销后的处理 |
| --- | --- | --- |
| 手机号和账号资料 | 账号存续期间 | 从活跃系统删除 |
| 短信验证码 | 最长5分钟 | 已自动删除 |
| 活跃登录会话 | 会话有效期间 | 立即撤销 |
| 登录、会话撤销和网络安全记录 | 6个月 | 隔离至期满 |
| 学习进度、收藏、笔记和回答 | 账号存续期间 | 删除 |
| AI 转写和分析结果 | 账号存续期间，可随时删除 | 删除 |
| 本机和服务端临时录音 | 会话结束或处理完成即删，异常最长24小时 | 删除 |
| AI 用量和成本明细，不含正文 | 12个月 | 删除直接身份关联或依法隔离 |
| 原始产品分析事件 | 90天 | 删除 |
| 去标识化汇总统计 | 最长24个月 | 不可关联具体用户 |
| 普通崩溃与错误日志 | 90天 | 删除或去标识化 |
| 用户主动提交的脱敏故障诊断 | 与对应反馈工单共用提交后365天的删除时间 | 随工单及附件一并删除 |
| 网络安全日志 | 6个月 | 隔离至期满 |
| 新用户体验点防重复摘要 | 免费体验点规则存续期间，并定期复核必要性 | 与原账号隔离保留，规则停止且无争议或安全义务后删除 |
| 反馈工单、文字、可选联系方式和图片 | 提交后365天统一删除 | 无争议和法定义务时删除 |
| 订单、支付、退款和售后记录 | 最后交易完成后至少3年 | 隔离保留，期满后删除或匿名化 |
| 数据库备份 | 7天循环覆盖 | 随备份自然过期，不用于恢复已注销账号 |

交易记录最终期限仍须在法律文本终审时结合财税义务确认；如法定期限更长，以法定义务为准并停止
除隔离存储和安全保护之外的处理。发生争议、调查或安全事件时，只对必要记录设置有原因、范围和
截止时间的临时保留，不能借此无限期保存全部账号数据。

## 最小数据分析

首发使用自有服务端事件观察注册/登录、学习激活、会员页、购买结果、AI 能力与成本、同步和错误
漏斗，不接广告 SDK 或第三方行为分析 SDK。

分析和诊断事件不得包含手机号、录音、音频地址、回答、转写、笔记、访问令牌、订单
凭证原文或用户反馈正文。原始 IP 只允许进入安全日志，普通产品分析不得携带。

## 用户自助权利

App 的“账号与隐私”页面提供：

- 查看和更换绑定手机号；
- 查看并退出登录设备；
- 查看、撤回和重新完成 AI 同意；
- 删除单条或全部 AI 结果；
- 清除学习数据但保留账号、会员和订单；
- 导出账号和学习数据；
- 注销整个账号；
- 查看隐私政策、用户协议、第三方服务清单和隐私联系邮箱。

无法使用 App 时，可以通过公开隐私邮箱提出查阅、复制、更正、删除或注销请求。自助入口和服务端
处理能力属于用户端隐私功能；管理员/客服管理界面与权限在后台建设阶段单独约束。

## 注销

- 不设置反悔期。用户在 App 内发起注销后，通过账号已经绑定的身份重新验证：手机号使用当前密码
  或短信验证码，Apple 再次完成 Apple 登录；已经绑定的手机号可以作为备用验证方式。未绑定手机号
  的 Apple 用户不得被要求为了注销而新增手机号。
- 重新验证并确认后立即撤销全部会话、会员权益和 AI 点数，并在24小时内完成活跃业务系统删除。
  Apple 身份对应的账号还必须由服务端撤销相关 Apple 授权令牌。
- 注销等同于主动放弃账号、学习数据、会员剩余时间、已发放和待发放 AI 点数，全部不恢复、不折现、
  不转移；确认页必须将这些后果单独、明确列出，并与“仅清除学习数据”区分。
- 法定交易记录和必要安全记录转入隔离状态；备份副本最长7天自然过期。完整恢复备份时必须重新
  应用注销记录，不能让已注销账号复活。
- 同一手机号以后可以重新注册并获得新的用户 ID，不恢复旧学习数据、会员、AI 点数或旧账号关系；
  同一已验证手机号或 Apple 身份已经领取过100点时，新账号不重复获得体验点。
- 为执行防重复规则，只保留由已验证登录身份生成、与原账号隔离且不能用于登录或恢复账号的带密钥
  摘要及领取状态，不保留原始手机号、Apple 身份值或旧权益。该处理仅用于防滥用并写入正式隐私
  政策；不额外收集身份证、人脸或强设备指纹。
- 登录提供方临时不可用时允许用户稍后重试。用户确实无法使用原身份且没有其他已绑定身份时，通过
  公开隐私入口进入必要的人工身份核验；不得把联系客服设为正常注销的默认流程，也不得要求先新增
  手机号。

## 第三方与披露

App Store 1.0.0 第三方清单至少覆盖阿里云基础设施、短信服务商、腾讯云语音识别、DeepSeek 开放
平台和 Apple 登录/App Store。Android 若实际启用支付宝或其他分发服务，按平台和调用时机进入对应
清单；微信登录与微信支付不进入 1.0.0 清单。每项记录主体、用途、数据类型、调用时机、处理地区、
保留规则、政策链接和启用版本。

未进入清单、隐私政策和商店隐私问卷的 SDK 或服务不得进入正式包。AI 服务需记录能够核实的数据
地域、保留和训练/改进口径；客户端和官网不得笼统承诺未经验证的“绝不留存”“绝不训练”或
“绝不出境”。DeepSeek 的训练/改进证据缺口作为已知风险登记并在后续专项收口，不单独阻塞1.0.0。

后续版本恢复微信能力时，微信 OpenSDK 必须锁定可复现的明确版本，并重新逐项核对供应商隐私政策、
实际网络请求、数据类型、用途、隐私清单和 Apple 要求的签名。SDK 如引入设备标识、跟踪或本表之外
的数据，优先关闭或移除该行为；确实属于产品必要能力时，必须先修改本决策、隐私政策和商店申报。
该后续方向不授权在 1.0.0 保留 OpenSDK 或微信生产数据流。

## 正式隐私政策口径

- App 内、公开 HTTPS 页面和 App Store 元数据引用同一份权威隐私政策，版本号、生效日期、主体和
  联系方式一致；不保留仍可访问的旧版冲突口径。
- 正式文本至少写明运营主体及联系方式、处理目的和方式、数据类型、权限调用、账号和支付、AI 与
  录音、第三方处理者、处理地区、保留期限、安全措施、用户权利、注销、16+ 年龄限制、政策变更及
  投诉渠道；第三方服务清单可以作为同一政策链接的版本化附表。
- 商店隐私政策 URL 必须无需登录即可访问，HTTPS 正常、无失效跳转；商店启用英文等其他本地化时，
  提供内容一致的对应语言版本。
- 同时提供公开的“隐私选择”页面，说明 App 内查阅、导出、更正、删除、撤回 AI 同意、注销账号和
  无法登录时的联系路径，并在 App Store Connect 的 Privacy Choices URL 中填写。
- 正式文本只陈述已由代码、部署配置、供应商合同或控制台设置验证的事实。不得在没有证据时承诺
  供应商零留存、绝不训练或数据绝不跨境；如确有跨境处理，启用前完成适用法律要求的告知、合法
  机制和单独同意，并如实写入政策。
- 当前内置隐私政策和公开网页只能作为待替换历史版本。进入执行阶段后，以最终发布代码、SDK 清单、
  服务商设置和真实数据流生成正式文本，再同步替换所有入口。

## 内部运营后台边界

- D8 已确认建设与用户 App 隔离的内部运营后台并使用独立工作人员账号；该后台不是当前冻结的用户
  Web 产品，也不得以后台建设为由修改现有 Web/Vercel。
- 可视化后台首次投产时的角色仅为管理员和客服。数据可见范围、角色权限及人工处理流程在后台建设
  阶段另行设计，本文件不重复定义。
- 后台只能通过专用服务端接口访问必要数据，不得直接连接生产数据库；敏感数据仍受本文件的最小化、
  脱敏、保留和审计规则约束。
- 用户自助入口、自动保留期清理、自动风控、必要告警和注销编排不依赖人工后台兜底。
- 可视化 Ops 的部署、管理员初始化和 TOTP 验收延后到 App Store 1.0.0 上架后，不是 App Store 提交、
  审核或发布门禁；本节保留的数据访问与审计约束在后台首次投产时生效。

## 实现与验收边界

- 建立统一保留策略和定时清理任务，覆盖数据库、对象存储、缓存、日志和备份。
- 反馈工单以唯一 `retentionAt` 为删除时钟；到期时先删除私有附件对象，再删除整个工单并由
  数据库级联删除附件记录和主动诊断。对象删除失败时保留工单供下次重试，定时任务失败必须产生
  不含工单号、对象键或原始错误正文的结构化告警。提前删除工单后遗留的对象由孤儿清理器补偿。
- 验证 AI 完成与失败清理、撤回同意、单条删除、清除学习数据、换机同步和跨设备删除传播。
- 验证仅绑定手机号、仅绑定 Apple 和同时绑定二者的账号都能在 App 内注销；注销使用已有身份
  重新验证，不以新增手机号为前置条件，Apple 注销同时撤销 Apple 授权令牌。
- 验证注销会撤销全部会话、内容凭证和 AI 权益，不删除依法应保留的隔离交易记录。
- 正式隐私政策、用户协议、账号删除页、App 内文案、备案材料和商店问卷必须与实际数据流一致。
- 对第三方网络请求和正式包 SDK 做清单核验，确保没有未披露采集或敏感内容进入日志。
- 对最终 iOS 归档包逐项核对主应用和所有第三方 SDK 的 `PrivacyInfo.xcprivacy`、SDK 签名、所需原因
  API 声明和实际依赖版本，并与本文件及 App Store Connect 标签对照；任一处不一致都阻止提交。
- 商店问卷必须在 StoreKit 内购、支付验签和正式 AI 服务全部集成，并确认最终归档不含微信 OpenSDK、
  微信入口或微信网络请求后再做最后一次复核；此处基线不能替代对最终发布包的事实审计。
