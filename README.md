# 飞猪 ICAO App

Native iOS and Android learning app built with React Native, Expo Development Builds,
and TypeScript. The high-fidelity Web project at
`/Users/zhouyide/Desktop/icao设计稿` is a read-only design and product reference; it is
not a source of React Native UI code.

## Toolchain

- Node.js 24.4.1
- pnpm 11.7.0
- Expo SDK 55 / React Native 0.83
- Xcode 26.3
- Android SDK 36 / OpenJDK 17

Expo SDK 55 is intentionally pinned because SDK 57 requires Xcode 26.4 or newer,
which is not available in the current local toolchain.

## Commands

```bash
pnpm install
pnpm check
pnpm ios
pnpm android:emulator
pnpm android
pnpm start
```

`pnpm ios` and `pnpm android` compile and install local Development Builds. Native
directories are generated by CNG and remain untracked.
