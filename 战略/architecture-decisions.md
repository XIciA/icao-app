# 飞猪 ICAO 架构决策记录

状态：当前长期决策
更新时间：2026-07-30

本文只记录改变后会造成明显返工或跨系统影响的长期边界。库版本、文件名、临时排障步骤和
单个页面实现不在这里固化。

## ADR-001：客户端技术栈

决定：

- iOS 与 Android 使用 React Native、Expo、TypeScript、Development Builds 和 CNG/Prebuild。
- Web 使用同一仓库的 Expo Web 目标。
- 不引入 WebView 或第二套客户端框架，除非新的架构决策明确说明收益、迁移和退出方式。

原因：共享产品语义和大部分实现，同时保留平台能力与部署边界。

## ADR-002：Native 与 Web 运行时分离

决定：

- Native 正式链路连接 ECS API 与 Supabase/受保护服务。
- Web 正式链路使用 Vercel Functions、同源静态内容和浏览器本地数据。
- Web 不调用 ECS/Supabase，不参与 Native 云同步。

原因：降低公开 Web 对正式账号后端的耦合和暴露面，并让两个平台独立发布与恢复。

## ADR-003：身份与邀请机制

决定：

- Native 使用现有邀请码入口与正式账号链路。
- Web 使用独立邀请码会话/cookie，不与 Native 身份合并。
- 身份方式的更换属于产品与迁移决策，不能由旧的“邮箱登录”阶段文档自动触发。

## ADR-004：共享来源与所有权

决定：

- 题库内容、题库资源、音频映射、录音资产、学习状态和运行时配置必须各有明确唯一来源。
- 新功能先复用或扩展现有共享模块；确实不能满足时，记录旧边界、独立所有权与迁移路径。
- 生成文件由工具产生，不手工维护平行副本。

## ADR-005：音频与录音生命周期

决定：

- Native 音频会话与录音沿用现有 orchestrator、recorder adapter、repository 和 asset 类型。
- Web 播放采用当前独立实现与浏览器生命周期，不伪装成 Native 会话模型。
- 任何新 owner、直接音频模式调用或删除路径都必须先证明现有抽象无法承担。

细节见 `docs/guides/audio-lifecycle-and-change-rules.md`。

## ADR-006：设计身份由代码令牌和共享组件承载

决定：

- 品牌色、字体角色、圆角、间距、阴影和动效基线以 `src/theme/` 为可执行来源。
- `docs/design/ui-style-guide.md` 解释不允许漂移的设计意图和使用方式。
- 历史设计仓库与截图是只读视觉证据，不作为当前组件路径或技术栈说明。
- 全局风格方向变化需要用户明确确认；页面适配可在既有语言内自主完成。

## ADR-007：验证按风险选择

决定：

- 不以“所有文件变化”触发同一套全仓检查、原生构建和部署。
- 变更触及共享边界、生命周期、生成资产、原生配置或发布时扩大验证。
- UI 以实际渲染和交互作为验收证据。

矩阵见 `docs/engineering/verification-matrix.md`。

## ADR-008：部署不由本地改动自动授权

决定：

- 仓库是实现来源，但本地、预览和线上是不同状态。
- API 或 Web 的生产发布必须在当前任务包含线上环境时执行。
- 数据库迁移独立审批、备份和验证；不能包含在普通部署授权里。
