RN 仓库含题库 JSON 和音频索引，不含完整音频文件；规范音频源仍位于只读设计仓库 `public/question-bank-assets/audio`。迁移应读取源文件但只把脚本、清单和结果写入 `icao-app` 或 ECS。

当前没有题库版本、checksum、远程 manifest、Storage bucket、签名地址或导入报告。

### 内容结构补充盘点

- `question-bank.json` 约 4.36 MB、45,734 行；适合作为运行快照和回退基线，不适合继续作为长期人工维护的唯一文件。
- `audio-index.json` 约 1.50 MB；记录 3894 个文件，但运行清单仍缺少逐文件 checksum、MIME 和云端 object key。
- 5 库、27 分类、239 话题、4947 卡片的声明数量全部一致；题库、分类、话题和卡片 ID 未发现重复。
- 当前 Repository、类型和学习页面统一，未形成五套实现；但 `QuestionBankId`、复习方式、OPI 生成音频、广播和模考仍有少量按题库硬编码。
- 题库 ID `sentences900` 与音频模块名 `sentence900` 不一致；发布前必须统一规范或提供显式兼容映射。
- 当前 JSON 通过 TypeScript 类型断言载入，没有独立运行时 schema 校验，错误数据可能到构建或运行阶段才暴露。

因此 A2 应先建立“维护层拆分、发布层生成、运行层统一”的内容工程基线，再进行云端导入；拆分维护源不得复制页面、Repository 或后端业务代码。

## 4. 本地学习数据

现有 `learning-store.ts` 已具备：

- v1 到 v2 的话题状态迁移。
- `visited`、`completed`、作答、录音标记、笔记、标签、高亮和 `updatedAt`。
- 同一话题写入队列，降低并发覆盖风险。
- 最近 100 条学习记录。

缺口：

- 无账号归属、设备 ID、稳定 mutation ID、服务端版本或同步 cursor。
- 无 outbox、重试、幂等确认、跨设备恢复或冲突处理。
- 学习记录仍使用旧 key，数量上限和报告归属尚未进入可同步结构。

## 5. 认证与页面

- 登录页当前接受“手机号/账号”，注册页以手机号和验证码为主，提交后只跳转页面。
- 没有 Auth adapter、Supabase client、SecureStore、会话恢复或退出清理。
- 找回密码、手机号验证码、换绑和注销均为演示页面。
- `app.json` 仍使用占位 Bundle ID/Package Name，并保留待更名的当前产品名称；不阻塞隧道内开发，但不能用于正式回调或上架。

## 7. 风险与回滚点

### 已关闭的 A0 决策

- 邮箱确认关闭，仅限受控测试；SMTP 延期。
- 物理 iPhone 公网认证与同步延期到正式域名和 HTTPS；当前使用本机/SSH 隧道。
- 云端为权威数据源，本地保留回退；首次登录由用户确认本机数据归属。
- 异机备份延期，本子阶段只完成 ECS 内备份和隔离恢复验证。

### P1

- 8 GB/40 GB 单机运行 Supabase、API、Storage 和备份的资源余量有限。
- 完整音频不在 RN 仓库，上传必须由清单驱动并做 checksum。
- 本地数据首次归属和 v3 迁移存在重复、错绑与覆盖风险。
- 服务器当前没有异机备份、恢复证据或持久化容量告警。

### 回滚点

- 保留内嵌 repository 和原 v1/v2 SQLite keys，远程切换失败时可回退。
- 导入使用新版本记录，不覆盖原题库 JSON 和音频源。
- Migration 必须先在空库和备份副本验证；禁止用重置脚本处理已有用户数据。
