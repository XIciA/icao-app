# 第二阶段 A 收口：题库云端接入与数据同步

状态：已完成

完成日期：2026-07-12

## 1. 完成结论

第二阶段 A 的 A0 至 A4 已完成并通过本地、iOS 模拟器和 ECS 真实验证。当前已具备：

- 单台 ECS 上的自托管 Supabase、TypeScript API、Migration、私有 Storage 和 ECS 内备份。
- 五套真实题库、统一内容工程、版本化发布、远程 Repository、缓存与内嵌回退。
- 受控邮箱密码注册/登录、SecureStore 会话恢复和退出。
- 学习状态、作答、标注、高亮、标签、笔记、学习记录和报告的版本化云同步。
- 首次归属确认、绑定前快照、outbox、幂等、冲突处理、server cursor 和失败恢复。

## 2. 核心证据

- 内容：5 库、27 分类、239 话题、4947 卡片、3894 个资源；云端数量一致。
- 运行：题库与资源 API 均在 iOS 模拟器经安全隧道实际命中；学习页真实资源可解析。
- 账号：注册、登录、错误密码、会话恢复、鉴权 API 和测试账号清理通过。
- 同步：重复提交、旧版本、双会话全量恢复和增量恢复通过。
- 恢复：含四类用户同步数据的备份在隔离库恢复通过，线上测试数据已清理。
- 工程：`pnpm check`、全量内容校验、Expo Doctor 19/19 和 iOS Development Build 通过。

## 3. 保留与回滚

- 内嵌题库和 v1/v2 SQLite 数据未删除。
- 云端失败时题库按远程缓存、内嵌数据顺序回退；学习写入失败时本地数据和 outbox 保留。
- 题库维护源、发布产物和运行层分离；后续更新不需要复制页面或后端模块。
- 客户端不持有数据库连接、service key 或 Storage 管理密钥。
