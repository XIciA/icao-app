## 1. 盘点结论

第一阶段具备执行条件。当前 Web 已形成可用的移动端高保真基线、统一题库结构、真实内容数据、音频资源、学习行为和状态页面，可以作为 React Native 原生复刻依据。

当前尚未创建 React Native 工程和独立 GitHub 仓库。正式进入小流程后，应先完成独立工程、双端 Development Build 和基础验证，再开始页面复刻。

本次盘点未发现与 `战略/总战略文档.md` 或 `战略/architecture-decisions.md` 冲突的阻塞项。

## 3. 当前页面与流程

### 3.1 顶层入口

当前共有以下顶层页面：

- `/`：主 App 预览与核心导航。
- `/auth`：认证流程预览。
- `/account`：账户与设置流程预览。
- `/info`：协议、隐私、帮助、反馈和关于。
- `/state`：权限、网络、加载和失败状态。
- `/curriculum`：独立桌面营销页；用户已确认不迁移到RN，App内部“体系课程”页面继续保留在复刻范围。

Web 中的 `PhoneFrame`、iframe 和 `embed=1` 只用于浏览器预览，不属于未来 RN App 页面结构。

### 3.2 主 App 流程

`components/app-shell.tsx` 当前集中管理：

- 三个主 Tab：题库、发现、我的。
- 五套题库及统一目录/学习页。
- 单词、文章、资源、课程、随身听、AI模考、AI报告、OPI热点。
- 我的标注、学习记录、账户资料、设置、帮助、关于和通知权限等全屏子流程。
- mock 登录状态、详情返回和覆盖层返回关系。

RN 不能直接复制这一大型组件，但其状态关系可以作为导航和页面清单依据。

### 3.3 基础 App 页面

- 认证流程：启动、登录、注册、手机验证码、忘记密码、用户协议、隐私政策。
- 账户流程：资料、编辑资料、设置、数据同步、安全、换手机号、换邮箱、改密码、注销账号、退出确认。
- 信息流程：信息入口、用户协议、隐私政策、帮助、反馈、关于。
- 状态流程：麦克风权限、麦克风拒绝、通知权限、无网络、加载失败、维护、全局加载。

这些页面已经具备视觉和交互参考，但多数使用 mock 或演示状态，第一阶段继续保持相同效果，不接真实账号与云端业务。

风险：560MB资源不能未经评估全部打入安装包。第一阶段应通过统一资源接口完成联网真机验证，不建设离线下载系统。

图片资源已覆盖文章、博客、案例、首页、OPI热点、图标和占位图；后续需在页面清单中逐项确认实际引用与RN适配方式。

当前至少以下能力依赖浏览器或Next.js：

- `window`、`document`、`navigator`、iframe和URL查询参数。

- `Audio`、`MediaRecorder`、`MediaStream`、Permissions API和Web Audio。

处理原则：保留用户可见行为与状态，使用RN、Expo或必要原生能力重建，不共享或翻译Web实现代码。

## 7. AI与服务端现状

当前Web已有6个AI Route Handler，覆盖查词、语法、润色、转写等能力，并有阿里云百炼模型、Prompt、错误码和响应校验基础。

这些代码属于后续真实服务能力参考，不能放入RN客户端，也不能把密钥下发到App。

第一阶段只需复刻当前页面、交互、mock/占位、加载和失败效果；不要求迁移真实AI服务。后续应通过项目业务后端接入。

## 8. 本机开发环境

已具备：

- Node.js `v24.4.1`、pnpm `11.7.0`。
- Xcode 26.3、可用iOS 26.3模拟器。
- CocoaPods 1.16.2。
- Android SDK、platform-tools、build-tools和emulator已安装。
- Android Studio自带JDK 21可用。
- 用户已确认可提供一台iPhone和一台Android手机用于最终双端物理真机验收。

待处理：

- 当前终端没有配置Java运行时路径。
- `ANDROID_HOME` / `ANDROID_SDK_ROOT` 未配置到当前终端。
- Android模拟器当前没有已创建AVD。
- Expo CLI不应在设计稿仓库临时安装；应在新RN工程创建时由项目依赖提供。
- Node具体版本由Codex在创建RN工程时按当时Expo兼容性锁定，不把当前Node 24直接视为必选版本。

iOS可以直接进入工程验证；Android必须先完成环境路径、JDK和AVD收口，才能满足双端阶段验收。

## 10. 缺口与风险分级

### P0：进入开发前必须解决

- 创建独立RN本地工程；本地项目目录已创建为 `/Users/zhouyide/Desktop/icao-app`，远程仓库确定为当前GitHub账号下的Private仓库 `icao-app`。
- iOS与Android均完成Development Build启动验证。
- 配置Android JDK、SDK路径和AVD。
- 建立完整页面/流程/状态对照矩阵，防止“全部页面复刻”发生遗漏。
- 明确规范资源来源，禁止同时迁移新旧音频目录。

### P1：垂直样例阶段必须验证

- RN数据接口能够读取真实题库并保持统一五题库结构。
- 真实音频在真机联网环境中稳定播放。
- 轻量本地保存能够覆盖学习记录、标注和笔记。
- 安全区、字体、长文本、滚动、底部导航和弹层达到设计稿效果。
- 录音、权限和应用生命周期能用Expo能力实现现有效果。

### P2：全面复刻阶段持续处理

- Web动画与RN原生动画的视觉差异。
- iOS与Android字体、返回手势、键盘和音频焦点差异。
- mock AI和未接真实能力的稳定失败回退。
- 当前缺少自动化测试和固定截图验收资产。

## 11. 总体判断

当前资料和资源足以开始第一阶段，不需要回到总战略或架构决策重新选型。

正确启动顺序是：独立工程与双端环境 -> 设计基础和导航壳 -> 一条真实题库垂直链路 -> 扩展五题库 -> 复刻其余页面与状态 -> 双端逐页验收与收口。
