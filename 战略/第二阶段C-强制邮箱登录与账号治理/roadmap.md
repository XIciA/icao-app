## 执行边界

- 当前唯一登录方式为邮箱密码；封闭内测注册自动确认。
- Mailpit 不持久化、不公网外发，只通过 SSH 隧道查看。
- 手机号、微信、Apple、正式 SMTP、公司主体、域名、备案、支付和公开运营延期。
- 活跃数据注销时立即删除；备份按现有 7 天周期自然过期。
- UI 保持当前视觉与导航，只把演示账号页面替换为真实逻辑。

## 验收门禁

- `pnpm check`、Migration check、Expo Doctor、iOS Development Build。
- 无 token/非法 token/已撤销 session 无法访问题库、资源、同步和 AI。
- 重启恢复、过期重登、双会话立即退出、数据合并/归档、换绑/找回和注销通过。
- iOS 模拟器完成 Mailpit 回跳；物理 iPhone完成登录、同步、修改密码和注销。
