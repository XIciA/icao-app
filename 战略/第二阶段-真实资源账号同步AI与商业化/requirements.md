# 第二阶段需求：真实产品能力与内部测试

状态：已确认

更新时间：2026-07-13

## 1. 目标

将第一阶段的本地对照 App 完善为内部测试可用的真实产品：接入真实资源、账号与学习数据同步，完整实现现有 Web 标准库中的 AI 能力，并建立后续商业化所需的权益边界。

本阶段不以正式上架或公开运营为目标。

## 2. 基本边界

- 客户端继续使用 React Native、Expo 和 TypeScript，不重新设计第一阶段已确认的页面结构、视觉语言和核心学习流程；允许补齐真实登录、AI 和状态反馈必需的入口与文案。
- Web 项目只作为功能、交互、内容、AI 规则和验收效果的参考库与标准库，不复制 Web UI、DOM、CSS、浏览器 API 或业务代码。
- 第二阶段以 iOS 内部测试为验收范围，暂不进行 Android 功能、构建或真机测试；该安排不取消 Android 作为正式支持平台，后续发布前必须恢复完整验证。

## 3. 真实资源

- 题库、音频、图片和其他首版内容通过真实资源服务提供。
- 资源缺失、加载失败、网络不可用和访问超时时必须提供明确提示与重试入口。
- 允许必要缓存提升体验，不把完整音频库打入安装包，不提供题库包或音频包下载，不承诺完整离线学习。

## 4. 登录与账号

- 邮箱密码是当前唯一身份入口；取消匿名游客和免登录业务能力，手机号、微信与 Apple 登录延期。
- 无有效会话不能访问题库、资源、同步或 AI；登录状态安全保存，并支持续期、失效提示、当前设备退出和全部设备立即退出。
- 封闭内测注册自动确认；Mailpit 只用于换绑邮箱和找回密码测试，正式 SMTP 延期。
- 支持修改密码、换绑邮箱测试流程、找回密码测试流程、用户自助注销和活跃数据删除。
- 旧版未归属本地数据在首次登录后必须明确选择合并到当前账号，或保存本地归档并从云端空账号开始。

## 5. 学习数据同步

- 正式账号登录后，自动同步学习进度、作答、标注、笔记和学习报告，并支持同账号恢复。
- 本地数据继续用于退出保护、网络波动和同步失败恢复，不作为完整离线学习系统。
- 同步失败时应明确提示并自动重试，不得静默丢失或覆盖学习数据。
- 数据冲突必须有稳定处理规则，具体方案在技术方案阶段确定。

## 6. AI 能力

React Native 必须具备当前 Web 标准库已有的全部真实 AI 学习能力：

| 能力 | 使用范围 |
| --- | --- |
| AI 查词 | 听力、900句、陆空通话、OPI、故事复诵 |
| 语音转写 | 900句、陆空通话、OPI、故事复诵 |
| 对比原文 | 900句 |
| 检查语法 | 陆空通话、故事复诵 |
| 分析表达 | OPI，包含语法纠错与表达润色 |

要求：

- Web 中的 Prompt、输出结构、领域术语、ASR 热词、数字与字母规则、转写规范化和质量标准作为行为依据，但必须为 React Native 和业务后端重新实现。
- AI 经项目业务后端统一调用；客户端不得直连模型供应商或保存模型密钥。
- 保留当前入口和结果区域，完整覆盖录音、转写、生成、成功、失败、超时、服务不可用、额度不足和重试状态。
- 不新增 Web 标准库不存在的评分、ICAO 等级判定或考试结论。

## 7. AI 数据同意

- 首次发送录音、转写文本或题目上下文前，必须取得用户明确同意，并说明数据类型、用途和外部 AI 处理事实。
- 用户拒绝后仍可使用非 AI 学习功能，并可在设置中撤回同意。
- 原始录音完成转写后不在项目服务器长期保存。
- 转写文本和 AI 结果仅在用户主动保存时进入学习记录。
- 用户数据不得用于模型训练或广告分析。

## 8. AI 内测额度

| 能力 | 单用户每日额度 |
| --- | ---: |
| AI 查词 | 20 次 |
| 语音转写 | 累计 15 分钟，单次最长 2 分钟 |
| 语法检查 | 10 次 |
| OPI 表达分析 | 5 次 |
| 900句原文对比 | 不限次数，本地执行 |

额度规则：

- 每分钟最多发起 10 次 AI 请求，同一用户同时只处理一个语音任务。
- 只扣除成功完成的用户额度；失败、超时和用户取消不扣除。
- 每日北京时间 00:00 重置，管理员测试账号可临时调整额度。
- 单用户每日成本达到 1 元时预警，1.5 元时停止新调用；整个内测环境每日成本上限为 100 元。
- 额度、频率和成本阈值必须由服务端统一控制并可配置。

## 9. 商业化预留

- 定义免费权益、AI 额度、未来会员权益、购买恢复和退款说明所需的规则与接入边界。
- 本阶段不接会员收费、订阅、单次购买或任何真实支付。
- 页面不得把预留权益误标为已经可以购买或正式生效。

## 10. 明确不做

- 不正式上架，不面向公众运营。
- 不接真实支付、订阅或会员收费。
- 不接正式 SMTP、手机号、微信、Apple 或公开注册运营。
- 不进行 Android 测试或以第二阶段结果声明 Android 已验收。
- 不建设完整离线学习、资源下载或复杂双向离线冲突系统。
- 不复制 Web 代码，不使用 WebView，不在客户端直连模型或云端业务表。
- 不重新设计第一阶段已确认的 UI、导航和学习流程。

## 11. 验收效果

- iOS 内部测试环境可完成邮箱注册/登录、登录恢复、修改密码、双层退出、测试邮件换绑/找回和账号注销。
- 同账号可恢复核心学习数据，同步失败和冲突不会造成无提示的数据丢失。
- 真实题库、音频、图片及失败回退在 iOS 内部测试环境可用。
- 五类 AI 学习能力均能从现有入口完成真实调用，并具备完整状态、同意和额度控制。
- AI 原始录音、转写文本和结果符合已确认的数据使用与保存边界。
- 商业化规则和未来接口边界清楚，但不存在真实收费入口。
- 第二阶段成果可供内部人员持续测试，并为后续上架准备提供稳定基础。
